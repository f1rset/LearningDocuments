## 🎯 Ключові концепції (Core Concepts)
1. **Математичне сподівання ($E[X]$ / $\mu$):** Центр тяжіння розподілу ймовірностей та фундаментальна лінійність ($E[aX+bY] = aE[X]+bE[Y]$).
2. **Дисперсія ($\operatorname{Var}(X)$ / $\sigma^2$) та стандартне відхилення ($\sigma$):** Міра розсіювання значень навколо середнього.
3. **Теорема про сподівання функції (LOTUS):** $E[g(X)]$.
4. **Вищі моменти (Higher-Order Moments):** Асиметрія (Skewness) та Ексцес (Kurtosis).
5. **Квантилі, медіана та міжквартильний розмах (Quantiles & IQR):** Робастні характеристики розподілу.
6. **Твірна функція моментів (MGF $M_X(t)$) та характеристична функція ($\varphi_X(t)$):** Аналітичний апарат генерації моментів.

---

## 1. Математичне сподівання (Expected Value / Mean)

### 1.1. Означення
**Математичне сподівання $E[X]$** (або $\mu$, $\mathbb{E}[X]$) — це теоретичне середньозважене значення випадкової величини:
* **Для дискретної ВВ:**
  $$E[X] = \sum_{i} x_i P(X = x_i) = \sum_{i} x_i p_i$$
* **Для неперервної ВВ:**
  $$E[X] = \int_{-\infty}^{+\infty} x f(x)\,dx$$
  *(За умови абсолютної збіжності ряду $\sum |x_i|p_i < \infty$ або інтеграла $\int |x|f(x)dx < \infty$)*.

### 1.2. Теорема LOTUS (Law of the Unconscious Statistician)
Для будь-якої функції $g(X)$ не потрібно шукати новий закон розподілу для $Y = g(X)$:
$$E[g(X)] = \begin{cases} \sum_i g(x_i) p_i, & \text{дискретний випадок} \\ \int_{-\infty}^\infty g(x) f(x)\,dx, & \text{неперервний випадок} \end{cases}$$

### 1.3. Властивості математичного сподівання
1. **Константа:** $E[c] = c$.
2. **Винесення константи:** $E[c X] = c E[X]$.
3. **👑 Лінійність (Linearity of Expectation):**
   $$E[a X + b Y + c] = a E[X] + b E[Y] + c$$
   *(Виконується **завжди**, незалежно від того, чи є величини $X$ та $Y$ незалежними, чи залежними!)*.
4. **Добуток незалежних величин:** Якщо $X$ та $Y$ незалежні:
   $$E[X Y] = E[X] \cdot E[Y]$$

## 2. Дисперсія та стандартне відхилення (Variance & Standard Deviation)

### 2.1. Означення
**Дисперсія (Variance $\operatorname{Var}(X)$ або $\sigma^2$)** — це середній квадрат відхилення від математичного сподівання:
$$\operatorname{Var}(X) = E\left[ (X - E[X])^2 \right]$$

* **Розрахункова формула (Computational Formula):**
  $$\operatorname{Var}(X) = E[X^2] - (E[X])^2$$
* **Стандартне (середньоквадратичне) відхилення (Standard Deviation $\sigma$):**
  $$\sigma = \operatorname{Std}(X) = \sqrt{\operatorname{Var}(X)}$$
  *(Має ту саму розмірність, що й вихідна випадкова величина)*.

### 2.2. Властивості дисперсії
1. **Невід'ємність:** $\operatorname{Var}(X) \ge 0$, причому $\operatorname{Var}(X) = 0 \iff P(X = c) = 1$.
2. **Зсув та масштаб:**
   $$\operatorname{Var}(a X + b) = a^2 \operatorname{Var}(X), \qquad \operatorname{Std}(a X + b) = |a| \operatorname{Std}(X)$$
3. **Сума незалежних величин:** Якщо $X$ та $Y$ незалежні:
   $$\operatorname{Var}(X + Y) = \operatorname{Var}(X) + \operatorname{Var}(Y), \qquad \operatorname{Var}(X - Y) = \operatorname{Var}(X) + \operatorname{Var}(Y)$$
4. **Загальний випадок із коваріацією:**
   $$\operatorname{Var}(a X + b Y) = a^2 \operatorname{Var}(X) + b^2 \operatorname{Var}(Y) + 2 a b \operatorname{Cov}(X, Y)$$

## 3. Вищі моменти, асиметрія та ексцес (Moments)

### 3.1. Означення моментів
* **Початковий момент порядку $k$ (Raw moment):** $\alpha_k = E[X^k]$. ($\alpha_1 = \mu$).
* **Центральний момент порядку $k$ (Central moment):** $\mu_k = E[(X - \mu)^k]$. ($\mu_2 = \sigma^2$).

### 3.2. Асиметрія (Skewness $\gamma_1$)
Безрозмірна міра несиметричності форми розподілу:
$$\gamma_1 = \operatorname{Skew}(X) = \frac{\mu_3}{\sigma^3} = \frac{E[(X - \mu)^3]}{\sigma^3}$$
* $\gamma_1 = 0$: Симетричний розподіл (наприклад, Нормальний).
* $\gamma_1 > 0$: Правостороння (додатна) асиметрія (довгий правий хвіст, доходи, LogNormal).
* $\gamma_1 < 0$: Лівосторонній довгий хвіст.

```text
    Правостороння (Skew > 0)          Симетрична (Skew = 0)
        ^                                  ^
       / \                                / \
      /   \                              /   \
     /     \________                    /     \
    +------------------->              +-------\----------->
```

### 3.3. Ексцес (Kurtosis / Excess Kurtosis $\gamma_2$)
Міра гостровершинності та важкості хвостів відносно нормального розподілу:
$$\gamma_2 = \operatorname{Kurt}(X) = \frac{\mu_4}{\sigma^4} - 3$$
* $\gamma_2 = 0$: Мезокуртичний (як у нормального розподілу).
* $\gamma_2 > 0$: Лептокуртичний (гостра вершина, важкі хвости, часті "чорні лебеді").
* $\gamma_2 < 0$: Платикуртичний (плоска вершина, легкі хвости).

---

## 4. Квантилі, медіана та мода (Quantiles & Order Statistics)

* **$p$-Квантиль (Quantile $x_p$):** Значення, для якого $F(x_p) = P(X \le x_p) = p$ ($p \in (0, 1)$).
* **Медіана ($\text{Med} / x_{0.5}$):** Значення, яке ділить розподіл навпіл ($F(\text{Med}) = 0.5$).
* **Квартилі:** $Q_1 = x_{0.25}$ (25%), $Q_2 = \text{Med}$ (50%), $Q_3 = x_{0.75}$ (75%).
* **Міжквартильний розмах (Interquartile Range - IQR):** $\text{IQR} = Q_3 - Q_1$ (робастна міра розсіювання).
* **Мода ($\text{Mode}$):** Точка локального максимуму PMF або PDF (найімовірніше значення).

---

## 5. Твірні функції моментів та характеристичні функції

### 5.1. Твірна функція моментів (Moment Generating Function - MGF)
$$M_X(t) = E\left[ e^{t X} \right]$$
* **Генерація моментів через похідні в нулі:**
  $$E[X^k] = \left. \frac{d^k M_X(t)}{dt^k} \right|_{t = 0} = M_X^{(k)}(0)$$
* **Властивість для суми незалежних величин:**
  $$M_{X + Y}(t) = M_X(t) \cdot M_Y(t)$$
* **Єдиність:** Якщо MGF існує в околі нуля, вона однозначно визначає розподіл випадкової величини.

### 5.2. Характеристична функція (Characteristic Function $\varphi_X(t)$)
$$\varphi_X(t) = E\left[ e^{i t X} \right] = \int_{-\infty}^\infty e^{i t x} f(x)\,dx$$
* Завжди існує для **будь-якої** випадкової величини (оскільки $|e^{itX}| = 1$).
* Є прямим перетворенням Фур'є для функції щільності $f(x)$.

---

## ⚠️ Підводні камені та типові помилки (Pitfalls)

1. **Неправомірне використання $\operatorname{Var}(X+Y) = \operatorname{Var}(X) + \operatorname{Var}(Y)$:**
   Ця рівність справедлива **виключно для некорельованих/незалежних** величин. Якщо вони залежні, обов'язково треба враховувати доданок $2\operatorname{Cov}(X, Y)$.
2. **Плутанина між лінійністю сподівання та дисперсії:**
   $E[aX] = aE[X]$, але $\operatorname{Var}(aX) = a^2 \operatorname{Var}(X)$! Для мінуса: $\operatorname{Var}(-X) = (-1)^2 \operatorname{Var}(X) = \operatorname{Var}(X)$.
3. **Нестійкість середнього до викидів (Outliers):**
   Математичне сподівання $E[X]$ та дисперсія надзвичайно чутливі до екстремальних значень, тоді як медіана та IQR є робастними (стійкими).
