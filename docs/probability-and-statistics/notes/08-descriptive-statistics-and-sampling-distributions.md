## 🎯 Ключові концепції (Core Concepts)
1. **Генеральна сукупність (Population) та вибірка (Sample):** Перехід від імовірнісних моделей до аналізу емпіричних даних.
2. **Вибіркові описові статистики:** Вибіркове середнє ($\bar{X}$), виправлена дисперсія ($S^2$, поправка Бесселя $n-1$), вибіркова коваріація та кореляція ($r$).
3. **Емпірична функція розподілу (ECDF $\hat{F}_n(x)$) та теорема Гливенка-Кантеллі:** Фундаментальна теорема статистики.
4. **Вибіркові розподіли Гауссових вибірок:**
   * Розподіл вибіркового середнього: $\bar{X} \sim \mathcal{N}\left(\mu, \frac{\sigma^2}{n}\right)$.
   * Розподіл Хі-квадрат: $\frac{(n-1)S^2}{\sigma^2} \sim \chi^2(n-1)$.
   * Розподіл Стьюдента ($t$-distribution): $\frac{\bar{X}-\mu}{S/\sqrt{n}} \sim t(n-1)$.
   * Розподіл Фішера-Снедекора ($F$-distribution): $\frac{S_1^2/\sigma_1^2}{S_2^2/\sigma_2^2} \sim F(n_1-1, n_2-1)$.
5. **Теорема Фішера про незалежність $\bar{X}$ та $S^2$:** Унікальна властивість нормальних вибірок.

## 1. Основи математичної статистики (Foundations of Statistics)

| Поняття | Теорія ймовірностей | Математична статистика |
| :--- | :--- | :--- |
| **Вхідні дані** | Відомий точний розподіл (напр., $\mathcal{N}(0, 1)$) | Спостережувані емпіричні дані $x_1, x_2, \dots, x_n$ |
| **Задача** | Обчислити ймовірність подій, сподівання | Відновити невідомий розподіл або параметри ($\mu, \sigma^2$) |
| **Напрямок думки** | Від моделі $\to$ до даних (дедукція) | Від даних $\to$ до моделі (індукція) |

* **Проста випадкова вибірка (Simple Random Sample - SRS):** Набір незалежних однаково розподілених (i.i.d.) випадкових величин $X_1, X_2, \dots, X_n$, що мають спільний розподіл генеральної сукупності.

## 2. Вибіркові статистики (Sample Statistics)

### 2.1. Вибіркове середнє (Sample Mean $\bar{X}$)
$$\bar{X} = \frac{1}{n} \sum_{i=1}^n X_i$$
* $E[\bar{X}] = \mu$ (незміщена оцінка).
* $\operatorname{Var}(\bar{X}) = \frac{\sigma^2}{n}$, стандартна помилка $\text{SE}(\bar{X}) = \frac{\sigma}{\sqrt{n}}$.

### 2.2. Вибіркова дисперсія та поправка Бесселя (Bessel's Correction)
* **Зміщена оцінка дисперсії ($S_{\text{biased}}^2$):**
  $$S_{\text{biased}}^2 = \frac{1}{n}\sum_{i=1}^n (X_i - \bar{X})^2 \implies E[S_{\text{biased}}^2] = \frac{n-1}{n}\sigma^2 \neq \sigma^2$$
* **Незміщена виправлена дисперсія (Unbiased Sample Variance $S^2$):**
  $$S^2 = \frac{1}{n - 1} \sum_{i=1}^n (X_i - \bar{X})^2 \implies E[S^2] = \sigma^2$$
  *(Ділення на $n-1$ компенсує втрату одного ступеня вільності через використання $\bar{X}$ замість істинного $\mu$)*.

### 2.3. Емпірична функція розподілу (ECDF)
$$\hat{F}_n(x) = \frac{1}{n} \sum_{i=1}^n \mathbb{I}(X_i \le x) = \frac{\text{кількість елементів вибірки } \le x}{n}$$

> **👑 Теорема Гливенка-Кантеллі (Основна теорема статистики):**
> Емпірична функція розподілу рівномірно збігається до істинної теоретичної функції розподілу майже напевно:
> $$\lim_{n \to \infty} \sup_{x \in \mathbb{R}} |\hat{F}_n(x) - F(x)| = 0 \quad \text{a.s.}$$

```text
    F(x) ^               --- Theoretical F(x)
       1 |          _--* ECDF Fn(x) (Східчаста)
         |       _--*
         |    _--*
       0 +---*----------------------------> x
```

## 3. Спеціальні вибіркові розподіли (Sampling Distributions)

Нехай $Z_1, Z_2, \dots \sim \mathcal{N}(0, 1)$ — незалежні стандартні нормальні величини.

### 3.1. Розподіл Хі-квадрат ($\chi^2(k)$ / Chi-Squared)
Сума квадратів $k$ незалежних стандартних нормальних величин:
$$\chi^2(k) = \sum_{i=1}^k Z_i^2$$
* **Параметр:** $k \in \mathbb{N}$ — число ступенів вільності (degrees of freedom - df).
* **Характеристики:** $E[\chi^2(k)] = k$, $\operatorname{Var}(\chi^2(k)] = 2k$.
* **👑 Теорема про вибіркову дисперсію:** Для нормальної вибірки $X_i \sim \mathcal{N}(\mu, \sigma^2)$:
  $$\frac{(n - 1)S^2}{\sigma^2} = \frac{\sum_{i=1}^n (X_i - \bar{X})^2}{\sigma^2} \sim \chi^2(n - 1)$$

### 3.2. Розподіл Стьюдента ($t(k)$ / Student's $t$-Distribution)
Відношення стандартної нормальної величини до кореня з незалежної хі-квадрат величини:
$$T = \frac{Z}{\sqrt{\chi^2(k) / k}} \sim t(k)$$
* **Характеристики:** Симетричний відносно 0, має важчі хвости, ніж $\mathcal{N}(0, 1)$. При $k \to \infty$ розподіл $t(k) \xrightarrow{d} \mathcal{N}(0, 1)$.
* **👑 $t$-Статистика Стьюдента для вибіркового середнього при невідомому $\sigma$:**
  $$T = \frac{\bar{X} - \mu}{S / \sqrt{n}} \sim t(n - 1)$$

```text
    f(t) ^           - - - Нормальний N(0, 1)
         |            ___  Стьюдента t(k) (Важчі хвости)
         |           /   \
         |          /     \
         +---------'-------'---------> t
```

### 3.3. Розподіл Фішера-Снедекора ($F(d_1, d_2)$ / Fisher-Snedecor $F$-Distribution)
Відношення двох незалежних хі-квадрат величин, нормованих на свої ступені вільності:
$$F = \frac{\chi^2(d_1) / d_1}{\chi^2(d_2) / d_2} \sim F(d_1, d_2)$$
* **👑 $F$-Статистика відношення вибіркових дисперсій:**
  $$F = \frac{S_1^2 / \sigma_1^2}{S_2^2 / \sigma_2^2} \sim F(n_1 - 1, \; n_2 - 1)$$
  *(Використовується для порівняння дисперсій у ANOVA та лінійній регресії)*.

## 4. Теорема Фішера про властивості нормальної вибірки

> **👑 Теорема Фішера:**
> Якщо вибірка $X_1, \dots, X_n \sim \mathcal{N}(\mu, \sigma^2)$ походить із нормального розподілу, то:
> 1. Вибіркове середнє $\bar{X} \sim \mathcal{N}\left(\mu, \frac{\sigma^2}{n}\right)$.
> 2. Масштабована дисперсія $\frac{(n-1)S^2}{\sigma^2} \sim \chi^2(n-1)$.
> 3. **Вибіркове середнє $\bar{X}$ та вибіркова дисперсія $S^2$ є абсолютно незалежними випадковими величинами!**

---

## ⚠️ Підводні камені та типові помилки (Pitfalls)

1. **Ділення на $n$ замість $n-1$ у вибірковій дисперсії:**
   При обчисленні дисперсії вибірки $S^2$ завжди діліть на $n-1$. Ділення на $n$ дає систематичне заниження дисперсії генеральної сукупності на коефіцієнт $\frac{n-1}{n}$.
2. **Застосування розподілів Стьюдента та Хі-квадрат до ненормальних даних:**
   Розподіли $t(n-1)$ та $\chi^2(n-1)$ для вибіркових статистик математично строгі **лише при нормальності вихідної генеральної сукупності**. Для вибірок великого розміру ($n \ge 30$) працює асимптотична нормальність за ЦГТ, але для малих ненормальних вибірок потрібні непараметричні критерії.
3. **Незалежність $\bar{X}$ та $S^2$ існує ЛИШЕ для Гауссового розподілу:**
   Для будь-якого іншого розподілу (наприклад, рівномірного або експоненційного) вибіркове середнє $\bar{X}$ і вибіркова дисперсія $S^2$ є статистично **залежними**.
