# 04. Числові, степеневі та ряди Фур'є (Numerical, Power & Fourier Series)

## 🎯 Ключові концепції (Core Concepts)
1. **Числовий ряд (Infinite Numerical Series $\sum a_n$):** Границя послідовності часткових сум $S_n$.
2. **Ознаки збіжності додатних рядів (Convergence Tests for Positive Series):** Ознака порівняння, Д'Аламбера (Ratio test), Коші (Root test), інтегральна ознака.
3. **Знакопереміжні ряди (Alternating Series):** Ознака Лейбніца, абсолютна та умовна збіжність.
4. **Степеневі ряди (Power Series $\sum c_n(x-x_0)^n$):** Радіус та інтервал збіжності, теорема Абеля.
5. **Ряди Фур'є (Fourier Series):** Ортогональний базис тригонометричних функцій, частотний спектр сигналу.

---

## 1. Числові ряди (Numerical Series)

### 1.1. Означення та необхідна умова збіжності
Нехай $(a_n)_{n=1}^\infty$ — числова послідовність. Вираз вигляду:
$$\sum_{n=1}^\infty a_n = a_1 + a_2 + a_3 + \dots + a_n + \dots$$
називається **числовим рядом**. Послідовність $S_k = \sum_{n=1}^k a_n$ — **часткові суми (partial sums)**.

* Ряд **збігається (converges)**, якщо існує скінченна границя $\lim_{k \to \infty} S_k = S$.
* **Необхідна умова збіжності (Divergence Test / Necessary Condition):**
  $$\sum_{n=1}^\infty a_n \text{ збігається } \implies \lim_{n \to \infty} a_n = 0$$
  *(Зауваження: зворотне твердження хибне! Приклад: гармонічний ряд $\sum \frac{1}{n}$ розбігається, хоч $\frac{1}{n} \to 0$)*.

---

## 2. Ознаки збіжності знакододатних рядів ($a_n \ge 0$)

### 2.1. Еталонні ряди (Benchmark Series)
1. **Геометричний ряд (Geometric Series):**
   $$\sum_{n=0}^\infty q^n = \frac{1}{1 - q} \quad \text{збігається при } |q| < 1, \quad \text{розбігається при } |q| \ge 1$$
2. **Узагальнений гармонічний ряд ($p$-Series / Dirichlet Series):**
   $$\sum_{n=1}^\infty \frac{1}{n^p} = \begin{cases} \text{збігається}, & p > 1 \\ \text{розбігається}, & p \le 1 \end{cases}$$

### 2.2. Ознаки порівняння (Comparison Tests)
* **Пряме порівняння:** Якщо $0 \le a_n \le b_n$:
  * $\sum b_n \text{ збігається} \implies \sum a_n \text{ збігається}$
  * $\sum a_n \text{ розбігається} \implies \sum b_n \text{ розбігається}$
* **Граничне порівняння (Limit Comparison):** Якщо $\lim_{n \to \infty} \frac{a_n}{b_n} = L \in (0, +\infty)$, то обидва ряди поводяться однаково.

### 2.3. Ознаки Д'Аламбера та Коші
* **Ознака Д'Аламбера (D'Alembert / Ratio Test):**
  $$D = \lim_{n \to \infty} \frac{a_{n+1}}{a_n}$$
  * $D < 1 \implies$ збігається.
  * $D > 1 \implies$ розбігається.
  * $D = 1 \implies$ тест не дає відповіді.
* **Радикальна ознака Коші (Cauchy Root Test):**
  $$C = \lim_{n \to \infty} \sqrt[n]{a_n}$$
  * $C < 1 \implies$ збігається; $C > 1 \implies$ розбігається; $C = 1 \implies$ невизначено.
* **Інтегральна ознака Коші-Маклорена (Integral Test):**
  Якщо $f(x)$ неперервна, додатна, монотонно спадна і $f(n) = a_n$:
  $$\sum_{n=1}^\infty a_n \text{ збігається} \iff \int_1^\infty f(x)\,dx \text{ збігається}$$

---

## 3. Знакозмінні ряди: Абсолютна та умовна збіжність

### 3.1. Ознака Лейбніца (Leibniz Test for Alternating Series)
Ряд вигляду $\sum_{n=1}^\infty (-1)^{n-1} b_n$ ($b_n > 0$) **збігається**, якщо:
1. $b_{n+1} \le b_n$ (послідовність спадає за модулем).
2. $\lim_{n \to \infty} b_n = 0$.
* *Оцінка похибки залишку:* $|R_n| = |S - S_n| \le b_{n+1}$.

### 3.2. Абсолютна та умовна збіжність (Absolute vs. Conditional)
* Ряд $\sum a_n$ називається **абсолютно збіжним (absolutely convergent)**, якщо збігається ряд модулів $\sum |a_n|$.
* Ряд називається **умовно збіжним (conditionally convergent)**, якщо сам ряд $\sum a_n$ збігається, але ряд модулів $\sum |a_n|$ розбігається.
  * *Приклад:* $\sum_{n=1}^\infty \frac{(-1)^{n-1}}{n} = 1 - \frac{1}{2} + \frac{1}{3} - \dots = \ln 2$ (умовно збіжний).
* **Теорема Рімана про перестановку членів (Riemann Rearrangement Theorem):** Члени умовно збіжного ряду можна переставити так, щоб його сума дорівнювала будь-якому наперед заданому дійсному числу або $\pm\infty$!

---

## 4. Степеневі ряди (Power Series)

### 4.1. Означення та радіус збіжності
Степеневий ряд навколо точки $x_0$:
$$\sum_{n=0}^\infty c_n (x - x_0)^n = c_0 + c_1(x - x_0) + c_2(x - x_0)^2 + \dots$$

* **Теорема Абеля:** Якщо степеневий ряд збігається в точці $x_1$, то він абсолютно збігається для всіх $|x - x_0| < |x_1 - x_0|$.
* **Радіус збіжності $R$ (Radius of Convergence):**
  $$R = \lim_{n \to \infty} \left| \frac{c_n}{c_{n+1}} \right| \quad \text{або (формула Коші-Адамара)} \quad \frac{1}{R} = \limsup_{n \to \infty} \sqrt[n]{|c_n|}$$
  * Ряд абсолютно збігається при $|x - x_0| < R$ (інтервал $(x_0 - R, x_0 + R)$).
  * На кінцях інтервалу $x = x_0 \pm R$ поведінка досліджується окремо!

### 4.2. Властивості степеневих рядів
Всередині інтервалу збіжності $(-R, R)$ степеневий ряд можна:
1. Почленно диференціювати (радіус $R$ не змінюється):
   $$\left( \sum_{n=0}^\infty c_n x^n \right)' = \sum_{n=1}^\infty n c_n x^{n-1}$$
2. Почленно інтегрувати:
   $$\int \left( \sum_{n=0}^\infty c_n x^n \right) dx = C + \sum_{n=0}^\infty \frac{c_n}{n+1} x^{n+1}$$

## 5. Ряди Фур'є (Fourier Series)

### 5.1. Тригонометричний ряд Фур'є $2\pi$-періодичної функції
Будь-яка кусково-гладка періодична функція $f(x)$ з періодом $T = 2\pi$ (або $T = 2L$) розкладається в ортогональний базис $\{\cos(nx), \sin(nx)\}$:
$$f(x) = \frac{a_0}{2} + \sum_{n=1}^\infty \left( a_n \cos\left(\frac{n\pi x}{L}\right) + b_n \sin\left(\frac{n\pi x}{L}\right) \right)$$

* **Формули Ейлера-Фур'є для коефіцієнтів ($T = 2L$):**
  $$a_0 = \frac{1}{L} \int_{-L}^L f(x)\,dx$$
  $$a_n = \frac{1}{L} \int_{-L}^L f(x) \cos\left(\frac{n\pi x}{L}\right) dx, \quad n \ge 1$$
  $$b_n = \frac{1}{L} \int_{-L}^L f(x) \sin\left(\frac{n\pi x}{L}\right) dx, \quad n \ge 1$$

* **Властивості парності:**
  * Якщо $f(x)$ парна: $b_n = 0$ (розклад тільки за косинусами).
  * Якщо $f(x)$ непарна: $a_n = 0, a_0 = 0$ (розклад тільки за синусами).

### 5.2. Комплексна форма ряду Фур'є (Complex Fourier Series)
Використовуючи формулу Ейлера $e^{i\theta} = \cos\theta + i\sin\theta$:
$$f(x) = \sum_{n=-\infty}^{+\infty} c_n e^{i n \omega_0 x}, \quad \text{де } c_n = \frac{1}{T}\int_{-T/2}^{T/2} f(x) e^{-i n \omega_0 x}\,dx$$

* **Рівність Парсеваля (Parseval's Identity / Енергія сигналу):**
  $$\frac{1}{2L}\int_{-L}^L |f(x)|^2\,dx = \frac{a_0^2}{4} + \frac{1}{2}\sum_{n=1}^\infty (a_n^2 + b_n^2) = \sum_{n=-\infty}^\infty |c_n|^2$$

```text
       Спектральний розклад сигналу:
        ^ f(t) [Прямокутний імпульс]
        |  +----+    +----+
        |  |    |    |    |
        +--+----+----+----+---> t
                  ||
                  \/
         Сума гармонік (Фур'є):
         sin(ωt) + 1/3 sin(3ωt) + 1/5 sin(5ωt) + ...
```

## ⚠️ Підводні камені та типові помилки (Pitfalls)

1. **Плутанина між необхідною та достатньою умовою:** $\lim a_n = 0$ гарантує лише те, що ряд *може* збігатися. Для збіжності потрібна одна з ознак (Д'Аламбер, Коші, Лейбніц тощо).
2. **Забута перевірка кінців інтервалу степеневого ряду:** Якщо $R = 2$, інтервал збіжності спочатку $(-2, 2)$, але точки $x = -2$ та $x = 2$ треба перевіряти підстановкою (там інтервал може бути $[-2, 2)$, $(-2, 2]$ або $[-2, 2]$).
3. **Ефект Гіббса (Gibbs Phenomenon):** Біля точок розриву функції суми Фур'є здійснюють перевищення (overshoot) значення стрибка приблизно на $9\%$ незалежно від кількості взятих членів.
