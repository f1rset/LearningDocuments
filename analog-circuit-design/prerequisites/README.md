# ⚡ Фізика електричних кіл: Повний конспект-довідник (Prerequisites)

Цей конспект створено як міцний фундамент для вивчення курсу **«Аналогова схемотехніка»**. Матеріал побудований за принципом **«від абсолютного нуля до рівня впевненого експерта»**: тут зібрано інтуїтивні фізичні моделі, суворі математичні закони, схеми та типові підводні камені схемотехніки.

## 🚀 Рекомендації щодо Git-хостингу та деплою документації

Для розміщення та публікації бази знань із формулами LaTeX та схемотехнічними діаграмами найкраще підходять наступні платформи:

### 1. 🥇 GitHub + GitHub Pages (Найкращий вибір)
* **Чому це топ:** Безкоштовний необмежений хостинг для Open Source / навчальних репозиторіїв, безшовна інтеграція з CI/CD (GitHub Actions), підтримка Markdown та LaTeX.
* **Рекомендовані генератори статичних сайтів:**
  1. **VitePress** (або VuePress) — блискавичний, мінімалістичний, ідеальний для технічної документації.
  2. **MkDocs + Material Theme** (`mkdocs-material`) — найпопулярніший стандарт для інженерних конспектів з вбудованим пошуком, підтримкою `mathjax`/`katex` і `mermaid`.
  3. **Starlight (Astro)** — надзвичайно швидкий сучасний фреймворк для документації.
  4. **Docusaurus (React)** — підтримує версіонування та складну інтерактивність.

### 2. 🥈 GitLab + GitLab Pages
* **Коли обрати:** Якщо потрібні приватні безкоштовні пайплайни або внутрішній університетський GitLab інстанс.

### 3. 🥉 GitBook / Notion / Obsidian Sync
* **GitBook:** Автоматично синхронізується з GitHub репозиторієм і генерує приємний сайт "з коробки" без написання конфігів.
* **Obsidian + Quartz / MkDocs:** Ви пишете локально в Obsidian (з графом знань), а Quartz автоматично публікує в GitHub Pages.
