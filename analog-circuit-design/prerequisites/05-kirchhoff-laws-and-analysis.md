## 1. Базова термінологія топології електричних кіл

Перш ніж розраховувати складні схеми, визначимо три ключові поняття:

1. **Гілка (Branch):** Нерозгалужена ділянка кола, якою тече один і той самий струм. Гілка складається з одного або кількох послідовно з'єднаних елементів.
2. **Вузол (Node):** Точка з'єднання **трьох або більше** гілок (провідників).
3. **Контур (Loop / Mesh):** Будь-який замкнений шлях, що проходить крізь кілька гілок і вузлів так, що жоден вузол не повторюється двічі.

```
       Вузол A              Гілка 2             Вузол B
          o-----------------[ R2 ]-----------------o
         /                                          \
 Гілка 1 |                                          | Гілка 3
       [R1]                                       [R3]
        (E1)                                       (E2)
         \                                          /
          o----------------------------------------o
       Вузол C              Гілка 4             Вузол D
```

---

## 2. Перше правило Кірхгофа (KCL — Kirchhoff's Current Law)

> **Формулювання:** Алгебраїчна сума струмів у будь-якому вузлі електричного кола дорівнює нулю.

$$\sum_{k=1}^{n} I_k = 0 \quad \Longleftrightarrow \quad \sum I_{\text{вхідні}} = \sum I_{\text{вихідні}}$$

```
               I1 --->       ---> I2
                      \     /
                       \   /
                   -----+--- (Вузол)
                       /   \
                      /     \
              I3 --->        ---> I4
```
$$\text{Для вузла на схемі: } I_1 + I_3 = I_2 + I_4 \quad \Longleftrightarrow \quad I_1 - I_2 + I_3 - I_4 = 0$$

* **Фізична основа:** **Закон збереження електричного заряду**. Заряд не може накопичуватися у вузлі або безслідно зникати.
* **Правило знаків:** Струми, що входять у вузол, зазвичай беруть зі знаком «$+$», а струми, що виходять — зі знаком «$-»$.

---

## 3. Друге правило Кірхгофа (KVL — Kirchhoff's Voltage Law)

> **Формулювання:** У будь-якому замкненому контурі електричного кола алгебраїчна сума ЕРС дорівнює алгебраїчній сумі спадів напруг на всіх опорах цього контуру.

$$\sum_{k} \mathcal{E}_k = \sum_{k} I_k R_k \quad \Longleftrightarrow \quad \sum_{k} \Delta V_k = 0$$

* **Фізична основа:** **Закон збереження енергії** у потенціальному електростатичному полі. Якщо пройти замкненим шляхом і повернутися у вихідну точку, сумарна зміна потенціалу дорівнює 0:
  $$\Delta \varphi_{\text{загальна}} = \varphi_{\text{кінцева}} - \varphi_{\text{початкова}} = 0$$

### ⚠️ Правило знаків для KVL:
1. Довільно обираємо **напрямок обходу контуру** (за годинниковою або проти годинникової стрілки).
2. Якщо напрямок струму в гілці **збігається** з напрямком обходу $\implies$ спад напруги береться зі знаком **$+$** ($+I_k R_k$). Якщо проти $\implies$ зі знаком **$-$** ($-I_k R_k$).
3. Якщо джерело ЕРС при обході проходиться **від мінуса до плюса** (в бік підвищення потенціалу) $\implies$ ЕРС береться зі знаком **$+$** ($+\mathcal{E}_k$). Якщо від плюса до мінуса $\implies$ зі знаком **$-$** ($-\mathcal{E}_k$).

## 4. Повний алгоритм розрахунку складного кола за Кірхгофом

Якщо в колі є $B$ гілок (невідомих струмів) і $N$ вузлів:

1. **Кількість рівнянь за 1-м правилом (KCL):** складаємо для **$(N - 1)$** незалежних вузлів.
2. **Кількість рівнянь за 2-м правилом (KVL):** складаємо для решти **$B - (N - 1)$** незалежних контурів.
3. Отримуємо замкнену систему з $B$ лінійних алгебраїчних рівнянь відносно $B$ невідомих струмів.
4. Розв'язуємо систему (методом Крамера, Гаусса або матричним методом).
5. **Інтерпретація знаку:** Якщо у відповіді якийсь струм вийшов від'ємним ($I_k < 0$), це означає лише те, що його реальний фізичний напрямок протилежний тому, який ми обрали спочатку на схемі.

---

## 5. Метод вузлових потенціалів (Nodal Analysis)

Це стандартний алгоритм, який використовують усі комп'ютерні симулятори схем (SPICE, LTspice, Multisim).

1. Один із вузлів обирається як **опорний (Земля / GND)**: $\varphi_0 = 0\text{ В}$.
2. Для решти $N-1$ вузлів записуються рівняння KCL, виражаючи струми через різницю потенціалів та провідності $G = 1/R$:
   $$I_{ij} = \frac{\varphi_i - \varphi_j}{R_{ij}} = (\varphi_i - \varphi_j) \cdot G_{ij}$$
3. Замість $B$ рівнянь розв'язується всього $N-1$ рівнянь!

## 6. Підсумок формул теми 05

| Назва | Формула | Фізичний закон |
|---|---|---|
| 1-е правило (KCL) | $\sum I_{\text{in}} = \sum I_{\text{out}}$ | Збереження заряду |
| 2-е правило (KVL) | $\sum \mathcal{E} = \sum I R$ | Збереження енергії |
| Незалежні KCL рівняння | $N - 1$ | — |
| Незалежні KVL рівняння | $B - N + 1$ | — |
