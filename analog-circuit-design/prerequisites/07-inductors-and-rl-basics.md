## 1. Електромагнітна індукція та закон Фарадея

Коли електричний струм тече крізь провідник, навколо нього виникає **магнітне поле**.
* **Магнітний потік ($\Phi$):** Кількість ліній магнітної індукції $\vec{B}$, що пронизують контур площею $S$:
  $$\Phi = B \cdot S \cdot \cos\alpha$$
  * Одиниця вимірювання: **Вебер ($\text{Вб}$, $\text{Wb}$)**.

### Закон Фарадея та правило Ленца
Будь-яка зміна магнітного потоку через контур породжує в ньому індукційну ЕРС:

$$\mathcal{E}_{\text{ind}} = -\frac{d\Phi}{dt}$$

* **Знак «$-$» (Правило Ленца):** Індукційний струм завжди спрямований так, щоб протидіяти причині, яка його викликала (зміні магнітного потоку).

---

## 2. Самоіндукція та Індуктивність ($L$)

Коли струм $i(t)$ змінюється в самій котушці, створений нею власний магнітний потік $\Phi$ теж змінюється.
Власний магнітний потік пропорційний силі струму:

$$\Phi = L \cdot i$$

* **Індуктивність ($L$)** — це міра «електричної інертності» провідника щодо зміни струму.
* **Одиниця вимірювання в СІ:** **Генрі ($\text{Гн}$, $\text{H}$)**. $1\text{ Гн} = 1\text{ В}\cdot\text{с} / 1\text{ А}$.
* Для котушки з числом витків $N$, довжиною $l$, площею $S$ і сердечником з проникністю $\mu_r$:
  $$L = \mu_0 \mu_r \frac{N^2 \cdot S}{l}$$

---

## 3. Диференціальне рівняння індуктивності ($u-i$ характеристика)

Підставивши $\Phi = L \cdot i$ в закон Фарадея, отримуємо ЕРС самоіндукції:
$$\mathcal{E}_{\text{self}} = -L \frac{di(t)}{dt}$$

Спад напруги на виводах котушки індуктивності:

$$u_L(t) = L \cdot \frac{di(t)}{dt}$$

### ⚠️ Головні висновки для схемотехніка:
1. **Напруга на котушці існує лише при зміні струму ($\frac{di}{dt} \neq 0$).**
2. **Постійний струм (DC, $\frac{di}{dt} = 0$):** Ідеальна котушка має напругу $u_L = 0$ і діє як **ідеальне коротке замикання (ідеальна перемичка з $0\,\Omega$)**.
3. **Другий закон комутації:** **Струм через котушку індуктивності не може змінитися миттєво!**
   $$i_L(0^+) = i_L(0^-)$$
4. **Індуктивний викид (Flyback Kick):** Якщо миттєво розімкнути ключ у колі з котушкою ($dt \to 0, \frac{di}{dt} \to -\infty$), на котушці виникне імпульс напруги в сотні або тисячі вольт! Це може пробити транзистор або створити іскру.
   *(Тому паралельно обмоткам реле та електродвигунів завжди ставлять захисний зворотний діод — Flyback diode).*

---

## 4. З'єднання котушок індуктивності

(За відсутності магнітного зв'язку між ними):

* **Послідовне з'єднання:**
  $$L_{\text{eq}} = L_1 + L_2 + \dots + L_n$$
* **Паралельне з'єднання:**
  $$\frac{1}{L_{\text{eq}}} = \frac{1}{L_1} + \frac{1}{L_2} + \dots \implies L_{\text{eq}} = \frac{L_1 \cdot L_2}{L_1 + L_2}$$

## 5. Енергія магнітного поля

Енергія накопичується у магнітному полі навколо витків котушки при протіканні струму:

$$W = \frac{L \cdot I^2}{2}$$

---

## 6. Перехідні процеси: RL-коло та стала часу ($\tau$)

Розглянемо коло з джерела напруги $V_0$, резистора $R$ та котушки $L$:

```
        S (ключ)     R              L
         o__/ o----[   ]----------UUUUUU----+
        |                                   |
       ( ) V0                               |
        |                                   |
        +-----------------------------------+
```

Диференціальне рівняння контуру:
$$V_0 = u_R(t) + u_L(t) = i(t) R + L \frac{di}{dt}$$

### 6.1. Наростання струму при замиканні ключа:
$$i_L(t) = \frac{V_0}{R} \cdot \left(1 - e^{-t/\tau}\right)$$
$$u_L(t) = V_0 \cdot e^{-t/\tau}$$

### 6.2. Стала часу RL-кола:
$$\tau = \frac{L}{R} \quad [\text{Секунди}]$$

```
    iL(t) ^
   V0/R   |              * * * * * (I_max = V0 / R)
          |          *
  0.63*I  |       *
          |     *
          |   *
          +---+----------------------------> t
          0  tau = L/R                   5*tau
```

## 7. Дуальність R, C та L компонентів (Шпаргалка для інженера)

| Властивість | Конденсатор ($C$) | Котушка індуктивності ($L$) |
|---|---|---|
| **Накопичує енергію** | Електричного поля: $\frac{CU^2}{2}$ | Магнітного поля: $\frac{LI^2}{2}$ |
| **Основне рівняння** | $i = C \frac{du}{dt}$ | $u = L \frac{di}{dt}$ |
| **Що не стрибає?** | Напруга: $u_C(0^+) = u_C(0^-)$ | Струм: $i_L(0^+) = i_L(0^-)$ |
| **Режим постійного струму (DC)** | **Розрив кола ($I = 0$)** | **Коротке замикання ($U = 0$)** |
| **Стала часу $\tau$** | $\tau = R \cdot C$ | $\tau = \frac{L}{R}$ |

## 8. Підсумок формул теми 07

| Формула | Опис |
|---|---|
| $\mathcal{E}_{\text{self}} = -L \frac{di}{dt}$ | ЕРС самоіндукції |
| $u_L(t) = L \frac{di}{dt}$ | Напруга на індуктивності |
| $W = \frac{L I^2}{2}$ | Енергія магнітного поля |
| $\tau = \frac{L}{R}$ | Стала часу RL-кола |
| $i_L(t) = \frac{V_0}{R}(1 - e^{-t/\tau})$ | Формула струму в RL-ланці |
