## 1. Фундаментальні фізичні константи та одиниці

| Константа / Величина | Позначення | Значення (СІ) | Одиниця |
|---|---|---|---|
| **Елементарний заряд** | $e$ | $1.602 \times 10^{-19}$ | $\text{Кл}$ (Кулон, $\text{C}$) |
| **Електрична стала** | $\varepsilon_0$ | $8.854 \times 10^{-12}$ | $\text{Ф/м}$ (Фарад на метр) |
| **Магнітна стала** | $\mu_0$ | $4\pi \times 10^{-7} \approx 1.257 \times 10^{-6}$ | $\text{Гн/м}$ (Генрі на метр) |
| **Швидкість світла у вакуумі** | $c$ | $2.998 \times 10^8$ | $\text{м/с}$ |
| **Коефіцієнт Кулона** | $k = \frac{1}{4\pi\varepsilon_0}$ | $8.988 \times 10^9$ | $\text{Н}\cdot\text{м}^2/\text{Кл}^2$ |

## 2. Електростатика та потенціал

| Закон / Поняття | Формула | Примітки |
|---|---|---|
| **Закон Кулона** | $F = \frac{1}{4\pi\varepsilon_0 \varepsilon_r} \frac{\|q_1 q_2\|}{r^2}$ | Сила між точковими зарядами |
| **Напруженість поля** | $\vec{E} = \frac{\vec{F}}{q_0} = -\nabla \varphi$ | В однорідному полі: $E = \frac{U}{d}$ |
| **Електричний потенціал** | $\varphi = \frac{W_p}{q}$ | Енергія одиничного заряду в точці |
| **Напруга (Різниця потенціалів)** | $U_{AB} = \varphi_A - \varphi_B = \frac{A_{A \to B}}{q}$ | Робота поля з переміщення $q$ |

---

## 3. Струм, Опір та Закон Ома

| Закон / Поняття | Формула | Примітки |
|---|---|---|
| **Сила струму** | $I = \frac{dq}{dt}$ | Для постійного струму: $I = \frac{q}{t}$ |
| **Густина струму** | $j = \frac{I}{S} = q \cdot n \cdot v_d$ | $v_d$ — швидкість дрейфу носіїв |
| **Опір провідника** | $R = \rho \frac{l}{S}$ | $\rho$ — питомий опір ($\Omega \cdot \text{м}$) |
| **Провідність** | $G = \frac{1}{R} = \sigma \frac{S}{l}$ | $\sigma = \frac{1}{\rho}$ (Сіменс, $\text{S}$) |
| **Залежність від температури** | $R(T) = R_0 \big(1 + \alpha \Delta T\big)$ | $\alpha$ — ТКО ($1/\text{K}$) |
| **Закон Ома (інтегральний)** | $I = \frac{U}{R} \iff U = I \cdot R$ | Для ділянки кола |
| **Закон Ома (диференціальний)** | $\vec{j} = \sigma \vec{E} = \frac{\vec{E}}{\rho}$ | У точці матеріалу |

## 4. ЕРС, Робота, Потужність і Повне коло

| Закон / Поняття | Формула | Примітки |
|---|---|---|
| **ЕРС джерела** | $\mathcal{E} = \frac{A_{\text{стор}}}{q}$ | Робота сторонніх сил |
| **Закон Ома для повного кола** | $I = \frac{\mathcal{E}}{R + r}$ | $r$ — внутрішній опір джерела |
| **Напруга під навантаженням** | $U = \mathcal{E} - I \cdot r$ | При $I=0 \implies U=\mathcal{E}$ |
| **Струм короткого замикання (КЗ)**| $I_{\text{кз}} = \frac{\mathcal{E}}{r}$ | При $R = 0$ |
| **Електрична потужність** | $P = U \cdot I = I^2 R = \frac{U^2}{R}$ | Виділяється в навантаженні |
| **Закон Джоуля-Ленца** | $Q = I^2 \cdot R \cdot t$ | Теплова енергія |
| **Теорема узгодження навантаження**| $R = r \implies P_{\max} = \frac{\mathcal{E}^2}{4r}$ | ККД при цьому $\eta = 50\%$ |

## 5. З'єднання резисторів та подільники

| Конфігурація | Струм / Напруга | Еквівалентний опір / Формула виходу |
|---|---|---|
| **Послідовне з'єднання** | $I = \text{const}, \quad U_{\Sigma} = \sum U_i$ | $R_{\text{eq}} = R_1 + R_2 + \dots + R_n$ |
| **Паралельне з'єднання** | $U = \text{const}, \quad I_{\Sigma} = \sum I_i$ | $\frac{1}{R_{\text{eq}}} = \sum \frac{1}{R_i} \implies R_{\text{eq}} = \frac{R_1 R_2}{R_1 + R_2}$ |
| **Подільник напруги** | $V_{\text{out}}$ на $R_2$ | $V_{\text{out}} = V_{\text{in}} \cdot \frac{R_2}{R_1 + R_2}$ |
| **Подільник струму** | $I_1$ через $R_1$ | $I_1 = I_{\text{total}} \cdot \frac{R_2}{R_1 + R_2}$ |
| **Міст Уїтстона (Баланс)** | $V_{AB} = 0\text{ В}$ | $\frac{R_1}{R_2} = \frac{R_3}{R_4} \iff R_1 R_4 = R_2 R_3$ |

## 6. Правила Кірхгофа

| Правило | Формула | Фізичний базис | Кількість рівнянь |
|---|---|---|---|
| **1-е правило (KCL)** | $\sum I_{\text{вхідні}} = \sum I_{\text{вихідні}}$ | Збереження заряду | $N - 1$ (для $N$ вузлів) |
| **2-е правило (KVL)** | $\sum \mathcal{E}_k = \sum I_k R_k$ | Збереження енергії | $B - (N - 1)$ (для $B$ гілок) |

## 7. Конденсатори та Котушки індуктивності (Порівняльна таблиця)

| Властивість | Конденсатор ($C$) | Котушка індуктивності ($L$) |
|---|---|---|
| **Одиниця ємності/індуктивності** | Фарад ($\text{Ф}$, $\text{F}$) | Генрі ($\text{Гн}$, $\text{H}$) |
| **Геометрична формула** | $C = \frac{\varepsilon_0 \varepsilon_r S}{d}$ | $L = \mu_0 \mu_r \frac{N^2 S}{l}$ |
| **Основний $i-u$ закон** | $\mathbf{i(t) = C \frac{du(t)}{dt}}$ | $\mathbf{u(t) = L \frac{di(t)}{dt}}$ |
| **Енергія поля** | $W_E = \frac{C U^2}{2}$ (електричне) | $W_M = \frac{L I^2}{2}$ (магнітне) |
| **Закон комутації** | **$u_C(0^+) = u_C(0^-)$** (напруга не стрибає) | **$i_L(0^+) = i_L(0^-)$** (струм не стрибає) |
| **Поведінка на DC ($\frac{d}{dt}=0$)** | **Розрив кола ($I = 0$)** | **Коротке замикання ($U = 0$)** |
| **Послідовне з'єднання** | $\frac{1}{C_{\text{eq}}} = \sum \frac{1}{C_i} \implies \frac{C_1 C_2}{C_1 + C_2}$ | $L_{\text{eq}} = L_1 + L_2 + \dots$ |
| **Паралельне з'єднання** | $C_{\text{eq}} = C_1 + C_2 + \dots$ | $\frac{1}{L_{\text{eq}}} = \sum \frac{1}{L_i} \implies \frac{L_1 L_2}{L_1 + L_2}$ |
| **Стала часу перехідного процесу** | $\mathbf{\tau = R \cdot C}$ [с] | $\mathbf{\tau = \frac{L}{R}}$ [с] |
| **Заряд/наростання від 0 до $V_0$** | $u_C(t) = V_0(1 - e^{-t/\tau})$ | $i_L(t) = \frac{V_0}{R}(1 - e^{-t/\tau})$ |
| **Реактивний опір на змінному струмі** | $\mathbf{X_C = \frac{1}{2\pi f C} = \frac{1}{\omega C}}$ | $\mathbf{X_L = 2\pi f L = \omega L}$ |
| **Зсув фаз ($u$ відносно $i$)** | Струм випереджає на $90^\circ$ ($-90^\circ$) | Напруга випереджає на $+90^\circ$ |

## 8. Змінний струм (AC) та RLC-кола

| Поняття | Формула | Примітки |
|---|---|---|
| **Гармонічний сигнал** | $u(t) = U_m \sin(\omega t + \varphi_0)$ | $U_m$ — пікова амплітуда |
| **Кутова частота** | $\omega = 2\pi f = \frac{2\pi}{T}$ | $\text{рад/с}$ |
| **Діюче значення (RMS)** | $U_{\text{RMS}} = \frac{U_m}{\sqrt{2}} \approx 0.707 U_m$ | Тепловий еквівалент постійного струму |
| **Імпеданс послідовного RLC** | $Z = \sqrt{R^2 + (X_L - X_C)^2}$ | Закон Ома: $I_{\text{RMS}} = \frac{U_{\text{RMS}}}{Z}$ |
| **Фазовий зсув RLC** | $\operatorname{tg}\varphi = \frac{X_L - X_C}{R}$ | Кут між напругою та струмом |
| **Резонанс (Формула Томсона)** | $f_0 = \frac{1}{2\pi\sqrt{LC}} \iff \omega_0 = \frac{1}{\sqrt{LC}}$ | При $X_L = X_C \implies Z_{\min} = R, I = \max$ |

## 9. Правила схемотехніка та вимірювання

1. **Вольтметр:** Включається **паралельно**, $R_V \to \infty$ (не споживає струм).
2. **Амперметр:** Включається **послідовно**, $R_A \to 0$ (не створює спаду напруги).
3. **Опорний потенціал (GND):** $\varphi_{\text{GND}} = 0\text{ В}$. Будь-яка напруга в точці $V_A = \varphi_A - \varphi_{\text{GND}}$.
4. **Підсилювач напруги:** Вхідний опір $R_{\text{in}} \to \infty$, вихідний опір $R_{\text{out}} \to 0$.
5. **Теорема Тевеніна:** Будь-яке лінійне коло $\equiv$ джерело $V_{\text{th}}$ + послідовний $R_{\text{th}}$.
6. **Правило $5\tau$:** Перехідний процес зарядки/розрядки вважається повністю завершеним через час $t = 5\tau$ ($99.3\%$).
