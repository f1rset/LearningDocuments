## 1. Що таке конденсатор і електрична ємність ($C$)?

**Конденсатор** — це пасивний електронний компонент, здатний накопичувати електричний заряд та енергію електричного поля. Він складається з двох провідних обкладок, розділених шаром діелектрика (ізолятора).

### Означення електричної ємності ($C$)
Ємність характеризує здатність провідника накопичувати заряд на одиницю прикладеної напруги:

$$C = \frac{q}{U}$$

* **Одиниця вимірювання в СІ:** **Фарад ($\text{Ф}$, $\text{F}$)**. $1\text{ Ф} = 1\text{ Кл} / 1\text{ В}$.
* На практиці $1\text{ Ф}$ — гігантська величина, тому використовують:
  * мікрофаради ($\mu\text{F} = 10^{-6}\text{ Ф}$),
  * нанофаради ($\text{nF} = 10^{-9}\text{ Ф}$),
  * пікофаради ($\text{pF} = 10^{-12}\text{ Ф}$).

### Ємність плоского конденсатора:
$$C = \frac{\varepsilon_0 \varepsilon_r S}{d}$$
* $S$ — площа пластини ($\text{м}^2$),
* $d$ — відстань між пластинами ($\text{м}$),
* $\varepsilon_r$ — відносна діелектрична проникність діелектрика між пластинами (кераміка, слюда, оксидна плівка тощо).

## 2. Диференціальне рівняння конденсатора ($i-u$ характеристика)

Оскільки $q(t) = C \cdot u(t)$, візьмемо похідну за часом від обох частин:

$$i(t) = \frac{dq}{dt} = C \cdot \frac{du(t)}{dt}$$

### ⚠️ Головні висновки для схемотехніка:
1. **Струм через конденсатор тече ТІЛЬКИ тоді, коли напруга змінюється ($\frac{du}{dt} \neq 0$).**
2. **Постійний струм (DC, $\frac{du}{dt} = 0$):** Конденсатор діє як **ідеальний розрив кола ($I = 0$)**. Він блокує постійну складову (DC-blocking).
3. **Перший закон комутації:** **Напруга на конденсаторі не може змінитися миттєво!**
   $$u_C(0^+) = u_C(0^-)$$
   *(Миттєвий стрибок напруги за $dt = 0$ вимагав би нескінченно великого струму $i = C \frac{\Delta U}{0} \to \infty$, що фізично неможливо).*

## 3. З'єднання конденсаторів

> **Зверніть увагу:** Формули для конденсаторів дзеркально протилежні до формул резисторів!

### 3.1. Паралельне з'єднання (площі пластин додаються):
$$C_{\text{eq}} = C_1 + C_2 + \dots + C_n$$

### 3.2. Послідовне з'єднання:
$$\frac{1}{C_{\text{eq}}} = \frac{1}{C_1} + \frac{1}{C_2} + \dots + \frac{1}{C_n} \implies C_{\text{eq}} = \frac{C_1 \cdot C_2}{C_1 + C_2} \quad \text{(для двох)}$$

---

## 4. Енергія зарядженого конденсатора

Енергія накопичується у вигляді електричного поля між пластинами:

$$W = \frac{C \cdot U^2}{2} = \frac{q \cdot U}{2} = \frac{q^2}{2C}$$

## 5. Перехідні процеси: RC-коло та стала часу ($\tau$)

Розглянемо послідовне коло з резистора $R$ та конденсатора $C$, підключене до джерела постійної напруги $V_0$:

```
        S (ключ)     R
         o__/ o----[   ]----+
        |                   |
       ( ) V0             ===== C   -> Uc(t)
        |                   |
        +-------------------+
```

За 2-м правилом Кірхгофа:
$$V_0 = u_R(t) + u_C(t) = i(t) R + u_C(t) = R C \frac{du_C}{dt} + u_C(t)$$

Розв'язок цього диференціального рівняння визначає процес зарядки:

### 5.1. Заряджання конденсатора:
$$u_C(t) = V_0 \cdot \left(1 - e^{-t/\tau}\right)$$
$$i(t) = \frac{V_0}{R} \cdot e^{-t/\tau}$$

### 5.2. Розряджання зарядженого конденсатора через опір $R$:
$$u_C(t) = V_0 \cdot e^{-t/\tau}$$

```
   Uc(t) ^
     V0  |              * * * * * (100% = V0)
         |          *
   0.63* |       *
         |     *
         |   *
         +---+----------------------------> t
         0  tau = RC                     5*tau
```

### 5.3. Стала часу кола ($\tau$ — тау):
$$\tau = R \cdot C \quad [\text{Секунди}]$$

* За час **$t = 1\tau$** конденсатор заряджається до **$63.2\%$** від $V_0$ ($1 - e^{-1} \approx 0.632$).
* За час **$t = 3\tau$** — до **$95.0\%$**.
* За час **$t = 5\tau$** — до **$99.3\%$** (в інженерній практиці вважається, що перехідний процес повністю завершився і настав стаціонарний стан).

### 5.4. Частота зрізу простого RC-фільтра:
$$f_c = \frac{1}{2\pi R C}$$

## 6. Підсумок формул теми 06

| Формула | Опис |
|---|---|
| $C = \frac{q}{U} = \frac{\varepsilon_0 \varepsilon_r S}{d}$ | Ємність конденсатора |
| $i(t) = C \frac{du}{dt}$ | Струм через конденсатор |
