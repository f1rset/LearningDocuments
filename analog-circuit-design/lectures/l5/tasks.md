## 🎯 Мета та інженерні орієнтири
Цей збірник містить **10 розрахункових інженерних завдань**, які охоплюють повний спектр розрахунку підсилювачів зі зворотним зв'язком (ЗЗ) та каскодних схем: від складання матриці провідностей $[Y]$ до знаходження петльового підсилення $T$ та перевірки запасу стійкості за фазою.

---

## 🧭 Методичні вказівки до розв'язання
1. **Робоча смуга середніх частот:** Вважати, що всі розділові та блокувальні конденсатори мають нульовий опір ($X_C \approx 0$), а джерело постійної напруги живлення $+E_ж$ по AC є землею (GND).
2. **Макромодель BJT ($h$-параметри):** вхідний опір $h_{11} = r_{be}$, кероване джерело струму колектора $i_c = h_{21} i_b = \frac{h_{21}}{h_{11}} u_{be} = g_m u_{be}$.
3. **Макромодель JFET ($S$-параметри):** струм стоку $i_d = S \cdot u_{gs}$ (де $S = g_m$ — крутизна), вхідний опір затвора $R_{gs} \to \infty$.
4. **Матричний метод $[Y]$:** $[Y] \cdot [U] = [I]$. Параметри чотириполюсника:
   $$K_U = \frac{\Delta_{12}}{\Delta_{11}}, \quad R_{\text{вх}} = \frac{\Delta_{11}}{\Delta}, \quad R_{\text{вих}} = \left. \frac{\Delta_{22}}{\Delta} \right|_{G_н = 0}$$

#### Завдання 1: Біполярний каскодний підсилювач СЕ-СБ (BJT-BJT)
Каскодна конфігурація на двох біполярних транзисторах $VT_1$ (спільний емітер) та $VT_2$ (спільна база) усуває ефект Міллера і забезпечує широку смугу пропускання.

```text
               +E_ж (+15 В)
                 │
                 ├───[ R_c: 2 кОм ]───┬─────────┤├───► U_вих
                 │                    │        C_out
                 │                 ┌──┴──┐
                 │                 │ VT2 │ BJT (СБ)
            [ R1 ]                 └──┬──┘
                 │       C_b          │
                 ├───────┤├───┐       │
                 │            │       │
            [ R2 ]           ─┴─   ┌──┴──┐
                 │           GND   │ VT1 │ BJT (СЕ)
  U_вх ───┤├───┬─┴─────────────────┤     │
          C_in │                   └──┬──┘
              [R_b]                   │
               │                     ─┴─ GND
              ─┴─ GND
```

* **Вихідні дані:**
  * Транзистори $VT_1, VT_2$: $h_{11} = 1.0\ \text{k}\Omega$, $h_{21} = 100$, $h_{22} \approx 0$.
  * Пасивні елементи: $R_b = 50\ \text{k}\Omega$, $R_c = 2.0\ \text{k}\Omega$, опір навантаження $R_н = 10\ \text{k}\Omega$.
* **Завдання:**
  1. Побудувати малосигнальну еквівалентну схему по AC та пронумерувати вузли.
  2. Записати матрицю провідностей $[Y]$.
  3. Розрахувати коефіцієнт підсилення напруги $K_U$ та вхідний опір $R_{\text{вх}}$.

#### Завдання 2: Каскодний підсилювач СВ-СЗ на польових транзисторах (JFET-JFET)
Повністю польовий каскод забезпечує гігаомний вхідний опір на низьких частотах та високу лінійність.

```text
               +E_ж (+20 В)
                 │
                 ├───[ R_d: 3.3 кОм ]──┬────────┤├───► U_вих
                 │                     │
                 │                  ┌──┴──┐
                 │                  │ VT2 │ JFET (СЗ)
                 ├───[ R1 ]─┬───────┤     │
                 │          │       └──┬──┘
                 │         [R2]        │
                 │          │          │
                 │         ─┴─ GND  ┌──┴──┐
  U_вх ───┤├───┬─┴──────────────────┤ VT1 │ JFET (СВ)
               │                    └──┬──┘
             [R_g: 1 МОм]              │
               │                      ─┴─ GND
              ─┴─ GND
```

* **Вихідні дані:**
  * Польові транзистори $VT_1, VT_2$: крутизна $S_1 = S_2 = 4.0\ \text{mA/V}$, вихідний диференційний опір $r_{ds} \to \infty$.
  * Навантаження $R_d = 3.3\ \text{k}\Omega$, опір затвора $R_g = 1.0\ \text{M}\Omega$, $R_н = 10\ \text{k}\Omega$.
* **Завдання:**
  1. Скласти матрицю $[Y]$ для змінного струму.
  2. Вивести аналітичну формулу для коефіцієнта підсилення $K_U$.
  3. Обчислити числове значення $K_U$ та $R_{\text{вх}}$.

#### Завдання 3: Каскад СЕ з емітерною дегенерацією (послідовний НЗЗ за струмом)
Введення неблокованого конденсатором резистора $R_e$ створює стабілізуючий негативний зворотний зв'язок.

```text
               +E_ж
                 │
                 ├───[ R_c: 3.0 кОм ]──┬────────┤├───► U_вих
                 │                     │
                 │                  ┌──┴──┐
  U_вх ───┤├───┬─┴──────────────────┤ VT1 │ BJT (СЕ)
               │                    └──┬──┘
             [R_b: 20 кОм]             │
               │                    ┌──┴──┐
              ─┴─ GND               │ R_e │ 150 Ом (без конденсатора C_e!)
                                    └──┬──┘
                                       │
                                      ─┴─ GND
```

* **Вихідні дані:** $h_{11} = 1.2\ \text{k}\Omega$, $h_{21} = 80$, $R_b = 20\ \text{k}\Omega$, $R_c = 3.0\ \text{k}\Omega$, $R_e = 150\ \Omega$, $R_н = 6.0\ \text{k}\Omega$.
* **Завдання:**
  1. Скласти вузлову матрицю схеми з урахуванням напруги на емітері $U_e \neq 0$.
  2. Знайти точний коефіцієнт підсилення $K_U$ матричним методом.
  3. Порівняти результат з інженерним наближенням $K_U \approx -\frac{R_c \parallel R_н}{R_e}$ та оцінити похибку формули.

#### Завдання 4: Двокаскадний підсилювач із паралельним НЗЗ за напругою
Зворотний зв'язок реалізовано резистором $R_{\text{зз}}$, увімкненим між виходом другого каскаду та входом першого.

```text
               +E_ж
                 │
                 ├──[ R_c1 ]───┬─────────├──[ R_c2 ]───┬───────► U_вих
                 │             │         │             │
                 │          ┌──┴──┐      │          ┌──┴──┐
                 │          │ VT1 │      │          │ VT2 │
                 │          └──┬──┘      │          └──┬──┘
                 │             │         │             │
                 │            ─┴─ GND    │            ─┴─ GND
  U_вх ───┤├───┬─┴───────────────────────┼─────────────┘
               │                         │
               └───[ R_зз: 100 кОм ]─────┘
```

* **Вихідні дані:**
  * $VT_1$: $h_{11}^{(1)} = 1.5\ \text{k}\Omega$, $h_{21}^{(1)} = 100$, $R_{c1} = 4.7\ \text{k}\Omega$.
  * $VT_2$: $h_{11}^{(2)} = 1.0\ \text{k}\Omega$, $h_{21}^{(2)} = 120$, $R_{c2} = 2.2\ \text{k}\Omega$.
  * Резистор петлі ЗЗ: $R_{\text{зз}} = 100\ \text{k}\Omega$, опір джерела $R_{\text{дж}} = 10\ \text{k}\Omega$, $R_н = 10\ \text{k}\Omega$.
* **Завдання:**
  1. Записати систему рівнянь за методом вузлових напруг.
  2. Сформувати матрицю $[Y]$ розміром $3 \times 3$.
  3. Розрахувати коефіцієнт передачі напруги $K_U = U_{\text{вих}} / U_{\text{вх}}$ та вхідний опір $R_{\text{вх}}$.

#### Завдання 5: Емітерний повторювач (каскад СК, 100% НЗЗ за напругою)
Каскад зі спільним колектором як граничний випадок послідовного зворотного зв'язку за напругою ($\chi = 1$).

```text
               +E_ж
                 │
                 ├─────────────────────┐
                 │                  ┌──┴──┐
  U_вх ───┤├───┬─┴──────────────────┤ VT1 │ BJT (СК)
               │                    └──┬──┘
             [R_b: 100 кОм]            │
               │                       ├───┤├───► U_вих
              ─┴─ GND               ┌──┴──┐
                                    │ R_e │ 1.0 кОм
                                    └──┬──┘
                                       │
                                      ─┴─ GND
```

* **Вихідні дані:** $h_{11} = 1.5\ \text{k}\Omega$, $h_{21} = 150$, $R_b = 100\ \text{k}\Omega$, $R_e = 1.0\ \text{k}\Omega$, $R_н = 2.0\ \text{k}\Omega$. Опір джерела $R_{\text{дж}} = 5.0\ \text{k}\Omega$.
* **Завдання:**
  1. Скласти матрицю провідностей $[Y]$ для схеми СК.

  3. Розрахувати вихідний опір $R_{\text{вих}}$ з урахуванням опору генератора $R_{\text{дж}}$.

#### Завдання 6: Вплив скінченного вихідного опору $r_{ds}$ на параметри каскоду СВ-СБ
У реальних транзисторах вихідний диференційний опір $r_{ds} = 1/g_{ds}$ є скінченним і шунтує вихідний струм першого транзистора.

* **Вихідні дані:**
  * $VT_1$ (JFET, СВ): $S = 3.5\ \text{mA/V}$, вихідний опір каналу $r_{ds1} = 40\ \text{k}\Omega$.
  * $VT_2$ (BJT, СБ): $h_{11} = 800\ \Omega$, $h_{21} = 100$, $h_{22} = 20\ \mu\text{S}$ ($r_o = 50\ \text{k}\Omega$).
  * Резистор колектора $R_c = 4.0\ \text{k}\Omega$, навантаження $R_н = 20\ \text{k}\Omega$.
* **Завдання:**
  1. Додати провідності $g_{ds1} = 1/r_{ds1}$ та $h_{22}$ у відповідні комірки матриці $[Y]$.
  2. Обчислити точний детермінант $\Delta$ та доповнення $\Delta_{12}$.
  3. Визначити, на скільки відсотків зменшився коефіцієнт підсилення $K_U$ через скінченність $r_{ds1}$ порівняно з ідеальним випадком ($r_{ds1} \to \infty$).

#### Завдання 7: Каскодний підсилювач із парою Дарлінгтона у верхньому плечі
Для зменшення вхідної провідності каскаду СБ та збільшення вихідного опору замість одинарного $VT_2$ застосовано складений транзистор $VT_2 + VT_3$.

```text
               +E_ж
                 │
                 ├───[ R_c: 5.0 кОм ]──┬────────┤├───► U_вих
                 │                     │
                 │                  ┌──┴──┐ VT3
                 │               ┌──┤     │
                 │               │  └──┬──┘
                 │       C_b   ┌─┴─┐   │
                 ├───────┤├───┤ VT2│   │
                 │             └─┬─┘   │
                 │               └─────┴─┐
                 │                       │
                 │                    ┌──┴──┐
  U_вх ───┤├───┬─┴────────────────────┤ VT1 │ JFET (СВ)
               │                      └──┬──┘
             [R_g: 1 МОм]                │
               │                        ─┴─ GND
              ─┴─ GND
```

* **Вихідні дані:**
  * $VT_1$ (JFET): $S = 5.0\ \text{mA/V}$.
  * $VT_2, VT_3$ (BJT): $h_{11(2)} = 2.0\ \text{k}\Omega$, $h_{21(2)} = 80$; $h_{11(3)} = 500\ \Omega$, $h_{21(3)} = 80$.

* **Завдання:**
  1. Знайти еквівалентні малосигнальні параметри пари Дарлінгтона ($h_{11\text{экв}}, h_{21\text{экв}}$).

#### Завдання 8: Каскодний підсилювач з активним динамічним навантаженням
Заміна резистора $R_c$ на транзисторне джерело стабільного струму на базі струмового дзеркала PNP різко збільшує еквівалентний опір навантаження $R_{\text{дин}}$.

```text
               +E_ж (+12 В)
                 │
            ┌────┴────┐
          ┌─┴─┐     ┌─┴─┐
          │   │ Q4  │   │ Q3 (Активне навантаження, PNP дзеркало)
          └─┬─┘     └─┬─┘
            ├───┬─────┤
            │   │     ├────────┤├───► U_вих (R_н = 100 кОм)
          ┌─┴─┐ │     │
          │R_0│ │  ┌──┴──┐
          └─┬─┘ │  │ VT2 │ BJT (СБ)
            │   │  └──┬──┘
           ─┴─ ─┴─    │
```

#### Завдання 9: Двокаскадний підсилювач із послідовним НЗЗ за напругою
Зворотний зв'язок знімається з виходу другого каскаду і подається через подільник $R_f, R_1$ в емітер першого транзистора.

```text
               +E_ж
                 │
                 ├──[ R_c1 ]───┬─────────├──[ R_c2 ]───┬───────► U_вих
                 │             │         │             │
                 │          ┌──┴──┐      │          ┌──┴──┐
  U_вх ───┤├───┬─┴──────────┤ VT1 │      │          │ VT2 │
               │            └──┬──┘      │          └──┬──┘
             [R_b]             │         │             │
               │               ├─────────┼──[ R_f ]────┘
              ─┴─ GND       ┌──┴──┐      │
                            │ R_1 │     ─┴─ GND
                            └──┬──┘
                               │
                              ─┴─ GND
```

* **Вихідні дані:**
  * Коефіцієнт підсилення прямого тракту без ЗЗ: $K_0 = -800$.
  * Резистори ланки зворотного зв'язку: $R_f = 18\ \text{k}\Omega$, $R_1 = 2.0\ \text{k}\Omega$.
* **Завдання:**
  1. Знайти коефіцієнт передачі ланки зворотного зв'язку $\chi = \frac{R_1}{R_1 + R_f}$.
  2. Розрахувати петльове підсилення $T = K_0 \cdot \chi$ та глибину зворотного зв'язку $F = 1 + T$.
  3. Обчислити точний коефіцієнт підсилення схеми $K_{\text{нзз}}$ за формулою Блека та зіставити з асимптотичним значенням $1/\chi$.
  4. Визначити, на скільки відсотків зменшаться нелінійні спотворення (THD) підсилювача.

#### Завдання 10: Комплексний аналіз стійкості та частотна корекція підсилювача
Підсилювач із розімкненим підсиленням на DC $A_0 = 10^4$ ($80$ дБ) має три дійсні полюси на частотах: $f_{p1} = 100\ \text{kHz}$, $f_{p2} = 2.0\ \text{MHz}$, $f_{p3} = 20\ \text{MHz}$. До схеми підключається частотно-незалежний НЗЗ із коефіцієнтом $\chi = 0.02$.

* **Завдання:**
  1. Записати вираз для комплексної передавальної функції петльового підсилення $T(jf) = \chi \cdot A(jf)$.
  2. Обчислити частоту $f_{180}$, на якій фазовий зсув підсилювача досягає $-180^\circ$:
     $$\arg(T(jf_{180})) = - \left( \text{arctg}\frac{f_{180}}{f_{p1}} + \text{arctg}\frac{f_{180}}{f_{p2}} + \text{arctg}\frac{f_{180}}{f_{p3}} \right) = -180^\circ$$
  3. Перевірити запас стійкості за амплітудою ($\text{Gain Margin}, GM$) та за фазою ($\text{Phase Margin}, PM$).
  4. Чи буде схема стійкою? Якщо ні, запропонувати ємність коригуючого конденсатора Міллера $C_C$ для забезпечення $\text{PM} \ge 45^\circ$.

## 💡 Опорні формули та інженерні підказки

* **До задачі 1 (Каскод СЕ-СБ):**  
  Вхідний опір каскаду СБ дуже малий: $R_{\text{вх(СБ)}} \approx \frac{h_{11(2)}}{h_{21(2)} + 1} \approx \frac{1000}{101} \approx 9.9\ \Omega$.  
  Тому перший транзистор $VT_1$ працює практично в режимі короткого замикання по колектору ($K_{U1} \approx -1$), що повністю ліквідує динамічне множення ємності колектора (ефект Міллера). Загальне підсилення формується каскадом СБ: $K_U \approx -g_{m1} (R_c \parallel R_н)$.
* **До задачі 3 (Емітерна дегенерація):**  
  Вхідний опір бази зростає в $(1 + \beta)$ разів відносно $R_e$:
  $$R_{\text{вх.бази}} = h_{11} + (h_{21} + 1) R_e$$
* **До задачі 5 (Емітерний повторювач):**  
  Вихідний опір СК навантажений паралельно на емітер:
  $$R_{\text{вих}} = R_e \parallel \left( \frac{h_{11} + R_{\text{дж}} \parallel R_b}{h_{21} + 1} \right)$$
* **До задачі 9 (Формула Блека):**  
  При $K_0 \chi \gg 1$: $K_{\text{нзз}} \approx \frac{1}{\chi} = 1 + \frac{R_f}{R_1}$. Нелінійні спотворення зменшуються строго в $F = 1 + K_0 \chi$ разів.
