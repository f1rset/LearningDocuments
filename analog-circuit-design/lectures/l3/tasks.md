## 🎯 Мета та інженерні орієнтири
Цей збірник містить **10 розрахункових інженерних завдань**, які охоплюють ключові схемотехнічні топології дискретних підсилювачів на біполярних (BJT) та польових (JFET) транзисторах:
* Каскади зі спільним емітером (СЕ) та спільним витоком (СВ) — розрахунок $K_U$, $R_{\text{вх}}$, $R_{\text{вих}}$.
* Каскади з частковим емітерним розв'язанням ($R_{e1}$) для лінеаризації передачі.
* Емітерні (СК) та витокові (СС) повторювачі як низькоомні буфери.
* Каскади зі спільною базою (СБ) та спільним затвором (СЗ) для високочастотного узгодження.
* Багатокаскадні схеми та подолання ефектів навантаження (Loading Effect).

## 🧭 Методичні вказівки до розв'язання
1. **Малосигнальні параметри BJT:**
   $$g_m = \frac{I_{C0}}{V_T}, \quad r_e \approx \frac{1}{g_m} = \frac{V_T}{I_{E0}}, \quad r_\pi = \frac{\beta}{g_m} = (\beta + 1)r_e \quad (V_T = 26\ \text{мВ})$$
2. **Спільний Емітер (СЕ):**
   $$K_U = -\frac{R_c \parallel R_н}{r_e + R_{e1}}, \quad R_{\text{вх}} = R_b \parallel \left[ (\beta + 1)(r_e + R_{e1}) \right], \quad R_{\text{вих}} = R_c \parallel r_o$$
3. **Спільний Колектор (СК / Повторювач):**
   $$K_U = \frac{R_e \parallel R_н}{r_e + (R_e \parallel R_н)} \approx 1, \quad R_{\text{вх}} = R_b \parallel \left[ (\beta + 1)(r_e + R_e \parallel R_н) \right], \quad R_{\text{вих}} = R_e \parallel \left( r_e + \frac{R_b \parallel R_{\text{дж}}}{\beta + 1} \right)$$
4. **Спільна База (СБ):**
   $$K_U = +\frac{R_c \parallel R_н}{r_e}, \quad R_{\text{вх}} \approx r_e \parallel R_e \approx r_e, \quad R_{\text{вих}} \approx R_c$$
5. **Польові транзистори (JFET):**
   $$g_m = \frac{2 \sqrt{I_{DSS} I_D}}{|V_p|}, \quad K_{U(\text{СВ})} = -g_m (R_d \parallel R_н), \quad K_{U(\text{СС})} = \frac{g_m (R_s \parallel R_н)}{1 + g_m (R_s \parallel R_н)}$$

### 🔹 Рівень 1: Базовий розрахунок каскадів на BJT

#### Завдання 1: Класичний підсилювальний каскад зі спільним емітером (СЕ)
Каскад попереднього підсилювача на кремнієвому транзисторі працює в точці спокою зі струмом колектора $I_{C0} = 2.0\ \text{мА}$. Емітерний резистор повністю зашунтований конденсатором великої ємності $C_e$ ($X_{Ce} \approx 0$).

```text
               +V_CC (+12 В)
                 │
                 ├───[ R_c: 2.7 кОм ]───┬─────────┤├───► U_вих
                 │                      │        C_out
                 │                   ┌──┴──┐
            [ R1 ]                   │ VT1 │ BJT (β = 180)
                 │                   └──┬──┘
   U_вх ───┤├───┼───────────────────────┤
           C_in  │                      ├───[ R_e ]───┬────┐
            [ R2 ]                      │            ─┴─  ─┴─ GND
                 │                     ─┴─ C_e       GND
                ─┴─ GND                GND
```

* **Вихідні дані:**
  * $I_{C0} = 2.0\ \text{мА}$, $\beta = 180$, $V_T = 26\ \text{мВ}$, $r_o \to \infty$.
  * Пасивні елементи: $R_c = 2.7\ \text{к}\Omega$, еквівалентний опір дільника $R_b = R_1 \parallel R_2 = 20\ \text{к}\Omega$.
  * Навантаження: $R_н = 10\ \text{к}\Omega$.
* **Завдання:**
  1. Розрахувати параметри $g_m, r_e, r_\pi$.
  2. Знайти коефіцієнт підсилення за напругою на холостому ході $K_U^{xx}$ та під навантаженням $K_U$.
  3. Розрахувати вхідний опір каскаду $R_{\text{вх}}$ та вихідний опір $R_{\text{вих}}$.
* 💡 **Підказка:** $R_{c\text{екв}} = R_c \parallel R_н = \frac{2.7 \times 10}{2.7 + 10} \approx 2.126\ \text{к}\Omega$.

---

#### Завдання 2: Каскад СЕ з частковим емітерним розв'язанням ($R_{e1} + R_{e2}$)
Для стабілізації коефіцієнта підсилення та зниження нелінійних спотворень частину емітерного резистора $R_{e1} = 100\ \Omega$ залишено незашунтованою конденсатором $C_e$.

* **Вихідні дані:**
  * $I_{C0} = 1.0\ \text{мА}$, $\beta = 120$, $V_T = 26\ \text{мВ}$.
  * $R_c = 3.9\ \text{к}\Omega$, $R_{e1} = 100\ \Omega$, $R_н = 15\ \text{к}\Omega$, $R_b = 25\ \text{к}\Omega$.
* **Завдання:**
  1. Розрахувати малосигнальний опір емітера $r_e$.
  2. Знайти коефіцієнт підсилення $K_U$ з урахуванням $R_{e1}$.
  3. Оцінити, на скільки відсотків зміниться коефіцієнт підсилення $|K_U|$, якщо внаслідок нагрівання крутизна транзистора $g_m$ збільшиться на $20\%$. Порівняти цей результат із каскадом без $R_{e1}$.
* 💡 **Підказка:** Без $R_{e1}$: $K_U \approx -g_m R_L$ (зміна підсилення прямо пропорційна $g_m$). З $R_{e1}$: $K_U = -\frac{R_L}{r_e + R_{e1}}$.

---

#### Завдання 3: Розрахунок емітерного повторювача (СК) під низькоомним навантаженням
Вихідний буферний каскад навантажений на лінійний кабель з опором $R_н = 50\ \Omega$. Джерело сигналу має внутрішній опір $R_{\text{дж}} = 2.0\ \text{к}\Omega$.

```text
               +V_CC (+12 В)
                 │
                 ├───[ R1 ]─────────────┬─────────────┐
                 │                      │             │
                 │                      │          ┌──┴──┐
                 │                      │          │ VT1 │ BJT (β = 150)
                 │                      ├──────────┤     │
                 │                      │          └──┬──┘
   U_ген ──[R_дж]──┤├───┼───────────────┘             ├───┤├───► U_вих
           (2 кОм) C_in │                             │   C_out
                       [ R2 ]                        [R_e: 1 кОм]  [R_н: 50 Ом]
                        │                             │             │
                       ─┴─ GND                       ─┴─ GND       ─┴─ GND
```

* **Вихідні дані:**
  * Струм спокою емітера: $I_{E0} = 5.0\ \text{мА}$, $\beta = 150$, $V_T = 26\ \text{мВ}$.
  * $R_e = 1.0\ \text{к}\Omega$, $R_н = 50\ \Omega$, $R_b = R_1 \parallel R_2 = 30\ \text{к}\Omega$, $R_{\text{дж}} = 2.0\ \text{к}\Omega$.
* **Завдання:**
  1. Розрахувати опір $r_e$ та еквівалентний опір навантаження по змінному струму $R_{L} = R_e \parallel R_н$.
  2. Знайти коефіцієнт передачі напруги під навантаженням $K_U = \frac{U_{\text{вих}}}{U_{\text{вх}}}$.
  3. Обчислити вхідний опір каскаду $R_{\text{вх}}$ та вихідний опір каскаду $R_{\text{вих}}$.
* 💡 **Підказка:** $R_{\text{вих}} = R_e \parallel \left( r_e + \frac{R_b \parallel R_{\text{дж}}}{\beta + 1} \right)$.

#### Завдання 4: Каскад зі спільною базою (СБ) для високочастотного тракту 50 Ом
Для підсилення сигналу від 50-омної антени використовується каскад зі спільною базою, що має низький вхідний опір і відсутність паразитного ефекту Міллера.

```text
               +V_CC (+12 В)
                 │
                 ├───[ R_c: 1.5 кОм ]───┬─────────┤├───► U_вих
                 │                      │        C_out
                 │                   ┌──┴──┐
                 │       C_b         │ VT1 │ BJT (СБ)
                 ├───────┤├───┐      └──┬──┘
                 │            │         │
                 │           ─┴─ GND    ├───────┤├───◄ U_вх (R_дж = 50 Ом)
            [ R1, R2 ]                  │       C_in
                 │                     [R_e: 1.0 кОм]
                ─┴─ GND                 │
                                       ─┴─ GND
```

* **Вихідні дані:**
  * Режим за постійним струмом: $I_{E0} = 2.6\ \text{мА}$, $\beta = 100$, $V_T = 26\ \text{мВ}$.
  * Пасивні елементи: $R_c = 1.5\ \text{к}\Omega$, $R_e = 1.0\ \text{к}\Omega$, навантаження $R_н = 2.0\ \text{к}\Omega$.
* **Завдання:**
  1. Розрахувати малосигнальний опір емітера $r_e$.
  2. Знайти вхідний опір каскаду $R_{\text{вх}} = r_e \parallel R_e$. Чи узгоджений каскад із 50-омним фідером антени?
  3. Знайти коефіцієнт підсилення напруги $K_U = \frac{U_{\text{вих}}}{U_{\text{вх}}}$ та фазовий зсув сигналу.
* 💡 **Підказка:** У схемі СБ вхідний сигнал подається в емітер, а вихід знімається з колектора. Фазовий зсув $\Delta \varphi = 0^\circ$.

#### Завдання 5: Підсилювальний каскад зі спільним витоком (СВ) на JFET
Вхідний каскад вимірювального приладу реалізовано на польовому транзисторі для забезпечення вхідного опору не менше $1\ \text{МОм}$.

* **Вихідні дані:**
  * JFET: початковий струм $I_{DSS} = 10.0\ \text{мА}$, напруга відсічки $V_p = -4.0\ \text{В}$.
  * Режим спокою: струм стоку $I_{D0} = 2.5\ \text{мА}$.
  * Резистори схеми: опір стоку $R_d = 3.3\ \text{к}\Omega$, опір затвора $R_g = 1.0\ \text{М}\Omega$.
  * Опір навантаження: $R_н = 10.0\ \text{к}\Omega$.
* **Завдання:**
  1. Розрахувати крутизну транзистора $g_m$ у робочій точці.
  2. Визначити еквівалентний опір навантаження стоку $R_{d\text{екв}} = R_d \parallel R_н$.
  3. Обчислити коефіцієнт підсилення напруги $K_U$ та вхідний опір $R_{\text{вх}}$.
* 💡 **Підказка:** $g_m = \frac{2 \sqrt{I_{DSS} I_{D0}}}{|V_p|}$. Підсилення $K_U = -g_m R_{d\text{екв}}$.

---

#### Завдання 6: Витоковий повторювач (СС) на польовому транзисторі
Буферний каскад на JFET використовується для узгодження п'єзоелектричного давача з кабелем.

* **Вихідні дані:**
  * JFET: $I_{DSS} = 8.0\ \text{мА}$, $V_p = -2.0\ \text{В}$, струм спокою $I_{D0} = 2.0\ \text{мА}$.
  * Резистор витоку: $R_s = 2.2\ \text{к}\Omega$, опір затвора: $R_g = 10.0\ \text{М}\Omega$.
  * Навантаження: $R_н = 1.0\ \text{к}\Omega$.
* **Завдання:**
  1. Розрахувати крутизну $g_m$ транзистора.
  2. Знайти еквівалентний опір у витоку $R_{s\text{екв}} = R_s \parallel R_н$.
  3. Обчислити коефіцієнт передачі $K_U$ та вихідний опір $R_{\text{вих}} \approx R_s \parallel \frac{1}{g_m}$.
* 💡 **Підказка:** $K_U = \frac{g_m R_{s\text{екв}}}{1 + g_m R_{s\text{екв}}}$.

#### Завдання 7: Каскад СЕ на PNP транзисторі
Підсилювач побудовано на PNP транзисторі за схемою зі спільним емітером при живленні від позитивної шини $+V_{CC} = 12.0\ \text{В}$.

* **Вихідні дані:**
  * Струм спокою: $I_{C0} = 1.2\ \text{мА}$, $\beta = 160$, $V_T = 26\ \text{мВ}$.
  * Опір колектора: $R_c = 4.7\ \text{к}\Omega$, опір навантаження: $R_н = 10.0\ \text{к}\Omega$.
  * Базовий дільник: $R_1 = 68\ \text{к}\Omega$ (до $+V_{CC}$), $R_2 = 22\ \text{к}\Omega$ (до землі).
  * Емітерний резистор повністю зашунтований конденсатором $C_e$.
* **Завдання:**
  1. Розрахувати крутизну $g_m$ та вхідний опір транзистора $r_\pi$.
  2. Знайти повний вхідний опір каскаду $R_{\text{вх}} = R_1 \parallel R_2 \parallel r_\pi$.
  3. Обчислити коефіцієнт підсилення напруги $K_U$.
* 💡 **Підказка:** Малосигнальний розрахунок PNP транзистора повністю ідентичний NPN, змінюється лише напрямок постійних струмів зміщення.

#### Завдання 8: Двокаскадний підсилювач напруги (СЕ-СЕ)
Підсилювач складається з двох однакових послідовно з'єднаних каскадів СЕ з ємнісним зв'язком ($C_c$).

```text
   U_ген ──[R_дж]──►┌─────────────┐       ┌─────────────┐
                    │  Каскад 1   ├───┤├──┤  Каскад 2   ├───► U_вих
                    │ (СЕ: Ku1)   │   Cc  │ (СЕ: Ku2)   │     │
                    └─────────────┘       └─────────────┘    [R_н]
```

* **Вихідні дані:**
  * Каскад 1: підсилення XX $K_{U1}^{xx} = -100$, $R_{\text{вх1}} = 2.5\ \text{к}\Omega$, $R_{\text{вих1}} = 3.0\ \text{к}\Omega$.
  * Каскад 2: підсилення XX $K_{U2}^{xx} = -80$, $R_{\text{вх2}} = 2.0\ \text{к}\Omega$, $R_{\text{вих2}} = 2.0\ \text{к}\Omega$.
  * Джерело сигналу: $R_{\text{дж}} = 600\ \Omega$.
  * Навантаження: $R_н = 5.0\ \text{к}\Omega$.
* **Завдання:**
  1. Розрахувати фактичне підсилення другого каскаду з урахуванням навантаження $R_н$.
  2. Розрахувати фактичне підсилення першого каскаду з урахуванням навантаження на вхідний опір другого каскаду $R_{\text{вх2}}$.
  3. Знайти наскрізний коефіцієнт передачі напруги усієї системи $K_{U\text{(sys)}} = \frac{U_{\text{вих}}}{U_{\text{ген}}}$ та визначити сумарний фазовий зсув на середніх частотах.
* 💡 **Підказка:** Два інвертуючі каскади ($180^\circ + 180^\circ$) дають результуючий синфазний сигнал ($360^\circ \equiv 0^\circ$).

#### Завдання 9: Високочастотний каскад із спільним затвором (СЗ)
Каскад зі спільним затвором використовується як вхідний підсилювач радіоприймача на частоті $10\ \text{МГц}$.

* **Вихідні дані:**
  * Крутизна JFET: $g_m = 4.0\ \text{мА/В}$.
  * Опір стокового навантаження: $R_d = 4.7\ \text{к}\Omega$.
  * Резистор витоку (для DC bias): $R_s = 1.5\ \text{к}\Omega$.
  * Навантаження наступного тракту: $R_н = 10.0\ \text{к}\Omega$.
* **Завдання:**
  1. Обчислити вхідний опір каскаду $R_{\text{вх}} = R_s \parallel \frac{1}{g_m}$.
  2. Розрахувати коефіцієнт підсилення напруги $K_U = \frac{U_{\text{вих}}}{U_{\text{вх}}}$.
  3. Пояснити, чому каскад СЗ не страждає від ефекту Міллера.
* 💡 **Підказка:** У схемі СЗ затвор заземлений, тому прохідна ємність сток-затвор $C_{gd}$ увімкнена паралельно виходу і не створює негативного зворотного зв'язку зі входом.

#### Завдання 10: Інженерний вибір топології: Однокаскадний СЕ проти каскаду СЕ-СК
Необхідно підсилити слабкий сигнал електродинамічного мікрофона з внутрішнім опором $R_{\text{дж}} = 200\ \Omega$ та амплітудою $U_{\text{сиг}} = 2.0\ \text{мВ}$ до рівня лінійного входу аудіоінтерфейсу ($U_{\text{вих}} \ge 200\ \text{мВ}$, тобто потрібне підсилення $|K_{U\text{(sys)}}| \ge 100$). Вхідний опір лінійного входу $R_н = 1.0\ \text{к}\Omega$.

* **Вихідні дані:**
  * $R_{\text{дж}} = 200\ \Omega$, $R_н = 1.0\ \text{к}\Omega$.
  * Доступний транзистор з $I_{C0} = 2.0\ \text{мА}$, $\beta = 150$, $R_c = 3.0\ \text{к}\Omega$, $R_b = 20\ \text{к}\Omega$.
* **Завдання:**
  1. Розрахувати наскрізне підсилення при використанні лише одного каскаду СЕ безпосередньо на навантаження $1.0\ \text{к}\Omega$. Чи виконується вимога $|K_{U\text{(sys)}}| \ge 100$?
  2. Додати вихідний буферний каскад СК (емітерний повторювач) зі струмом $I_{E2} = 5.0\ \text{мА}$ та повторити розрахунок.
  3. Сформулювати інженерне обґрунтування застосування структури СЕ-СК.
* 💡 **Підказка:** Для СЕ каскаду: $R_{c\text{екв}} = 3.0\ \text{к}\Omega \parallel 1.0\ \text{к}\Omega = 750\ \Omega$. Крутизна $g_m = 76.9\ \text{мА/В}$.
