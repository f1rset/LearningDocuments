# 🧮 Приклад розв'язання задачі: Малосигнальний розрахунок двокаскадного підсилювача СЕ-СК (Common Emitter + Emitter Follower)

> **Курс:** Аналогова схемотехніка  
> **Тема:** Лекція 3. Базові підсилювальні каскади на BJT та FET

## 🎯 Мета та інженерні задачі практикуму
1. Опанувати методику малосигнального аналізу в смузі середніх частот (Midband AC Analysis) для базових підсилювальних каскадів зі **Спільним Емітером (СЕ)** та **Спільним Колектором (СК / Емітерний повторювач)**.
2. Розрахувати вхідні та вихідні опори ($R_{\text{вх}}, R_{\text{вих}}$) і коефіцієнти підсилення ($K_U$) кожного окремого каскаду з урахуванням ефектів навантаження (Loading Effect).
3. Дослідити вплив часткового емітерного розв'язання (незашунтованого резистора $R_{e1}$) на стабільність підсилення та вхідний опір каскаду СЕ.
4. Продемонструвати інженерну необхідність застосування буферного каскаду (СК) при роботі на низькоомне навантаження ($R_н = 600\ \Omega$).

---

## 1. Постановка задачі та принципова схема

Розглядається двокаскадний транзисторний підсилювач звукового діапазону. Перший каскад реалізовано на транзисторі $VT_1$ за схемою СЕ з частковим емітерним зворотним зв'язком ($R_{e1} + R_{e2}$), другий каскад — на транзисторі $VT_2$ за схемою емітерного повторювача (СК) для узгодження з лінійним навантаженням $R_н = 600\ \Omega$.

```text
                     +V_CC (+15 В)
                       │
             ┌─────────┼─────────────────────────┬──────────────┐
             │         │                         │              │
            [R1]      [R_c1]                    [R3]            │
             │         │                         │           ┌──┴──┐
             ├─────────┼──────────┐              ├───────────┤ VT2 │ (СК)
             │      ┌──┴──┐       │              │           └──┬──┘
   U_вх ──┤├──┤     │ VT1 │ (СЕ)  └───┤├───┬─────┤              ├───┤├───► U_вих
   (R_дж) C_in      └──┬──┘           C_c  │    [R4]            │   C_out
             │         ├───[ R_e1 ]──┐    ─┴─    │             [R_e2]     [R_н: 600 Ом]
            [R2]       │             │    GND   ─┴─             │          │
             │        [R_e2]         │          GND            ─┴─        ─┴─ GND
            ─┴─        │            ─┴─ C_e                    GND
            GND       ─┴─ GND       GND
```

### Вихідні дані:
* Напруга живлення: $V_{CC} = 15.0\ \text{В}$.
* Опір джерела сигналу: $R_{\text{дж}} = 1.0\ \text{к}\Omega$.
* Опір навантаження: $R_н = 600\ \Omega$.
* **Параметри Каскаду 1 ($VT_1$ — СЕ):**
  * Струм спокою колектора: $I_{C1} = 1.5\ \text{мА}$.
  * Резистори: $R_{c1} = 3.9\ \text{к}\Omega$, $R_{e1} = 47\ \Omega$ (не зашунтований), $R_{e2} = 1.2\ \text{к}\Omega$ (зашунтований конденсатором $C_e$).
  * Дільник бази: $R_1 = 82\ \text{к}\Omega$, $R_2 = 18\ \text{к}\Omega$.
  * Транзистор $VT_1$: $\beta_1 = 150$, $V_T = 26\ \text{мВ}$, $r_{o1} \approx 60\ \text{к}\Omega$.
* **Параметри Каскаду 2 ($VT_2$ — СК / Емітерний повторювач):**
  * Струм спокою емітера: $I_{E2} = 4.0\ \text{мА}$.
  * Резистор емітера: $R_{e3} = 1.5\ \text{к}\Omega$.
  * Дільник бази: $R_3 = 47\ \text{к}\Omega$, $R_4 = 47\ \text{к}\Omega$.
  * Транзистор $VT_2$: $\beta_2 = 120$, $V_T = 26\ \text{мВ}$, $r_{o2} \approx 30\ \text{к}\Omega$.

---

## 2. Розрахунок малосигнальних параметрів транзисторів

### 2.1. Транзистор $VT_1$ (Каскад СЕ):
1. Крутизна:
   $$g_{m1} = \frac{I_{C1}}{V_T} = \frac{1.5\ \text{мА}}{26\ \text{мВ}} \approx \mathbf{57.69\ \text{мА/В}} = 0.0577\ \text{S}$$
2. Внутрішній динамічний опір емітера:
   $$r_{e1} = \frac{V_T}{I_{E1}} \approx \frac{1}{g_{m1}} = \frac{26\ \text{мВ}}{1.5\ \text{мА}} \approx \mathbf{17.33\ \Omega}$$
3. Вхідний диференційний опір бази:
   $$r_{\pi1} = \frac{\beta_1}{g_{m1}} = 150 \times 17.33\ \Omega \approx \mathbf{2600\ \Omega} = 2.6\ \text{к}\Omega$$

### 2.2. Транзистор $VT_2$ (Каскад СК):
1. Динамічний опір емітера:
   $$r_{e2} = \frac{V_T}{I_{E2}} = \frac{26\ \text{мВ}}{4.0\ \text{мА}} = \mathbf{6.50\ \Omega}$$
2. Вхідний диференційний опір бази:
   $$r_{\pi2} = (\beta_2 + 1) r_{e2} = 121 \times 6.5\ \Omega \approx \mathbf{786.5\ \Omega}$$

---

## 3. Малосигнальний аналіз Каскаду 2 (Спільний Колектор / Повторювач)

Каскад 2 навантажений безпосередньо на зовнішнє навантаження $R_н = 600\ \Omega$.  
Аналіз проводиться у зворотному напрямку (від виходу до входу), щоб визначити вхідний опір $R_{\text{вх2}}$, який служить навантаженням для Каскаду 1.

```text
               Вхід 2 (База VT2)
                       │
                      ┌┴┐
                      │ │ r_π2 (786.5 Ом)
                      └┬┘
                       │
              ─────────────────── Емітер VT2
                       │
           ┌───────────┼───────────┐
          ┌┴┐         ┌┴┐         ┌┴┐
     r_o2 │ │    R_e3 │ │     R_н │ │ (600 Ом)
  (30 кОм)│ │(1.5 кОм)│ │         │ │
          └┬┘         └┬┘         └┬┘
           │           │           │
          ─┴───────────┴───────────┴─ GND
```

### 3.1. Еквівалентний опір навантаження в емітері по AC:
$$R_{L2} = R_{e3} \parallel R_н = 1500\ \Omega \parallel 600\ \Omega = \frac{1500 \times 600}{1500 + 600} = \frac{900000}{2100} \approx \mathbf{428.57\ \Omega}$$

### 3.2. Вхідний опір транзистора $VT_2$ з боку бази:
Згідно з правилом відбиття опорів (Impedance Reflection Rule), опір кола емітера трансформується в базу, помножений на $(\beta_2 + 1)$:
$$R_{\text{вх(base2)}} = r_{\pi2} + (\beta_2 + 1) R_{L2} = 786.5\ \Omega + 121 \times 428.57\ \Omega = 786.5 + 51857 \approx \mathbf{52.64\ \text{к}\Omega}$$

### 3.3. Повний вхідний опір Каскаду 2 ($R_{\text{вх2}}$):
Опір бази шунтується паралельно резисторами базового дільника:
$$R_{b2} = R_3 \parallel R_4 = 47\ \text{к}\Omega \parallel 47\ \text{к}\Omega = 23.5\ \text{к}\Omega$$
$$R_{\text{вх2}} = R_{b2} \parallel R_{\text{вх(base2)}} = \frac{23.5\ \text{к}\Omega \times 52.64\ \text{к}\Omega}{23.5 + 52.64} = \frac{1237}{76.14} \approx \mathbf{16.25\ \text{к}\Omega}$$

### 3.4. Коефіцієнт передачі напруги другого каскаду під навантаженням ($K_{U2}$):
$$K_{U2} = \frac{U_{\text{вих}}}{U_{\text{вх2}}} = \frac{R_{L2}}{r_{e2} + R_{L2}} = \frac{428.57\ \Omega}{6.50\ \Omega + 428.57\ \Omega} = \frac{428.57}{435.07} \approx \mathbf{+0.985} \quad (-0.13\ \text{дБ})$$

### 3.5. Вихідний опір повторювача ($R_{\text{вих}}$ каскаду 2):
Вихідний опір залежить від еквівалентного опору джерела, яким для нього є вихідний опір першого каскаду $R_{\text{вих1}}$ у паралель з дільником $R_{b2}$:
$$R_{\text{дж2}} = R_{\text{вих1}} \parallel R_{b2} \approx R_{c1} \parallel R_{b2} = 3.9\ \text{к}\Omega \parallel 23.5\ \text{к}\Omega \approx 3.34\ \text{к}\Omega$$
$$R_{\text{вих(tot)}} = R_{e3} \parallel \left( r_{e2} + \frac{R_{\text{дж2}}}{\beta_2 + 1} \right) = 1500\ \Omega \parallel \left( 6.5\ \Omega + \frac{3340\ \Omega}{121} \right) = 1500 \parallel (6.5 + 27.6) = 1500 \parallel 34.1\ \Omega \approx \mathbf{33.3\ \Omega}$$
> 💡 **Коментар:** Низький вихідний опір ($33.3\ \Omega$) дозволяє каскаду керувати навантаженням $600\ \Omega$ практично без просідання напруги.

---

## 4. Малосигнальний аналіз Каскаду 1 (Спільний Емітер з частковим $R_{e1}$)

Конденсатор $C_e$ замикає на землю резистор $R_{e2} = 1.2\ \text{к}\Omega$, тому на змінному струмі в емітері діє лише малий опір місцевого зворотного зв'язку $R_{e1} = 47\ \Omega$.

### 4.1. Еквівалентне навантаження колектора $VT_1$:
Навантаженням для колектора $VT_1$ є паралельне з'єднання власного резистора $R_{c1}$, вихідного опору транзистора $r_{o1}$ та вхідного опору наступного каскаду $R_{\text{вх2}}$:
$$R_{L1} = R_{c1} \parallel r_{o1} \parallel R_{\text{вх2}}$$
$$R_{c1} \parallel r_{o1} = 3.9\ \text{к}\Omega \parallel 60\ \text{к}\Omega = \frac{3.9 \times 60}{63.9} \approx 3.66\ \text{к}\Omega$$
$$R_{L1} = 3.66\ \text{к}\Omega \parallel 16.25\ \text{к}\Omega = \frac{3.66 \times 16.25}{3.66 + 16.25} = \frac{59.47}{19.91} \approx \mathbf{2.987\ \text{к}\Omega}$$

### 4.2. Коефіцієнт підсилення напруги першого каскаду ($K_{U1}$):
Завдяки незашунтованому $R_{e1}$, загальний емітерний опір по AC становить $r_{e1} + R_{e1}$:
$$K_{U1} = \frac{U_{\text{вих1}}}{U_{\text{вх1}}} = -\frac{R_{L1}}{r_{e1} + R_{e1}} = -\frac{2987\ \Omega}{17.33\ \Omega + 47.0\ \Omega} = -\frac{2987}{64.33} \approx \mathbf{-46.43} \quad (33.34\ \text{дБ})$$
*(Знак «мінус» позначає інверсію фази на $180^\circ$)*.

### 4.3. Вхідний опір першого каскаду ($R_{\text{вх1}}$):
Динамічний опір бази з урахуванням емітерного резистора:
$$R_{\text{вх(base1)}} = (\beta_1 + 1)(r_{e1} + R_{e1}) = 151 \times (17.33 + 47.0) = 151 \times 64.33\ \Omega \approx 9.71\ \text{к}\Omega$$
Опір базового дільника:
$$R_{b1} = R_1 \parallel R_2 = 82\ \text{к}\Omega \parallel 18\ \text{к}\Omega = \frac{82 \times 18}{82 + 18} = \frac{1476}{100} = 14.76\ \text{к}\Omega$$
Повний вхідний опір підсилювача:
$$R_{\text{вх(tot)}} = R_{b1} \parallel R_{\text{вх(base1)}} = 14.76\ \text{к}\Omega \parallel 9.71\ \text{к}\Omega = \frac{14.76 \times 9.71}{14.76 + 9.71} = \frac{143.3}{24.47} \approx \mathbf{5.86\ \text{к}\Omega}$$

---

## 5. Розрахунок наскрізних характеристик двокаскадного тракту

### 5.1. Послаблення сигналу на вході (дільник $R_{\text{дж}} - R_{\text{вх}}$):
$$K_{\text{вх}} = \frac{U_{\text{вх1}}}{U_{\text{ген}}} = \frac{R_{\text{вх(tot)}}}{R_{\text{вх(tot)}} + R_{\text{дж}}} = \frac{5.86\ \text{к}\Omega}{5.86\ \text{к}\Omega + 1.0\ \text{к}\Omega} = \frac{5.86}{6.86} \approx \mathbf{0.854} \quad (-1.37\ \text{дБ})$$

### 5.2. Наскрізний коефіцієнт підсилення напруги ($K_{U\text{(sys)}}$):
$$K_{U\text{(sys)}} = \frac{U_{\text{вих}}}{U_{\text{ген}}} = K_{\text{вх}} \cdot K_{U1} \cdot K_{U2} = 0.854 \times (-46.43) \times 0.985 \approx \mathbf{-39.06}$$
У децибелах:
$$|K_{U\text{(sys)}}|_{\text{дБ}} = 20 \lg(39.06) \approx \mathbf{31.83\ \text{дБ}}$$

---

## 6. Демонстрація ефекту навантаження: Що буде без каскаду СК?

Припустимо, ми виключили каскад СК і підключили навантаження $R_н = 600\ \Omega$ безпосередньо до колектора $VT_1$:
1. Новий еквівалентний опір колектора $VT_1$:
   $$R_{L1}' = R_{c1} \parallel r_{o1} \parallel R_н = 3.66\ \text{к}\Omega \parallel 600\ \Omega = \frac{3660 \times 600}{3660 + 600} = \frac{2196000}{4260} \approx \mathbf{515.5\ \Omega}$$
2. Підсилення каскаду СЕ:
   $$K_{U1}' = -\frac{R_{L1}'}{r_{e1} + R_{e1}} = -\frac{515.5\ \Omega}{64.33\ \Omega} \approx \mathbf{-8.01}$$
3. Спад підсилення:
   $$\frac{|K_{U1}|}{|K_{U1}'|} = \frac{46.43}{8.01} \approx \mathbf{5.8\ \text{разів}} \quad (\text{втрата } \mathbf{15.27\ \text{дБ}}!)$$

> ⚠️ **Ключовий висновок:** Пряме підключення низькоомного навантаження до каскаду СЕ призводить до катастрофічного обвалу коефіцієнта підсилення майже в 6 разів. Використання емітерного повторювача (СК) повністю нівелює ефект навантаження, забезпечуючи високу амплітуду вихідного сигналу.
