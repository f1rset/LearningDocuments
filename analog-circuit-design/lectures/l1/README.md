## 🎯 Мета та ключові питання лекції
1. **Двополюсники та чотириполюсники:** Лінійні та нелінійні компоненти, імпеданс ($Z$) та адміттанс ($Y$).
2. **Біполярні транзистори (BJT):** Будова (NPN / PNP), фізичний механізм роботи, ВАХ та області функціонування (відсічка, активний режим, насичення).
3. **Малосигнальні макромоделі BJT:** Еквівалентні схеми для низьких/робочих частот (НЧ/РЧ) та високих частот (ВЧ) з урахуванням паразитарних параметрів.
4. **Польові транзистори (FET / JFET):** Класифікація, принцип керування каналом через $pn$-перехід, напруга відсічки ($V_p$), ВАХ та малосигнальні моделі.

## 1. Базові поняття: Двополюсники, чотириполюсники, лінійність

### 1.1. Двополюсні компоненти (One-Port / Two-Terminal)
Будь-який елемент електричного кола, який має два виводи (полюси), називається **двополюсником**.

```text
       i(t) --->
    o---[ Двополюсник ]---o
    |                     |
    +-------- u(t) -------+
```

* **Лінійні двополюсники ($R, L, C$):** Параметри не залежать від величини напруги чи струму.
  * Резистор: $u(t) = R \cdot i(t)$
  * Котушка індуктивності: $u(t) = L \cdot \frac{di(t)}{dt}$
  * Конденсатор: $i(t) = C \cdot \frac{du(t)}{dt}$
* **Нелінійні двополюсники (напівпровідникові діоди, стабілітрони, варикапи):** ВАХ не є прямою лінією, диференційний опір $r_{\text{диф}} = \frac{du}{di}$ залежить від робочої точки.

### 1.2. Імпеданс ($Z$) та Адміттанс ($Y$)
Для гармонічних сигналів у комплексній формі:
* **Комплексний опір (Імпеданс):** $Z(j\omega) = \frac{\dot{U}}{\dot{I}} = R(\omega) + j X(\omega)$
* **Комплексна провідність (Адміттанс):** $Y(j\omega) = \frac{1}{Z(j\omega)} = \frac{\dot{I}}{\dot{U}} = G(\omega) + j B(\omega)$
  * $G$ — активна провідність (кондуктанс),
  * $B$ — реактивна провідність (сусцептанс).

### 1.3. Поняття чотириполюсника (Two-Port Network)
Система, що має дві пари затискачів: **вхідні** (1–1') та **вихідні** (2–2').

```text
        i1 --->                             ---> i2
    1 o-------+-----------------------------+-------o 2
              |                             |
      u1      |       Чотириполюсник        |      u2
              |                             |
   1' o-------+-----------------------------+-------o 2'
```

* **Приклади:** Резистивні дільники напруги, фільтри, підсилювачі, узгоджувальні трансформатори.
* **Резистивний дільник як чотириполюсник:**
  $K_u = \frac{u_2}{u_1} = \frac{R_2}{R_1 + R_2}$

## 2. Біполярні транзистори (BJT: Bipolar Junction Transistor)

### 2.1. Фізична структура та принцип дії
Біполярний транзистор складається з трьох напівпровідникових шарів із чергуванням типів провідності: **$n\text{-}p\text{-}n$** або **$p\text{-}n\text{-}p$**.

```text
             NPN Транзистор                       PNP Транзистор
             
             Колектор (C)                          Колектор (C)
                 |                                     |
              +--+--+                               +--+--+
              |  n  |                               |  p  |
              +-----+                               +-----+
   База (B) --|  p  | (Тонка, слабколегована)База (B) --|  n  |
              +-----+                               +-----+
              |  n+ | (Сильнолегована)              |  p+ |
              +--+--+                               +--+--+
                 |                                     |
             Емітер (E)                            Емітер (E)
```

> **💡 Інтуїція ("на пальцях"):**
> Біполярний транзистор — це **струмовий кран**. Маленький струм, який ми вливаємо в Базу ($I_B$), відкриває "ворота" і дозволяє великому струму текти від Колектора до Емітера ($I_C = \beta \cdot I_B$).

#### Ключові фізичні особливості:
1. **Нерівномірність легування:** Емітер легований набагато сильніше за базу ($n^+ \gg p$). Це забезпечує високий коефіцієнт інжекції носіїв з емітера в базу.
2. **Тонка база:** Товщина бази $W_b$ значно менша за дифузійну довжину пробігу електронів ($W_b \ll L_n$), тому майже всі інжектовані електрони ($98-99\%$) не встигають рекомбінувати в базі й захоплюються прискорювальним полем колекторного переходу.

### 2.2. Режими роботи та вольт-амперні характеристики (ВАХ)

| Режим роботи | Емітерний перехід ($EB$) | Колекторний перехід ($CB$) | Стан транзистора та застосування |
|---|---|---|---|
| **Відсічка (Cut-off)** | Зворотний ($U_{BE} < 0.6\text{V}$) | Зворотний ($U_{CB} > 0$) | Транзистор закритий, $I_C \approx 0$ (ключ розімкнений) |
| **Активний лінійний** | **Прямий** ($U_{BE} \approx 0.6\dots 0.7\text{V}$) | **Зворотний** ($U_{CE} > U_{BE}$) | **Основний підсилювальний режим**, $I_C = \beta I_B$ |
| **Насичення (Saturation)**| Прямий ($U_{BE} \approx 0.7\text{V}$) | Прямий ($U_{CB} < 0$) | Транзистор повністю відкритий, $U_{CE,\text{sat}} \approx 0.1\dots 0.2\text{V}$ (ключ замкнений) |
| **Інверсний** | Зворотний | Прямий | Підсилення вкрай низьке ($\beta_{\text{inv}} \approx 1\dots 5$), використовується рідко |

```text
   Вихідна ВАХ BJT (Ic від Uce):
   
   Ic ^
      |           /-------------------  IB3 (найбільший)
      |  Наси-   /--------------------  IB2
      |  чення  /---------------------  IB1
      |  |     /
      |  |    /   АКТИВНА ОБЛАСТЬ (підсилення)
      |  |   /
      +--+--+------------------------> Uce
      |   Область відсічки (IB = 0)
```

## 3. Малосигнальні макромоделі біполярного транзистора

Для розрахунку коефіцієнтів підсилення ($K_u, K_i$), вхідного та вихідного опорів у лінійному режимі нелінійний транзистор замінюють лінійною еквівалентною схемою (гібридна $\pi$-модель).

### 3.1. Модель для низьких та робочих частот (НЧ / РЧ)

```text
         B o-------[ r_pi ]-------+------------------o C
                   |      |       |
                   +--v_be-+      |
                                  |
                                ( | ) g_m * v_be    [ r_o ]
                                ( v )                 |
                                  |                   |
         E o----------------------+-------------------+--o E
```

#### Параметри моделі:
* **Крутизна характеристики ($g_m$ — transconductance):**
  $g_m = \frac{dI_C}{dU_{BE}} = \frac{I_C}{V_T} \approx \frac{I_C}{25\text{ mV}} \quad \text{при } T = 300\text{ K}$
* **Вхідний диференційний опір бази ($r_\pi$ або $r_{be}$):**
  $r_\pi = \frac{\beta}{g_m} = \frac{\beta \cdot V_T}{I_C}$
* **Вихідний опір за рахунок ефекту Ерлі ($r_o$ або $r_{ce}$):**
  $r_o = \frac{V_A + U_{CE}}{I_C} \approx \frac{V_A}{I_C}$
  *(де $V_A$ — напруга Ерлі, зазвичай $50\dots 150\text{ В}$).*

---

### 3.2. Високочастотна макромодель BJT (ВЧ)
На високих частотах проявляються бар'єрні та дифузійні паразитарні ємності $p\text{-}n$ переходів та опір тіла бази.

```text
                     +-------------[ C_mu ]------------+
                     |                                 |
         B o---[ r_bb' ]---+-------[ r_pi ]--------+---+---o C
                           |       |      |        |   |
                           |       +--v_be+        |  [ro]
                         [C_pi]                  ( | ) |
                           |                     ( v )g_m*v_be
                           |                       |   |
         E o---------------+-----------------------+---+---o E
```

* **$r_{bb'}$:** Об'ємний розподілений опір матеріалу бази ($20\dots 100\ \Omega$).
* **$C_\pi$ ($C_{be}$):** Ємність емітерного переходу (сума дифузійної ємності $C_{\text{diff}} \propto I_C$ та бар'єрної ємності $C_{j,e}$). Типово: $1\dots 50\text{ пФ}$.
* **$C_\mu$ ($C_{bc}$):** Бар'єрна ємність колекторного переходу (відповідає за **ефект Міллера** на ВЧ). Типово: $0.1\dots 5\text{ пФ}$.
* **Гранична частота передачі струму ($f_T$):** Частота, на якій $\beta(f) = 1$:
  $f_T = \frac{g_m}{2\pi (C_\pi + C_\mu)}$

## 4. Польові транзистори (FET: Field-Effect Transistors)

### 4.1. Класифікація польових транзисторів

```text
                         Польові транзистори (FET)
                                     |
         +---------------------------+---------------------------+
         |                                                       |
    З керуючим p-n переходом                              З ізольованим затвором
          (JFET)                                                 (MOSFET / МОН)
         |      |                                                |            |
     n-канал  p-канал                          З вбудованим каналом   З індукованим каналом
                                                    (Depletion)            (Enhancement)
                                                   |           |           |           |
                                                n-канал     p-канал     n-канал     p-канал
```

### 4.2. Польовий транзистор із керуючим $p\text{-}n$-переходом (JFET)

#### Виводи JFET:
* **Затвор (Gate, З):** Керуючий електрод.
* **Витік (Source, В):** Електрод, з якого носії входять у провідний канал.
* **Стік (Drain, С):** Електрод, через який носії виходять із каналу.

```text
                  n-канальний JFET
                     Стік (Drain)
                          |
                       +--+--+
                       |  n  |
           Затвор (p) -| [ ] |- Затвор (p)
           (Gate)      |  n  | (Збіднена область під зворотною напругою)
                       +--+--+
                          |
                     Витік (Source)
```

> **💡 Інтуїція ("на пальцях"):**
> JFET — це **водопровідний шланг**, на який наступають ногою. Провідний канал (шланг) звужується під дією зворотної напруги на затворі $U_{GS}$, що перекриває потік носіїв. Оскільки $p\text{-}n$ перехід затвора зміщений **у зворотний бік**, вхідний струм практично дорівнює нулю ($I_G \approx 0$), а вхідний опір колосальний ($R_{\text{in}} \sim 10^9\dots 10^{12}\ \Omega$).

### 4.3. ВАХ та області роботи JFET

```text
   Вихідна ВАХ JFET (Id від Uds):
   
   Id ^
  Idss|            /-------------------  Ugs = 0V
      |   Крута   /--------------------  Ugs = -1V
      |   область/---------------------  Ugs = -2V
      |  (омічна)/
      |         /  ОБЛАСТЬ НАСИЧЕННЯ (Пінч-оф / Підсилення)
      +--------+------------------------> Uds
      0      Uds,sat = |Ugs - Vp|
```

1. **Крута (омічна / тріодна) область ($U_{DS} < U_{DS,\text{sat}}$):**
   Канал веде себе як резистор, опір якого регулюється напругою затвора $U_{GS}$ (керований напругою резистор).
2. **Область насичення / відсічки каналу (Pinch-off / Полога ділянка):**
   Канал біля стоку перекривається. Струм $I_D$ перестає залежати від напруги $U_{DS}$ і визначається виключно напругою $U_{GS}$ за **формулою Шоклі**:
   $I_D = I_{DSS} \left(1 - \frac{U_{GS}}{V_p}\right)^2$
   * $I_{DSS}$ — струм стоку при $U_{GS} = 0\text{ В}$,
   * $V_p$ ($U_{\text{зрізу}}$) — напруга відсічки (Pinch-off voltage).
3. **Крутизна характеристики JFET:**
   $g_m = \frac{dI_D}{dU_{GS}} = \frac{2 I_{DSS}}{|V_p|} \left(1 - \frac{U_{GS}}{V_p}\right) = g_{m0} \left(1 - \frac{U_{GS}}{V_p}\right)$

## 5. Малосигнальні макромоделі JFET

### 5.1. Модель JFET на низьких частотах (НЧ / РЧ)

```text
         G o          +-------------------------o D
                      |                         |
                      |                         |
                      +---- ( | ) g_m * v_gs   [ r_ds ]
                            ( v )               |
                              |                 |
         S o------------------+-----------------+o S
```
* Вхідний опір з боку затвора $R_{\text{in}} \to \infty$ (розрив кола на НЧ).
* $r_{ds} = \frac{\Delta U_{DS}}{\Delta I_D}$ — внутрішній диференційний вихідний опір каналу ($20\dots 100\text{ к}\Omega$).

### 5.2. Високочастотна модель JFET (ВЧ)

```text
                     +-------------[ C_gd ]------------+
                     |                                 |
         G o---------+-------[ C_gs ]-------+----------+---o D
                     |                      |          |
                     |                      |         [rds]
                     +-- v_gs --+         ( | ) g_m*v_gs
                                |         ( v )        |
                                |           |          |
         S o--------------------+-----------+----------+---o S
```
* $C_{gs}$ — міжелектродна ємність затвор-витік ($1\dots 5\text{ пФ}$).
* $C_{gd}$ — міжелектродна ємність затвор-стік (прохідна ємність Міллера, $0.5\dots 3\text{ пФ}$).

## 6. Порівняння BJT та JFET (Головне для розробника)

| Критерій | Біполярний транзистор (BJT) | Польовий транзистор (JFET) |
|---|---|---|
| **Тип керування** | **Струмом:** $I_C = \beta \cdot I_B$ | **Напругою:** $I_D = f(U_{GS})$ |
| **Вхідний опір ($R_{\text{in}}$)** | Низький / середній ($1\dots 10\text{ к}\Omega$) | **Колосальний ($10^9\dots 10^{12}\ \Omega$)** |
| **Крутизна ($g_m$)** | **Дуже висока** ($g_m \approx 40\cdot I_C$, $\sim 40\text{ мСм/мА}$) | Нижча ($g_m \sim 1\dots 10\text{ мСм/мА}$) |
| **Власний шум на НЧ** | Вищий (шум рекомбінації носіїв) | **Дуже низький** (ідеальний для високоомних датчиків) |
| **Термостабільність** | Потребує схемної термокомпенсації ($U_{BE}$ падає на $-2\text{ мВ/}^\circ\text{C}$) | Вища природна термостабільність |

## 7. ⚠️ Підводні камені та типові помилки початківців

1. **Плутанина між насиченням BJT та JFET:**
   * У **BJT** насичення — це режим ключа, коли напруга $U_{CE} \approx 0\text{ В}$, транзистор повністю відкритий і **не підсилює**.
   * У **JFET** область насичення — це якраз **робоча лінійна підсилювальна зона**, де струм стоку стабілізувався (перекрито канал)!
2. **Пряме зміщення затвора JFET:**
   * Якщо на затвор $n$-канального JFET подати $U_{GS} > +0.6\text{ В}$, $pn$-перехід відкриється, струм затвора різко зросте, і транзистор втратить свої високі вхідні властивості або згорить.
3. **Нехтування ємністю Міллера ($C_\mu$ / $C_{gd}$):**
   * В інвертуючих підсилювачах динамічна вхідна ємність збільшується в $(1 + |K_u|)$ разів: $C_{\text{in, Miller}} = C_\mu (1 + |K_u|)$, що різко обмежує смугу пропускання на високих частотах.

| Параметр / Закон | Формула | Схемотехнічне значення |
|---|---|---|
| **Крутизна BJT** | $g_m = \frac{I_C}{V_T} \approx \frac{I_C}{25\text{ мВ}}$ | Визначає підсилення каскаду: $K_u \approx -g_m R_C$ |
| **Вхідний опір BJT** | $r_\pi = \frac{\beta}{g_m}$ | Диференційний опір бази в точці спокою |

| **Гранична частота BJT** | $f_T = \frac{g_m}{2\pi(C_\pi + C_\mu)}$ | Частота одиничного підсилення за струмом |
