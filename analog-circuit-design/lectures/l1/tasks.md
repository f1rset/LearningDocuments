## 🎯 Мета та інженерні орієнтири
Цей збірник містить **10 розрахункових інженерних завдань**, які охоплюють ключові аспекти аналізу малосигнальних моделей напівпровідникових компонентів та пасивних/активних чотириполюсників:
* Розрахунок диференційних опорів діодів та $pn$-переходів.
* Обчислення малосигнальних параметрів моделі Гібріда-$\pi$ (BJT) та моделі Шоклі (JFET).
* Врахування вторинних ефектів (ефект Ерлі $V_A$, паразитна ємність переходів $C_\pi, C_\mu$).
* Матричні моделі чотириполюсників ($h$-, $z$-, $y$-параметри) та узгодження трактів передачі.

## 🧭 Методичні вказівки до розв'язання
1. **Термічний потенціал ($V_T$):** При кімнатній температурі ($T = 300\ \text{K}$) термічний потенціал $V_T = \frac{k T}{q} \approx 25.85\dots 26.0\ \text{мВ}$. Якщо в умові не вказано інше, використовуйте $V_T = 26\ \text{мВ}$.
2. **Крутизна BJT ($g_m$):** $g_m = \frac{I_{C0}}{V_T}$. Опір емітера: $r_e = \frac{V_T}{I_{E0}} \approx \frac{1}{g_m}$.
3. **Вхідний опір бази:** $r_\pi = \frac{\beta}{g_m} = (\beta + 1) r_e$.
4. **Крутизна JFET ($S = g_m$):** За формулою Шоклі $I_D = I_{DSS}\left(1 - \frac{V_{GS}}{V_p}\right)^2 \implies g_m = \frac{2 I_{DSS}}{|V_p|}\left(1 - \frac{V_{GS}}{V_p}\right) = \frac{2 \sqrt{I_{DSS} \cdot I_D}}{|V_p|}$.
5. **Гранична частота передачі струму ($f_T$):** $f_T = \frac{g_m}{2\pi (C_\pi + C_\mu)}$.

### 🔹 Рівень 1: Базовий розрахунок параметрів компонентів

#### Завдання 1: Диференційний опір випрямного діода
Через кремнієвий діод у прямому напрямку протікає постійний струм спокою $I_{D0} = 2.5\ \text{мА}$. Коефіцієнт неідеальності переходу $\eta = 1.0$, термічний потенціал $V_T = 26\ \text{мВ}$.

```text
       I_D (mA)
          ▲           /
          │          /  <- Робоча точка Q (2.5 мА, 0.68 В)
          │         /│
   I_D0 ──┼────────* │
          │        │ │    Диференційний опір r_d = ΔU / ΔI
          │        │ │
          └────────┴─┴────────► U_D (В)
                  U_D0
```

* **Вихідні дані:**
  * Струм спокою: $I_{D0} = 2.5\ \text{мА}$.
  * Опір тіла напівпровідника та контактів: $r_s = 1.6\ \Omega$.
* **Завдання:**
  1. Розрахувати диференційний опір ідеального $pn$-переходу $r_j$.
  2. Знайти повний динамічний опір діода $r_d = r_j + r_s$.
  3. Визначити амплітуду змінної напруги на діоді $\Delta U_d$, якщо змінна складова струму становить $\Delta I = 0.2\ \text{мА}$.
* 💡 **Підказка:** $r_j = \frac{\eta V_T}{I_{D0}}$.

---

#### Завдання 2: Параметри моделі Гібріда-$\pi$ малопотужного BJT
Кремнієвий NPN-транзистор працює в активному режимі підсилення зі струмом колектора $I_{C0} = 1.2\ \text{мА}$. Статичний коефіцієнт передачі струму $\beta = 180$, $V_T = 25.85\ \text{мВ}$.

* **Вихідні дані:**
  * $I_{C0} = 1.2\ \text{мА}$, $\beta = 180$, $V_T = 25.85\ \text{мВ}$.
* **Завдання:**
  1. Розрахувати крутизну прямої передачі $g_m$.
  2. Знайти внутрішній опір емітера $r_e$.
  3. Обчислити динамічний вхідний опір бази $r_\pi$ (параметр $h_{11e}$).
* 💡 **Підказка:** Струм емітера $I_E = I_C \cdot \frac{\beta + 1}{\beta}$.

---

#### Завдання 3: Розрахунок крутизни та робочої точки JFET
Польовий транзистор з керуючим $pn$-переходом (JFET) має початковий струм стоку при короткозамкненому затворі $I_{DSS} = 8.0\ \text{мА}$ та напругу відсічки каналу $V_p = -3.0\ \text{В}$. Напруга на затворі встановлена $V_{GS0} = -1.0\ \text{В}$.

```text
               +E_d
                 │
                [R_d]
                 │
                 ├───► U_вих
            ┌────┴───┐
   U_вх ───┤│ JFET   │ (N-канал)
            └────┬───┘
                 ├───[ R_s ]───┐
                ─┴─           ─┴─ GND
```

* **Вихідні дані:**
  * $I_{DSS} = 8.0\ \text{мА}$, $V_p = -3.0\ \text{В}$, $V_{GS0} = -1.0\ \text{В}$.
* **Завдання:**
  1. Розрахувати постійний струм стоку $I_{D0}$ за формулою Шоклі.
  2. Знайти крутизну $S = g_m$ у вибраній робочій точці.
  3. Знайти максимальну можливу крутизну транзистора $S_0$ (при $V_{GS} = 0$).
* 💡 **Підказка:** $S_0 = \frac{2 I_{DSS}}{|V_p|}$.

#### Завдання 4: Врахування ефекту Ерлі та вихідного опору колектора
У підсилювальному каскаді зі спільним емітером струм колектора становить $I_{C0} = 0.8\ \text{мА}$, напруга Ерлі для транзистора $V_A = 80\ \text{В}$, постійна напруга $V_{CE0} = 4.0\ \text{В}$. Опір колекторного навантаження $R_c = 10.0\ \text{к}\Omega$.

* **Вихідні дані:**
  * $I_{C0} = 0.8\ \text{мА}$, $V_A = 80\ \text{В}$, $V_{CE0} = 4.0\ \text{В}$, $R_c = 10\ \text{к}\Omega$, $\beta = 120$.
* **Завдання:**
  1. Розрахувати вихідний диференційний опір транзистора $r_o$ та вихідну провідність $h_{22e}$.
  2. Знайти еквівалентний опір колекторного навантаження $R_{c\text{екв}} = R_c \parallel r_o$.
  3. Оцінити, на скільки відсотків зменшиться коефіцієнт підсилення $|K_U|$ через урахування кінцевого опору $r_o$ у порівнянні з ідеальним випадком ($r_o \to \infty$).
* 💡 **Підказка:** $r_o = \frac{V_A + V_{CE0}}{I_{C0}}$. Відносна похибка: $\delta = \frac{R_c - R_{c\text{екв}}}{R_c} \times 100\%$.

#### Завдання 5: Гранична частота одиничного підсилення $f_T$
Транзистор надвисокочастотного тракту працює при струмі колектора $I_{C0} = 3.0\ \text{мА}$. Еквівалентні малосигнальні ємності складають: бар'єрна ємність колекторного переходу $C_\mu = 2.5\ \text{пФ}$, повна ємність емітерного переходу (дифузійна + бар'єрна) $C_\pi = 28.0\ \text{пФ}$.

* **Вихідні дані:**
  * $I_{C0} = 3.0\ \text{мА}$, $V_T = 26\ \text{мВ}$, $C_\pi = 28.0\ \text{пФ}$, $C_\mu = 2.5\ \text{пФ}$.
* **Завдання:**
  1. Обчислити крутизну $g_m$.
  2. Знайти граничну частоту передачі струму $f_T$ (частоту, на якій $|\beta(f)| = 1$).
  3. Якщо низькочастотний коефіцієнт підсилення струму $\beta_0 = 150$, знайти частоту зрізу підсилення за струмом $f_\beta$.
* 💡 **Підказка:** $f_\beta = \frac{f_T}{\beta_0} = \frac{1}{2\pi r_\pi (C_\pi + C_\mu)}$.

#### Завдання 6: Динамічний опір та стабілізація на базі параметричного двополюсника
Параметричний стабілізатор напруги реалізовано на кремнієвому стабілітроні з напругою стабілізації $U_Z = 6.2\ \text{В}$ та динамічним опором $r_z = 8.0\ \Omega$. Баластний резистор $R_б = 240\ \Omega$, опір корисного навантаження $R_н = 1.2\ \text{к}\Omega$.

```text
              R_б (240 Ом)
   U_вх ───────[───]────────┬───────────► U_вих
   (12 В)                   │
                           ┌┴┐
                  стабі-   │▲│ VD1     [ R_н ] (1.2 кОм)
                  літрон   └┬┘ (r_z)    │
                            │           │
                           ─┴───────────┴─ GND
```

* **Вихідні дані:**
  * $U_{\text{вх}} = 12.0\ \text{В}$, $U_Z = 6.2\ \text{В}$, $r_z = 8.0\ \Omega$, $R_б = 240\ \Omega$, $R_н = 1200\ \Omega$.
* **Завдання:**
  1. Скласти еквівалентну схему змінного струму для пульсацій вхідної напруги $\Delta U_{\text{вх}}$.
  2. Розрахувати коефіцієнт стабілізації за напругою $K_{\text{ст}} = \frac{\Delta U_{\text{вх}}}{\Delta U_{\text{вих}}}$.
  3. Знайти вихідний опір стабілізатора $R_{\text{вих}}$.
* 💡 **Підказка:** По змінному струму стабілітрон моделюється опором $r_z$. Еквівалентне навантаження баласту: $R_{\text{пар}} = r_z \parallel R_н$.

#### Завдання 7: Перетворення $h$-параметрів між схемами зі Спільним Емітером (СЕ) та Спільною Базою (СБ)
Відомі малосигнальні $h$-параметри біполярного транзистора за схемою зі спільним емітером: $h_{11e} = 2.0\ \text{к}\Omega$, $h_{21e} = 100$, $h_{12e} \approx 0$, $h_{22e} = 20\ \mu\text{S}$.

* **Вихідні дані:**
  * $h_{11e} = 2000\ \Omega$, $h_{21e} = 100$.
* **Завдання:**
  1. Визначити вхідний опір каскаду за схемою зі спільною базою $h_{11b}$.
  2. Знайти коефіцієнт передачі струму для схеми зі спільною базою $h_{21b} = -\alpha$.
  3. Пояснити фізичну причину, чому вхідний опір схеми СБ значно менший, ніж у схеми СЕ.
* 💡 **Підказка:** $h_{11b} = \frac{h_{11e}}{1 + h_{21e}} \approx r_e$, $h_{21b} = -\frac{h_{21e}}{1 + h_{21e}}$.

#### Завдання 8: Повний розрахунок активного чотириполюсника за $h$-матрицею
Активний транзисторний чотириполюсник характеризується повною матрицею $h$-параметрів:
$$[H] = \begin{bmatrix} 1500\ \Omega & 4.0 \cdot 10^{-4} \\ 120 & 25.0\ \mu\text{S} \end{bmatrix}$$
На вихід чотириполюсника підключено навантаження $R_н = 5.0\ \text{к}\Omega$, а на вхід подається сигнал від генератора з внутрішнім опором $R_{\text{дж}} = 600\ \Omega$.

* **Вихідні дані:**
  * $h_{11} = 1500\ \Omega$, $h_{12} = 4 \cdot 10^{-4}$, $h_{21} = 120$, $h_{22} = 2.5 \cdot 10^{-5}\ \text{S}$, $R_н = 5000\ \Omega$, $R_{\text{дж}} = 600\ \Omega$.
* **Завдання:**
  1. Обчислити визначник матриці $\Delta_h = h_{11} h_{22} - h_{12} h_{21}$.
  2. Розрахувати коефіцієнт підсилення напруги $K_U = \frac{U_2}{U_1} = \frac{-h_{21}}{h_{11} + \Delta_h R_н} R_н \approx \frac{-h_{21} R_н}{h_{11} (1 + h_{22} R_н)}$.
  3. Знайти точний вхідний опір $R_{\text{вх}} = h_{11} - \frac{h_{12} h_{21}}{h_{22} + 1/R_н}$ та вихідний опір $R_{\text{вих}} = \frac{R_{\text{дж}} + h_{11}}{\Delta_h + h_{22} R_{\text{дж}}}$.
* 💡 **Підказка:** Зверніть увагу на вплив коефіцієнта зворотного зв'язку $h_{12}$.

#### Завдання 9: Порівняльний аналіз підсилювальних властивостей BJT та JFET
Порівнюються два транзистори однакової вартості за однакового струму спокою $I_0 = 1.0\ \text{мА}$:
* Транзистор A: NPN BJT з $\beta = 150$, $V_T = 26\ \text{мВ}$.
* Транзистор B: N-канал JFET з $I_{DSS} = 4.0\ \text{мА}$, $V_p = -2.0\ \text{В}$.
Обидва працюють на однакове активне навантаження $R_{\text{нав}} = 3.3\ \text{к}\Omega$.

* **Вихідні дані:**
  * $I_0 = 1.0\ \text{мА}$, $R_{\text{нав}} = 3.3\ \text{к}\Omega$.
  * BJT: $\beta = 150$, $V_T = 26\ \text{мВ}$.
  * JFET: $I_{DSS} = 4.0\ \text{мА}$, $V_p = -2.0\ \text{В}$.
* **Завдання:**
  1. Розрахувати крутизну $g_m$ для BJT та JFET. Знайти їх співвідношення $\frac{g_{m\text{(BJT)}}}{g_{m\text{(JFET)}}}$.
  2. Знайти коефіцієнти підсилення каскадів $|K_U| = g_m R_{\text{нав}}$.
  3. Обчислити вхідні опори обох каскадів на частоті $f = 1\ \text{кГц}$ (для JFET прийняти ємність входу $C_{\text{вх}} = 5\ \text{пФ}$, опір витоку $R_{\text{ут}} = 100\ \text{МОм}$). Зробити висновок щодо сфер застосування.

#### Завдання 10: Пасивний Т-подібний чотириполюсник (Атенюатор 50 Ом)
Для узгодження тракту вимірювального генератора з навантаженням $Z_0 = 50\ \Omega$ потрібно спроєктувати симетричний Т-подібний резистивний атенюатор зі згасанням $A = 6.0\ \text{дБ}$ ($K_U = 0.5$).

```text
               R1          R1
   Вхід 1 ─────[───]───┬───[───]─────► Вихід 2
   (50 Ом)             │               (50 Ом)
                      ┌┴┐
                      │ │ R2
                      └┬┘
                       │
   Вхід 1' ────────────┴─────────────► Вихід 2' (GND)
```

* **Вихідні дані:**
  * Хвильовий/характеристичний опір: $Z_0 = 50\ \Omega$.
  * Коефіцієнт ослаблення напруги під навантаженням: $k = 10^{-A/20} = 10^{-6/20} \approx 0.5012 \approx 0.5$.
* **Завдання:**
  1. Розрахувати номінали резисторів $R_1$ та $R_2$ симетричного Т-моста за формулами:
     $$R_1 = Z_0 \cdot \frac{1 - k}{1 + k}, \quad R_2 = Z_0 \cdot \frac{2k}{1 - k^2}$$
  2. Записати матрицю опорів $[Z]$ чотириполюсника.
  3. Перевірити, чи дорівнює вхідний опір атенюатора $R_{\text{вх}} = 50\ \Omega$ при підключенні на вихід опору $R_н = 50\ \Omega$.
* 💡 **Підказка:** $R_{\text{вх}} = R_1 + [R_2 \parallel (R_1 + R_н)]$.
