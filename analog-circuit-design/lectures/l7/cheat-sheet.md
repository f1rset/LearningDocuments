## 🧭 1. TL;DR — Квінтесенція теми за 60 секунд

1. **Що таке «Нульовий порядок»:** У колах зворотного зв'язку використовуються виключно **резистори** (без $L, C$). Передавальна функція $W(s) = K_0 \cdot s^0 = \text{const}$ не залежить від частоти (у робочій смузі ОП).
2. **Інвертуючий масштабуючий каскад:** $K_U = -\frac{R_2}{R_1}$, інверсія фази ($180^\circ$). Вхідний опір дорівнює номіналу вхідного резистора: $R_{\text{вх}} = R_1$. На інвертуючому вході утворюється **віртуальна земля** ($0\ \text{В}$).
3. **Неінвертуючий масштабуючий каскад:** $K_U = 1 + \frac{R_2}{R_1}$, синфазний сигнал ($0^\circ$). Вхідний опір колосальний ($R_{\text{вх}} \to \infty$).
4. **Повторювач (Буфер):** $R_2 = 0, R_1 = \infty \implies K_U = 1.0$. $100\%$ НЗЗ. Ідеальний узгоджувач високого вихідного опору джерела з низькоомним навантаженням.
5. **Диференціальний підсилювач (Віднімач):** $U_{\text{вих}} = \frac{R_2}{R_1}(U_{\text{вх2}} - U_{\text{вх1}})$. Умова ідеального віднімання: **$\frac{R_2}{R_1} = \frac{R_4}{R_3}$** (типово $R_3 = R_1, R_4 = R_2$).
6. **Головний ворог CMRR:** Навіть при ідеальному ОП неточність резисторів $\pm 1\%$ обмежує синфазне придушення до $\approx 54\ \text{дБ}$. Для вимірювальних систем потрібні резистори $0.1\%$ або інструментальні ОП (In-Amp).
7. **Суматори:**
   * *Інвертуючий:* $U_{\text{вих}} = -R_{\text{зз}} \sum \frac{U_i}{R_i}$. Входи **повністю розв'язані** завдяки віртуальній землі (немає cross-talk).
   * *Неінвертуючий:* вимагає пасивного змішування на вході $(+)$; при однакових опорах обчислює середнє арифметичне.
8. **Інвертор імпедансу (NIC):** Синтезує від'ємний динамічний опір **$R_{\text{вх}} = -\frac{R_1 R_3}{R_2} < 0$**. Схема стійка лише за умови домінування НЗЗ над ПЗЗ: **$R_г < |R_{\text{вх}}|$** (Short-Circuit Stable).

## ⚡ 2. Ключові формули та розрахункові залежності

| Схема / Параметр | Розрахункова формула | Вхідний опір $R_{\text{вх}}$ | Умова застосування / Стійкість |
| :--- | :--- | :---: | :--- |
| **Інвертуючий підсилювач** | $$U_{\text{вих}} = -\frac{R_2}{R_1} U_{\text{вх}}$$ | $$R_{\text{вх}} = R_1$$ | Віртуальна земля на вході ($-$) |
| **Неінвертуючий підсилювач**| $$U_{\text{вих}} = \left(1 + \frac{R_2}{R_1}\right) U_{\text{вх}}$$ | $$R_{\text{вх}} \to \infty$$ | Не інвертує фазу сигналу |
| **Буферний повторювач** | $$U_{\text{вих}} = U_{\text{вх}} \implies K_U = 1$$ | $$R_{\text{вх}} \to \infty$$ | $R_2 = 0, R_1 = \infty$ (100% НЗЗ) |
| **Диференціальний віднімач**| $$U_{\text{вих}} = \frac{R_2}{R_1}(U_{\text{вх2}} - U_{\text{вх1}})$$ | $$R_{\text{diff}} = 2 R_1$$ | Умова балансу: $\frac{R_2}{R_1} = \frac{R_4}{R_3}$ |
| **CMRR за допусками резисторів**| $$\text{CMRR}_{\text{res}} \approx \frac{1 + K_d}{4 \epsilon_{\text{tol}}}$$ | — | $\epsilon_{\text{tol}} = 0.01$ (1%) або $0.001$ (0.1%) |
| **Інвертуючий суматор** | $$U_{\text{вих}} = -R_{\text{зз}} \sum_{i=1}^n \frac{U_{\text{вх}i}}{R_i}$$ | $$R_{\text{вх}i} = R_i$$ | Відсутність перехресних завад |
| **Неінвертуючий суматор (усереднювач)**| $$U_{\text{вих}} = \left(1 + \frac{R_2}{R_1}\right) \frac{\sum U_{\text{вх}i}}{n}$$| $$R_{\text{вх}i} = R_i + R_{\text{пар}}$$ | Чиста сума при $1 + \frac{R_2}{R_1} = n$ |
| **Вхідний опір інвертора NIC** | $$R_{\text{вх}} = -\frac{R_1 R_3}{R_2} < 0$$ | **Від'ємний** | Еквівалентний генератор енергії |
| **Умова стійкості NIC** | $$R_г < \frac{R_1 R_3}{R_2} = \|R_{\text{вх}}\|$$ | — | НЗЗ переважає ПЗЗ ($\chi_{\text{НЗЗ}}^- > \chi_{\text{ПЗЗ}}^+$) |

## 📊 3. Порівняльна матриця топологій нульового порядку

| Топологія | Знак $K_U$ | $R_{\text{вх}}$ | Стійкість до синфазної завади | Складність налаштування | Сфера застосування |
| :--- | :---: | :---: | :---: | :---: | :--- |
| **Інвертуюча** | $-$ | Помірний ($1\dots 50\ \text{к}\Omega$) | Погана (немає придушення) | 🟢 Мінімальна (2 резистори) | ЦАП, суматори, перетворювачі I-U |
| **Неінвертуюча** | $+$ | Надвисокий ($> 10\ \text{МОм}$) | Посередня (вхід бачить CM) | 🟢 Мінімальна (2 резистори) | Буфери сенсорів, передпідсилювачі |
| **Диференціальна** | $+$ | Середній ($R_1$ та $R_3+R_4$) | 🟢 Відмінна (при точних $R$) | 🟡 Висока (потребує підбору $R$) | Мостові схеми, шунти вимірювання струму |
| **Інвертуючий суматор**| $-$ | Незалежний для каналів | Не застосовується | 🟢 Проста | Звукові мікшери, аналогові ЕОМ |
| **NIC (Інвертор)** | — | **Від'ємний ($< 0$)** | Схильний до зриву в генерацію | 🔴 Критична (вимагає контролю $R_г$) | Компенсація опору кабелів, активні фільтри |

## 🛠️ 4. Інженерні евристики та правила (Rules of Thumb)

1. **Діапазон номіналів резисторів ($1\ \text{к}\Omega \dots 100\ \text{к}\Omega$):**
   * Менше $1\ \text{к}\Omega$ — перевантажує вихідний каскад ОП (типовий ліміт струму виходу LM324: $20\dots 40\ \text{мА}$).
   * Більше $100\ \text{к}\Omega$ — створює підвищений тепловий шум Джонсона ($\sqrt{4kTR\Delta f}$) та чутливість до наведень і струмів $I_{IB}$.
2. **Балансування входів для компенсації струму $I_{IB}$:**
   * В інвертуючому підсилювачі на вхід $(+)$ обов'язково встановлюйте $R_{\text{комп}} = R_1 \parallel R_2$.
   * У неінвертуючому підсилювачі послідовно зі входом $(+)$ додавайте опір $R_{\text{комп}} = R_1 \parallel R_2$.
3. **Правило 100-відсоткового придушення синфазної завади:**
   * Не використовуйте звичайні дискретні резистори $5\%$ чи $1\%$ у вимірювальних мостах. Застосовуйте узгоджені резистивні збірки (Resistor Networks) з допуском відносного коефіцієнта $0.05\%\dots 0.1\%$.
4. **Стійкість інвертора імпедансу (NIC):**
   * Ніколи не залишайте вхід конвертора негативного опору розімкненим ($R_г \to \infty$). Завжди підключайте джерело з внутрішнім опором $R_г < |R_{\text{вх}}|$, інакше схема миттєво перетвориться на тригер Шмітта.

## ⚠️ 5. Типові підводні камені та помилки на іспиті/тесті

* 🚨 **Помилка: "Вхідний опір інвертуючого каскаду нескінченний, бо це ОП":**  
  * *Факт:* Вхідний опір інвертуючого підсилювача дорівнює **номіналу резистора $R_1$** (зазвичай кілька кілоом)! Нескінченний опір має лише **неінвертуючий** каскад.
* 🚨 **Помилка: "Віртуальна земля існує завжди":**  
  * *Факт:* Потенціал $U_- = U_+ = 0\ \text{В}$ існує **тільки тоді**, коли ОП охоплений негативним зворотним зв'язком і його вихід **не зайшов у насичення** на шину живлення.
* 🚨 **Помилка: Неоднакові вхідні опори диференціального каскаду:**  
  * *Факт:* Вхід 1 бачить опір $R_1$, а вхід 2 бачить опір $R_3 + R_4$. Якщо джерела сигналу мають внутрішні опори, ця асиметрія повністю знищує CMRR!
* 🚨 **Помилка у визначенні знака від'ємного опору NIC:**  
  * *Факт:* $R_{\text{вх}} = -\frac{R_1 R_3}{R_2}$. Якщо поміняти місцями входи ОП ($+$ та $-$), формула виявиться нестійкою в іншій конфігурації.
