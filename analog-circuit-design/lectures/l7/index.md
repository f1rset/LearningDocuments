## 1. Фізична сутність та поняття схем нульового порядку

В інженерній класифікації аналогових функціональних пристроїв порядок схеми визначається **найвищим порядком диференціального рівняння**, що описує її поведінку, або **максимальним степенем комплексного оператора $s$ (де $s = j\omega$)** у передавальній функції:
$$W(s) = \frac{U_{\text{вих}}(s)}{U_{\text{вх}}(s)}$$

> 💡 **Визначення:**  
> **Схемами нульового порядку** називаються такі функціональні вузли на операційних підсилювачах, у колах зворотного зв'язку яких використовуються **виключно резистивні елементи (без реактивних накопичувачів енергії — конденсаторів $C$ чи індуктивностей $L$)**.

### Ключові властивості схем нульового порядку:
1. **Частотна незалежність (у квазістатичній смузі):** Передавальна функція є безрозмірним числом або константою ($W(s) = K_0 \cdot s^0 = K_0 = \text{const}$).
2. **Миттєва реакція:** У часовій області вихідний сигнал пропорційний вхідному без фазового запізнення або накопичення заряду:
   $$u_{\text{вих}}(t) = K_0 \cdot u_{\text{вх}}(t)$$
3. **Область застосування:** Виконання лінійних алгебраїчних операцій над неперервними електричними величинами — масштабування (множення на скаляр), віднімання, сумування, формування різницевих сигналів та синтез екзотичних параметрів (від'ємного диференційного опору).

## 2. Масштабні підсилювачі на ОП

Масштабний підсилювач призначений для точного помноження аналогового сигналу на постійний коефіцієнт $K_U$ з високою лінійністю та незалежністю від параметрів джерела та навантаження.

### 2.1 Інвертуючий масштабуючий підсилювач

В інвертуючому підсилювачі вхідний сигнал подається на інвертуючий вхід $(-)$ через резистор $R_1$, а неінвертуючий вхід $(+)$ заземлено.

```text
               R1                      R2
   U_вх ──────[───]────────┬──────────[───]───────────┐
              i1           │                          │
                           │                          │
                          ┌┴┐                         │
                          │-│ ОП                      │
                          │ ├─────────────────────────┴──► U_вих
                          │+│
                          └┬┘
                           │
                          ─┴─ GND (0 В)
```

#### Математичне виведення за Золотими правилами:
1. Оскільки неінвертуючий вхід підключений до землі ($U_+ = 0$), за **Першим золотим правилом ОП** ($U_- = U_+$) на інвертуючому вході утворюється **потенціал віртуальної землі**:
   $$U_- = U_+ = 0\ \text{В}$$
2. Струм через вхідний резистор $R_1$:
   $$i_1 = \frac{U_{\text{вх}} - U_-}{R_1} = \frac{U_{\text{вх}} - 0}{R_1} = \frac{U_{\text{вх}}}{R_1}$$
3. За **Другим золотим правилом ОП** вхідний струм самого ОП дорівнює нулю ($i_- = 0$). Отже, за першим законом Кірхгофа весь струм $i_1$ без втрат протікає через резистор зворотного зв'язку $R_2$:
   $$i_1 = \frac{U_- - U_{\text{вих}}}{R_2} = \frac{0 - U_{\text{вих}}}{R_2} = -\frac{U_{\text{вих}}}{R_2}$$
4. Прирівнюючи обидва вирази для струму $i_1$:
   $$\frac{U_{\text{вх}}}{R_1} = -\frac{U_{\text{вих}}}{R_2} \implies K_U = \frac{U_{\text{вих}}}{U_{\text{вх}}} = -\frac{R_2}{R_1}$$

#### Імпедансні властивості:
* **Вхідний опір:** Оскільки точка з'єднання резисторів $R_1$ та $R_2$ перебуває під нульовим потенціалом віртуальної землі, вхідний струм визначається виключно резистором $R_1$:
  $$R_{\text{вх}} = \frac{U_{\text{вх}}}{i_1} = R_1$$
* **Вихідний опір:** Завдяки глибокому негативному зворотному зв'язку за напругою вихідний опір замкненого ОП наближається до нуля:
  $$R_{\text{вих}} \approx 0\ \Omega$$

> ⚠️ **Інженерний компроміс схеми:**  
> Щоб отримати високий коефіцієнт підсилення (наприклад, $K_U = -100$) при високому вхідному опорі ($R_{\text{вх}} = 100\ \text{к}\Omega$), резистор $R_2$ повинен мати номінал $10\ \text{МОм}$. Такий надвисокий опір створює великий тепловий шум Джонсона та паразитно взаємодіє з міжкаскадною ємністю друкованої плати.

### 2.2 Неінвертуючий масштабуючий підсилювач та повторювач

У неінвертуючій схемі вхідний сигнал подається безпосередньо на високоомний вхід $(+)$, а коло зворотного зв'язку $R_1 - R_2$ формує подільник вихідної напруги на вхід $(-)$.

```text
   U_вх ───────────────────┐
                          ┌┴┐
                          │+│ ОП
                          │ ├──────────────┬─────────────► U_вих
                          │-│              │
                          └┬┘              │
                           │               │
                           ├───[ R2 ]──────┘
                           │
                          ┌┴┐
                          │ │ R1
                          └┬┘
                           │
                          ─┴─ GND
```

#### Математичне виведення:
1. За Першим золотим правилом напруги на входах рівні:
   $$U_- = U_+ = U_{\text{вх}}$$
2. Потенціал на інвертуючому вході формується подільником вихідної напруги:
   $$U_- = U_{\text{вих}} \cdot \frac{R_1}{R_1 + R_2}$$
3. Підставляючи $U_- = U_{\text{вх}}$:
   $$U_{\text{вх}} = U_{\text{вих}} \cdot \frac{R_1}{R_1 + R_2} \implies K_U = \frac{U_{\text{вих}}}{U_{\text{вх}}} = \frac{R_1 + R_2}{R_1} = 1 + \frac{R_2}{R_1}$$

#### Імпедансні характеристики:
* **Вхідний опір:** Оскільки сигнал подається безпосередньо на затвор/базу вхідного каскаду, а вхідний струм $i_+ \approx 0$:
  $$R_{\text{вх}} \to \infty \quad (\text{на практиці } 10^7\dots 10^{12}\ \Omega)$$
* **Вихідний опір:** $R_{\text{вих}} \approx 0\ \Omega$.

#### Окремий випадок: Повторювач напруги (Буфер)
Якщо вибрати $R_2 = 0$ (пряме закорочення виходу на інвертуючий вхід), а $R_1 = \infty$ (розрив кола на землю):
$$K_U = 1 + \frac{0}{\infty} = \mathbf{1.0}$$
Буфер має $100\%$ зворотний зв'язок ($\chi = 1$), володіє абсолютною лінійністю, повторює напругу та забезпечує повне гальванічне узгодження чутливого джерела сигналу з низькоомним навантаженням.

## 3. Диференціальний підсилювач (Віднімач)

Диференціальний підсилювач призначений для виділення та підсилення різниці потенціалів між двома точками кола з одночасним придушенням синфазної завади.

### 3.1 Схемотехніка та повне аналітичне виведення

Схема об'єднує інвертуючу та неінвертуючу топології в єдиний симетричний чотириполюсник:

```text
                 R1 (Вхід 1: Інвертуючий)
   U_вх1 ─────────[───]────────┬───────────────────┐
                               │                   │
                              ┌┴┐                  │
                              │-│                  │
                              │ ├───[ R2 ]─────────┴────► U_вих
                              │+│
                              └┬┘
   U_вх2 ─────────[───]────────┤
   (Вхід 2)      R3            │
                              ┌┴┐
                              │ │ R4
                              └┬┘
                               │
                              ─┴─ GND
```

#### Покроковий аналіз:
1. **Потенціал неінвертуючого входу ($U_+$):**  
   Оскільки струм у вхід $(+)$ не тече ($i_+ = 0$), коло $R_3 - R_4$ є класичним резистивним подільником напруги $U_{\text{вх2}}$:
   $$U_+ = U_{\text{вх2}} \cdot \frac{R_4}{R_3 + R_4}$$
2. **Потенціал інвертуючого входу ($U_-$):**  
   За Золотим правилом $U_- = U_+$:
   $$U_- = U_{\text{вх2}} \cdot \frac{R_4}{R_3 + R_4}$$
3. **Рівняння вузлових струмів для інвертуючого входу:**  
   Струм від $U_{\text{вх1}}$ дорівнює струму у вузол зворотного зв'язку:
   $$\frac{U_{\text{вх1}} - U_-}{R_1} = \frac{U_- - U_{\text{вих}}}{R_2}$$
   $$U_{\text{вих}} = U_- \left(1 + \frac{R_2}{R_1}\right) - U_{\text{вх1}} \frac{R_2}{R_1}$$
4. **Підстановка виразу для $U_-$:**
   $$U_{\text{вих}} = -\frac{R_2}{R_1} U_{\text{вх1}} + \frac{R_4}{R_3 + R_4}\left(1 + \frac{R_2}{R_1}\right) U_{\text{вх2}}$$

#### Умова чистого диференціального підсилення:
Щоб вихідний сигнал був пропорційним виключно різниці $(U_{\text{вх2}} - U_{\text{вх1}})$, коефіцієнти при обох входах повинні бути строго рівними за абсолютною величиною:
$$\frac{R_2}{R_1} = \frac{R_4}{R_3 + R_4}\left(1 + \frac{R_2}{R_1}\right)$$
Перетворимо праву частину:
$$\frac{R_2}{R_1} = \frac{R_4}{R_3 + R_4} \cdot \frac{R_1 + R_2}{R_1} \iff R_2(R_3 + R_4) = R_4(R_1 + R_2)$$
$$R_2 R_3 + R_2 R_4 = R_1 R_4 + R_2 R_4 \iff \mathbf{R_2 R_3 = R_1 R_4} \iff \mathbf{\frac{R_2}{R_1} = \frac{R_4}{R_3}}$$

> 🎯 **Головне правило симетрії диференціального каскаду:**  
> Якщо $\frac{R_2}{R_1} = \frac{R_4}{R_3} = K_d$, вихідна напруга описується формулою:
> $$U_{\text{вих}} = K_d \cdot (U_{\text{вх2}} - U_{\text{вх1}}) = \frac{R_2}{R_1}(U_{\text{вх2}} - U_{\text{вх1}})$$
> Найпростіша практична реалізація: вибір **$R_3 = R_1$** та **$R_4 = R_2$**.

#### Вхідні опори диференціального підсилювача:
* Для інвертуючого входу: $R_{\text{вх1}} = R_1$.
* Для неінвертуючого входу: $R_{\text{вх2}} = R_3 + R_4$.
* Диференційний вхідний опір між клемами: $R_{\text{вх(diff)}} = R_1 + R_3 = 2 R_1$.

### 3.2 Аналіз коефіцієнта придушення синфазного сигналу (CMRR)

У реальному пристрої на обидва входи завжди накладається синфазна напруга $U_{\text{вх\_CM}}$ (наприклад, наведення від промислової електромережі 50 Гц):
$$U_{\text{вх1}} = U_{\text{вх\_CM}} - \frac{U_d}{2}, \quad U_{\text{вх2}} = U_{\text{вх\_CM}} + \frac{U_d}{2}$$

#### Виведення синфазного коефіцієнта передачі ($K_{CM}$):
Подамо синфазний сигнал $U_{\text{вх1}} = U_{\text{вх2}} = U_{\text{вх\_CM}}$:
$$K_{CM} = \frac{U_{\text{вих}}}{U_{\text{вх\_CM}}} = -\frac{R_2}{R_1} + \frac{R_4}{R_3 + R_4}\left(1 + \frac{R_2}{R_1}\right)$$
В ідеальному випадку ($R_2/R_1 = R_4/R_3$) значення $K_{CM} = 0$. Проте через технологічний розкид резисторів виникає паразитний вихідний сигнал.

#### Точна аналітична формула CMRR:
Коефіцієнт послаблення синфазного сигналу визначається як відношення диференційного підсилення $K_d$ до синфазного $K_{CM}$:
$$\text{CMRR} = \left| \frac{K_d}{K_{CM}} \right| = \frac{1}{2} \cdot \frac{\frac{R_4}{R_3 + R_4}\left(1 + \frac{R_2}{R_1}\right) + \frac{R_2}{R_1}}{\frac{R_4}{R_3 + R_4}\left(1 + \frac{R_2}{R_1}\right) - \frac{R_2}{R_1}}$$

Якщо резистори мають технологічний допуск $\pm \epsilon_{\text{tol}}$ (наприклад, $\epsilon_{\text{tol}} = 0.01$ для 1%-х резисторів), найгірше теоретичне значення CMRR оцінюється формулою:
$$\text{CMRR}_{\text{res}} \approx \frac{1 + K_d}{4 \cdot \epsilon_{\text{tol}}}$$
У децибелах:
$$\text{CMRR}_{\text{дБ}} = 20 \lg(\text{CMRR})$$

## 4. Аналогові суматори на ОП

Суматори здійснюють операцію додавання декількох електричних напруг із заданими ваговими коефіцієнтами.

### 4.1 Інвертуючий сумуючий підсилювач

Найбільш досконала і поширена конфігурація суматора завдяки взаємній ізоляції каналів.

```text
   U_вх1 ───[ R1 ]───┬─────────────────────────────┐
                     │                             │
   U_вх2 ───[ R2 ]───┼─────────────────────────┐   │
                     │                         │   │
   U_вхn ───[ Rn ]───┼─────────────────────┐   │   │
                     │                     │   │   │
                     │  Вузол підсумовування │ ┌┴┐ │
                     └─── (0 В віртуальний) ┴─┤-│ │
                                              │ ├──┴──[ R_зз ]──► U_вих
                                            ┌─┤+│
                                           ─┴─└┬┘
                                           GND ─┴─ GND
```

#### Принцип роботи та суперпозиція:
Оскільки інвертуючий вхід знаходиться під потенціалом віртуального нуля ($U_- = 0$), струм кожного вхідного каналу не залежить від напруг на інших входах:
$$i_k = \frac{U_{\text{вх}k} - 0}{R_k} = \frac{U_{\text{вх}k}}{R_k}$$
За першим законом Кірхгофа сумарний струм вузла вимушений текти через резистор зворотного зв'язку $R_{\text{зз}}$:
$$i_{\text{зз}} = \sum_{k=1}^n i_k = \frac{U_{\text{вх1}}}{R_1} + \frac{U_{\text{вх2}}}{R_2} + \dots + \frac{U_{\text{вх}n}}{R_n}$$
Вихідна напруга:
$$U_{\text{вих}} = 0 - i_{\text{зз}} R_{\text{зз}} = -R_{\text{зз}} \left( \frac{U_{\text{вх1}}}{R_1} + \frac{U_{\text{вх2}}}{R_2} + \dots + \frac{U_{\text{вх}n}}{R_n} \right)$$
$$U_{\text{вих}} = -\sum_{k=1}^n \left(\frac{R_{\text{зз}}}{R_k}\right) U_{\text{вх}k}$$

#### Інженерні переваги:
1. **Повна відсутність перехресних перешкод (Zero Cross-talk):** Вхідний опір $k$-го каналу строго дорівнює $R_{\text{вх}k} = R_k$ і не змінюється при підключенні чи відключенні інших каналів.
2. **Незалежне регулювання ваг:** Зміна резистора $R_1$ змінює масштаб тільки сигналу $U_{\text{вх1}}$, не порушуючи підсилення решти входів.

---

### 4.2 Неінвертуючий сумуючий підсилювач

Застосовується у випадках, коли інверсія фази є небажаною, а вхідний опір має бути високим.

```text
   U_вх1 ───[ R31 ]───┬──────────────┐
                      │              │
   U_вх2 ───[ R32 ]───┼──────────┐   │
                      │          │   │
   U_вхn ───[ R3n ]───┼──────┐   │   │
                      │      │   │  ┌┴┐
                      │      │   │  │+│ ОП
                      ├──────┴───┴──┤ ├──────┬──────► U_вих
                      │             │-│      │
                     ┌┴┐            └┬┘      │
                     │ │ R4          ├──[R2]─┘
                     └┬┘             │
                      │             ┌┴┐ R1
                     ─┴─ GND        └┬┘
                                     │
                                    ─┴─ GND
```

#### Розрахунок методом вузлових провідностей:
Потенціал на неінвертуючому вході $U_+$ визначається за формулою Міллмана:
$$U_+ = \frac{\sum_{k=1}^n U_{\text{вх}k} G_{3k}}{G_4 + \sum_{k=1}^n G_{3k}}, \quad \text{де } G = \frac{1}{R}$$
Вихідна напруга дорівнює:
$$U_{\text{вих}} = \left(1 + \frac{R_2}{R_1}\right) U_+ = \left(1 + \frac{R_2}{R_1}\right) \sum_{i=1}^n \frac{U_{\text{вх}i}}{1 + R_{3i}\left(G_4 + \sum_{j \neq i}^n G_{3j}\right)}$$

#### Окремий випадок: Схема усереднення (Average Calculator)
Якщо всі вхідні резистори однакові ($R_{31} = R_{32} = \dots = R_{3n} = R_3$), а резистор $R_4$ відсутній ($R_4 = \infty, G_4 = 0$):
$$U_+ = \frac{U_{\text{вх1}} + U_{\text{вх2}} + \dots + U_{\text{вх}n}}{n}$$
$$U_{\text{вих}} = \left(\frac{U_{\text{вх1}} + U_{\text{вх2}} + \dots + U_{\text{вх}n}}{n}\right) \left(1 + \frac{R_2}{R_1}\right)$$
> 💡 **Евристика чистої суми:** Якщо вибрати підсилення каскаду таким, що $1 + \frac{R_2}{R_1} = n \implies \frac{R_2}{R_1} = n - 1$, на виході отримаємо пряму суму сигналів без ділення на $n$:
> $$U_{\text{вих}} = U_{\text{вх1}} + U_{\text{вх2}} + \dots + U_{\text{вх}n}$$

---

### 4.3 Диференціальний сумуючий підсилювач

Дозволяє виконувати загальну операцію зваженого додавання та віднімання сигналів:
$$U_{\text{вих}} = \sum_{j=1}^m K_j^+ U_{\text{вх}j}^+ - \sum_{i=1}^n K_i^- U_{\text{вх}i}^-$$

За умови повної симетрії матриці провідностей ($n = m$, $R_{1i} = R_{3i}$, $R_2 = R_4$):
$$U_{\text{вих}} = \sum_{i=1}^n \frac{R_2}{R_{1i}} (U_{\text{вх}i}^+ - U_{\text{вх}i}^-)$$

---

## 5. Інвертор імпедансу (Конвертор негативного імпедансу, NIC)

Конвертор негативного імпедансу (**Negative Impedance Converter — NIC**) — це активний двополюсник, який перетворює опір пасивного навантаження у від'ємний еквівалентний динамічний опір.

### 5.1 Схемотехніка та синтез від'ємного опору

Схема використовує одночасний позитивний та негативний зворотний зв'язок:

```text
                  R3
        ┌────────[───]────────┬────────────────┐
        │                     │                │
        │  i_вх               │             ┌──┴──┐
   Вхід ┼────────►───────────┼─────────────┤+ │  │
   U_вх │                     │             │  ├──┴──► U_вих_ОП
       ┌┴┐                    │             │- │
    R_г│ │ (Опір              │          ┌──┴──┘
       └┬┘  джерела)          │          │
        │                     ├───[ R2 ]─┘
       ─┴─ GND                │
                             ┌┴┐
                             │ │ R1
                             └┬┘
                              │
                             ─┴─ GND
```

#### Математичне виведення вхідного опору:
1. За правилом віртуального замикання напруги на входах рівні:
   $$U_- = U_+ = U_{\text{вх}}$$
2. Негативний зворотний зв'язок через дільник $R_1 - R_2$ фіксує вихідну напругу ОП:
   $$U_{\text{вих}}^{\text{ОП}} = \left(1 + \frac{R_2}{R_1}\right) U_- = \left(1 + \frac{R_2}{R_1}\right) U_{\text{вх}}$$
3. Розглянемо струм $i_{\text{вх}}$, що втікає у вхідну клему через резистор $R_3$:
   Оскільки струм у неінвертуючий вхід ОП не тече ($i_+ = 0$), весь вхідний струм тече через резистор $R_3$ до виходу ОП:
   $$U_{\text{вх}} - U_{\text{вих}}^{\text{ОП}} = -i_{\text{вх}} R_3 \iff U_{\text{вх}} = U_{\text{вих}}^{\text{ОП}} + i_{\text{вх}} R_3$$
4. Підставимо значення $U_{\text{вих}}^{\text{ОП}}$:
   $$U_{\text{вх}} = \left(1 + \frac{R_2}{R_1}\right) U_{\text{вх}} + i_{\text{вх}} R_3$$
   $$U_{\text{вх}} - U_{\text{вх}} - \frac{R_2}{R_1} U_{\text{вх}} = i_{\text{вх}} R_3 \implies -\frac{R_2}{R_1} U_{\text{вх}} = i_{\text{вх}} R_3$$
5. Знаходимо вхідний опір $R_{\text{вх}} = \frac{U_{\text{вх}}}{i_{\text{вх}}}$:
   $$R_{\text{вх}} = -\frac{R_1 R_3}{R_2} < 0$$

> 💡 **Фізичний зміст від'ємного опору:**  
> Звичайний резистор зі зростанням прикладеної напруги споживає більший струм ($i = U/R$). Інвертор імпедансу при підвищенні $U_{\text{вх}}$ видає струм **назустріч джерелу**! Тобто схема є керованим генератором енергії.

---

### 5.2 Критерій та фізична умова стійкості схеми

Оскільки в схемі діють два конкуруючі канали зворотного зв'язку — негативний (НЗЗ) та позитивний (ПЗЗ), постає фундаментальне питання стійкості. Якщо переважатиме ПЗЗ, схема втратить лінійність і перейде в режим компаратора (тригера Шмітта) або релаксаційного автогенератора.

#### Аналіз глибини зворотних зв'язків:
* **Коефіцієнт негативного зворотного зв'язку ($\chi_{\text{НЗЗ}}^-$):**
  $$\chi_{\text{НЗЗ}}^- = \frac{R_1}{R_1 + R_2} = \frac{1}{1 + \frac{R_2}{R_1}}$$
* **Коефіцієнт позитивного зворотного зв'язку ($\chi_{\text{ПЗЗ}}^+$):**  
  Замикається через опір джерела сигналу $R_г$, підключеного до входу:
  $$\chi_{\text{ПЗЗ}}^+ = \frac{R_г}{R_г + R_3} = \frac{1}{1 + \frac{R_3}{R_г}}$$

#### Умова стійкості:
Система залишається стійкою в лінійному режимі тоді й лише тоді, коли **негативний зворотний зв'язок є сильнішим за позитивний**:
$$\chi_{\text{НЗЗ}}^- > \chi_{\text{ПЗЗ}}^+$$
$$\frac{1}{1 + \frac{R_2}{R_1}} > \frac{1}{1 + \frac{R_3}{R_г}}$$
Оскільки знаменники додатні:
$$1 + \frac{R_2}{R_1} < 1 + \frac{R_3}{R_г} \iff \frac{R_2}{R_1} < \frac{R_3}{R_г}$$
Перемножуючи перехресно на $R_г$:
$$\mathbf{R_г < \frac{R_1 R_3}{R_2} = |R_{\text{вх}}|}$$

> ⚠️ **Практичний висновок для проєктувальника:**  
> Цей тип інвертора імпедансу є **стійким при короткому замиканні входу (Short-Circuit Stable)**.  
> Для стійкої роботи внутрішній опір джерела $R_г$ повинен бути строго меншим за модуль синтезованого від'ємного опору $|R_{\text{вх}}|$. Якщо розімкнути вхід ($R_г \to \infty$), схема негайно перейде в стан насичення на одну з шин живлення ($\pm E_ж$).

| Схема на ОП | Формула передачі $K_U$ | Вхідний опір $R_{\text{вх}}$ | Вихідний опір $R_{\text{вих}}$ | Зсув фази | Головна перевага |
| :--- | :--- | :--- | :--- | :---: | :--- |
| **Інвертуючий підсилювач** | $K_U = -\frac{R_2}{R_1}$ | $R_1$ (помірний) | $\approx 0$ | $180^\circ$ | Простота, віртуальна земля |
| **Неінвертуючий підсилювач** | $K_U = 1 + \frac{R_2}{R_1}$ | $\to \infty$ ($> 10\ \text{МОм}$) | $\approx 0$ | $0^\circ$ | Надвисокий $R_{\text{вх}}$ |
| **Повторювач (Буфер)** | $K_U = 1.0$ | $\to \infty$ | $\approx 0$ | $0^\circ$ | Ідеальне узгодження опорів |
| **Диференціальний підсилювач**| $K_U = \frac{R_2}{R_1}$ (при балансі) | $R_{\text{diff}} = 2 R_1$ | $\approx 0$ | $0^\circ$ | Придушення синфазної завади |
| **Інвертуючий суматор** | $U_{\text{вих}} = -\sum \frac{R_{\text{зз}}}{R_i} U_i$| $R_i$ для кожного каналу | $\approx 0$ | $180^\circ$ | Немає взаємного впливу входів |
| **Неінвертуючий суматор**| $U_{\text{вих}} = (1 + \frac{R_2}{R_1}) \overline{U}$| Складний ($R_i + R_{\text{пар}}$)| $\approx 0$ | $0^\circ$ | Збереження фази без інверсії |
| **Інвертор імпедансу (NIC)** | $R_{\text{вх}} = -\frac{R_1 R_3}{R_2}$ | **Від'ємний ($< 0$)** | — | — | Компенсація омічних втрат у колах |

## 7. Зведена таблиця розрахункових формул

| Назва вузла / Параметр | Формула | Опис змінних |
| :--- | :--- | :--- |
| **Інвертуючий каскад** | $U_{\text{вих}} = -\frac{R_2}{R_1} U_{\text{вх}}$ | $R_1$ — вхідний, $R_2$ — зворотний зв'язок |
| **Неінвертуючий каскад** | $U_{\text{вих}} = \left(1 + \frac{R_2}{R_1}\right) U_{\text{вх}}$ | $R_1$ — нижнє плече, $R_2$ — верхнє плече |
| **Умова балансу диференціатора** | $\frac{R_2}{R_1} = \frac{R_4}{R_3}$ | Умова занулення синфазного коефіцієнта ($K_{CM} = 0$) |
| **Синфазний коефіцієнт $K_{CM}$**| $K_{CM} = -\frac{R_2}{R_1} + \frac{R_4}{R_3 + R_4}\left(1 + \frac{R_2}{R_1}\right)$ | Передача синфазної напруги на вихід |
| **Оцінка CMRR за допусками** | $\text{CMRR} \approx \frac{1 + K_d}{4 \epsilon_{\text{tol}}}$ | $\epsilon_{\text{tol}}$ — допуск резисторів (0.01 для 1%) |
| **Інвертуючий суматор** | $U_{\text{вих}} = -R_{\text{зз}} \sum_{k=1}^n \frac{U_{\text{вх}k}}{R_k}$ | Вага кожного каналу: $k_i = R_{\text{зз}} / R_i$ |
| **Синтезований опір NIC** | $R_{\text{вх}} = -\frac{R_1 R_3}{R_2}$ | Вхідний від'ємний динамічний опір |
| **Умова стійкості NIC** | $R_г < \frac{R_1 R_3}{R_2} = \|R_{\text{вх}}\|$ | $R_г$ — внутрішній опір джерела керування |

## 8. Питання для самоперевірки

1. **Чому схеми цієї теми називаються «схемами нульового порядку» і чи залежить їх коефіцієнт передачі від частоти в ідеальному випадку?**
2. **Чому в інвертуючому підсилювачі інвертуючий вхід називають «віртуальною землею», хоча він не з'єднаний фізично з проводом GND?**
3. **Чому для вимірювання сигналів високоомних сенсорів (наприклад, pH-електродів) використовують неінвертуючу схему або буфер, а не інвертуючий підсилювач?**
4. **Яка умова повинна виконуватися для номіналів чотирьох резисторів диференційного підсилювача, щоб він ідеально віднімав напруги?**
5. **Чому інвертуючий суматор є кращим за неінвертуючий для побудови багатоканальних аудіомікшерів?**
6. **За рахунок чого інвертор імпедансу (NIC) формує від'ємний опір і що станеться зі схемою, якщо опір джерела $R_г$ перевищить $|R_{\text{вх}}|$?**
