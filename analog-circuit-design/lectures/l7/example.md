# 🧮 Приклад розв'язання задачі: Проєктування диференціального віднімача з аналізом CMRR та конвертора негативного імпедансу (NIC)

> **Курс:** Аналогова схемотехніка  
> **Тема:** Лекція 7. Підсилювальні схеми на ОП нульового порядку

## 🎯 Мета та інженерні задачі практикуму
1. Опанувати методику покрокового інженерного розрахунку **диференціального підсилювача (віднімача)** нульового порядку на ОП для вимірювання струму у верхньому плечі живлення (High-Side Current Sense).
2. Вивести аналітичну залежність та розрахувати коефіцієнт придушення синфазної складової (**CMRR**) схеми при використанні резисторів із промисловими допусками $\pm 1\%$ та прецизійними допусками $\pm 0.1\%$.
3. Розрахувати параметри **конвертора негативного імпедансу (NIC)** для синтезу від'ємного динамічного опору $R_{\text{вх}} < 0$, призначеного для компенсації омічних втрат лінії зв'язку.
4. Провести математичну перевірку **критерію стійкості** NIC-ланки при підключенні реального джерела сигналу з кінцевим внутрішнім опором $R_г$.

## 1. Постановка задачі та вихідні дані

Розглядається прецизійна аналогова система моніторингу та передачі сигналу, яка складається з двох функціональних блоків:
1. **Блок A (High-Side Current Monitor):** Диференціальний віднімач на ОП $DA_1$, який вимірює спад напруги на струмовому шунті $R_{\text{ш}} = 0.10\ \Omega$, увімкненому в шину живлення $+12.0\ \text{В}$.
2. **Блок B (Active Line Compensator):** Інвертор імпедансу (NIC) на ОП $DA_2$, призначений для компенсації паразитного опору кабельної лінії зв'язку $R_{\text{лін}} = 100\ \Omega$.

```text
       Блок A: Диференціальний віднімач (High-Side)
       
            +12 В ─────┬───[ R_ш: 0.1 Ом ]───┬────► До навантаження
                       │                     │      (I = 0..2 А)
                      ┌┴┐ R1                ┌┴┐ R3
                      │ │(10 кОм)           │ │(10 кОм)
                      └┬┘                   └┬┘
                       │                     │
                       ├──────────────┐      ├──────────────┐
                      ┌┴┐             │     ┌┴┐             │
                      │-│ DA1         │     │+│ DA1         │
                      │ ├──[ R2 ]─────┴─────┤ ├──[ R4 ]─────┴──► U_вих
                      │+│  (150 кОм)        │-│  (150 кОм)
                      └┬┘                   └┬┘
                       │                     │
                      ─┴─                   ─┴─ GND
```

```text
       Блок B: Інвертор імпедансу (NIC)
       
                R3 (1.0 кОм)
         ┌─────────[───]─────────┬─────────────────┐
         │                       │                 │
         │  i_вх                 │              ┌──┴──┐
    Вхід ┼─────────►────────────┼──────────────┤+ │DA2
    U_вх │                       │              │  ├──┴──► U_вих_ОП
        ┌┴┐                      │              │- │
     R_г│ │ (Опір                │           ┌──┴──┘
  (80 Ом)│  джерела)             │           │
        └┬┘                      ├───[ R2 ]──┘ (10 кОм)
         │                       │

                                │ │ R1 (10 кОм)
                                └┬┘
                                 │
                                ─┴─ GND
```

### Вихідні числові параметри:
* **Блок A:**
  * Напруга шини живлення: $V_{CC} = +12.0\ \text{В}$.
  * Діапазон струму навантаження: $I_{\text{нав}} = 0\dots 2.0\ \text{А}$.
  * Спад напруги на шунті: $U_d = I_{\text{нав}} \cdot R_{\text{ш}} = 0\dots 200\ \text{мВ}$.
  * Синфазна напруга: $U_{\text{вх\_CM}} \approx 12.0\ \text{В}$.
  * Бажаний діапазон вихідної напруги: $U_{\text{вих}} = 0\dots 3.0\ \text{В}$ (диференційне підсилення $K_d = 15.0$).
* **Блок B:**
  * Опір лінії передачі, що підлягає компенсації: $R_{\text{лін}} = 100\ \Omega$.
  * Необхідний вхідний опір NIC: $R_{\text{вх}} = -100\ \Omega$.
  * Внутрішній опір джерела сигналу: $R_г = 80\ \Omega$.

## 2. Покроковий розрахунок Блоку A: Диференціальний віднімач

### 2.1. Розрахунок номіналів резисторів для заданого коефіцієнта $K_d = 15.0$:
Класичне рівняння диференціального підсилювача:
$$U_{\text{вих}} = U_{\text{вх2}} \cdot \left(\frac{R_4}{R_3 + R_4}\right) \cdot \left(1 + \frac{R_2}{R_1}\right) - U_{\text{вх1}} \cdot \left(\frac{R_2}{R_1}\right)$$
Для забезпечення умови ідеального віднімання різниці напруг:
$$\frac{R_2}{R_1} = \frac{R_4}{R_3} = K_d = 15.0$$
* Вибираємо номінал вхідних резисторів: **$R_1 = R_3 = 10.0\ \text{к}\Omega$** (1%).
* Тоді резистори зворотного зв'язку та заземлення:
  $$R_2 = R_4 = K_d \cdot R_1 = 15.0 \times 10.0\ \text{к}\Omega = \mathbf{150.0\ \text{к}\Omega}$$

Перевірка діапазону вихідної напруги:
$$U_{\text{вих(max)}} = K_d \cdot U_{d(\text{max})} = 15.0 \times (2.0\ \text{А} \times 0.1\ \Omega) = 15.0 \times 0.2\ \text{В} = \mathbf{3.0\ \text{В}}$$

---

### 2.2. Аналіз послаблення синфазного сигналу (CMRR)

На входах підсилювача присутня висока постійна напруга шини живлення $U_{\text{вх\_CM}} = 12.0\ \text{В}$.

#### 1. Синфазний коефіцієнт передачі ($K_{CM}$):
$$K_{CM} = -\frac{R_2}{R_1} + \frac{R_4}{R_3 + R_4}\left(1 + \frac{R_2}{R_1}\right)$$
Припустимо, що внаслідок розкиду компонентів резистор $R_4$ відхилився на $+1\%$ ($R_4 = 151.5\ \text{к}\Omega$), а решта мають номінальні значення ($R_1 = R_3 = 10.0\ \text{к}\Omega, R_2 = 150.0\ \text{к}\Omega$):
$$\frac{R_2}{R_1} = \frac{150}{10} = 15.0$$
$$\frac{R_4}{R_3 + R_4} = \frac{151.5}{10 + 151.5} = \frac{151.5}{161.5} \approx 0.93808$$
$$1 + \frac{R_2}{R_1} = 1 + 15 = 16.0$$
$$K_{CM} = -15.0 + (0.93808 \times 16.0) = -15.0 + 15.00928 = \mathbf{+0.00928}$$

#### 2. Розрахунок CMRR схеми:
$$\text{CMRR} = \frac{K_d}{|K_{CM}|} = \frac{15.0}{0.00928} \approx \mathbf{1616.4}$$
У логарифмічному масштабі:
$$\text{CMRR}_{\text{дБ}} = 20 \lg(1616.4) \approx \mathbf{64.17\ \text{дБ}}$$

Оцінимо паразитна напругу на виході від синфазного сигналу $12.0\ \text{В}$:
$$V_{\text{вих(CM)}} = U_{\text{вх\_CM}} \cdot |K_{CM}| = 12.0\ \text{В} \times 0.00928 \approx \mathbf{111.4\ \text{мВ}}$$
> ⚠️ **Оцінка похибки:** Паразитна напруга $111.4\ \text{мВ}$ відносно максимального корисного сигналу $3.0\ \text{В}$ вносить систематичну похибку $\delta = \frac{111.4\ \text{мВ}}{3000\ \text{мВ}} \times 100\% = \mathbf{3.71\%}$, що неприпустимо для точних вимірювань!

#### 3. Перехід на прецизійні резистори з допуском $0.1\%$ ($\epsilon = 0.001$):
За оціночною інженерною формулою:
$$\text{CMRR}_{\text{res}} \approx \frac{1 + K_d}{4 \epsilon} = \frac{1 + 15}{4 \times 0.001} = \frac{16}{0.004} = \mathbf{4000} \implies 20\lg(4000) \approx \mathbf{72.04\ \text{дБ}}$$
Паразитна вихідна напруга знижується до:
$$V_{\text{вих(CM)}} = 12.0\ \text{В} \times \frac{15}{4000} = \mathbf{45.0\ \text{мВ}}$$

## 3. Покроковий розрахунок Блоку B: Конвертор негативного імпедансу (NIC)

### 3.1. Розрахунок номіналів для створення $R_{\text{вх}} = -100\ \Omega$:
Вхідний опір інвертора імпедансу описується виразом:
$$R_{\text{вх}} = -\frac{R_1 R_3}{R_2}$$
Нам необхідно забезпечити $R_{\text{вх}} = -100\ \Omega$.  
Виберемо симетричні резистори дільника негативного зворотного зв'язку:
$$R_1 = R_2 = 10.0\ \text{к}\Omega \implies \frac{R_1}{R_2} = 1.0$$
Тоді необхідний номінал резистора $R_3$:
$$R_3 = |R_{\text{вх}}| \cdot \frac{R_2}{R_1} = 100\ \Omega \times 1.0 = \mathbf{100.0\ \Omega}$$

Перевіримо вхідний опір:
$$R_{\text{вх}} = -\frac{10000 \times 100}{10000} = \mathbf{-100\ \Omega}$$

---

### 3.2. Компенсація опору кабельної лінії:
Якщо послідовно з лінією передачі $R_{\text{лін}} = 100\ \Omega$ увімкнути наш блок NIC:
$$R_{\text{екв}} = R_{\text{лін}} + R_{\text{вх}} = 100\ \Omega + (-100\ \Omega) = \mathbf{0\ \Omega}$$
Лінія зв'язку стає «надпровідною» для слабкого аналогового сигналу — сигнал передається на приймач без падіння амплітуди!

---

### 3.3. Аналіз та доведення стійкості (Stability Proof)

Джерело сигналу має внутрішній опір $R_г = 80\ \Omega$.

#### 1. Розрахунок коефіцієнтів зворотного зв'язку:
* **Канал НЗЗ (інвертуючий вхід):**
  $$\chi_{\text{НЗЗ}}^- = \frac{R_1}{R_1 + R_2} = \frac{10\ \text{к}\Omega}{10\ \text{к}\Omega + 10\ \text{к}\Omega} = \mathbf{0.50}$$
* **Канал ПЗЗ (неінвертуючий вхід через $R_г$ та $R_3$):**
  $$\chi_{\text{ПЗЗ}}^+ = \frac{R_г}{R_г + R_3} = \frac{80\ \Omega}{80\ \Omega + 100\ \Omega} = \frac{80}{180} \approx \mathbf{0.444}$$

#### 2. Перевірка критерію стійкості:
$$\chi_{\text{НЗЗ}}^- > \chi_{\text{ПЗЗ}}^+ \iff 0.50 > 0.444 \quad (\text{\textbf{Умова виконується!}})$$
Запас стійкості за петлевим фактором:
$$\Delta \chi = \chi_{\text{НЗЗ}}^- - \chi_{\text{ПЗЗ}}^+ = 0.500 - 0.444 = \mathbf{+0.056} > 0$$

Оскільки опір джерела $R_г = 80\ \Omega < |R_{\text{вх}}| = 100\ \Omega$, схема гарантовано працює в **лінійній області без самозбудження та переходу в насичення**.

> 🚨 **Що станеться при обриві кабелю ($R_г \to \infty$)?**  
> При відключенні джерела $R_г \to \infty$:
> $$\chi_{\text{ПЗЗ}}^+ \to \frac{\infty}{\infty + 100} = 1.0$$
> Тоді $\chi_{\text{ПЗЗ}}^+ = 1.0 > \chi_{\text{НЗЗ}}^- = 0.5$. Позитивний зв'язок стає домінуючим, і ОП миттєво звалюється в стан компараторного насичення (напруга на виході стрибає до $+V_{OH}$ або $-V_{OL}$).

## 5. Інженерні висновки
1. **Вирішальна роль допусків у диференціальних схемах:** Навіть при ідеальних мікросхемах розкид номіналів пасивних резисторів у $1\%$ обмежує синфазне придушення до $\approx 60\dots 65\ \text{дБ}$. Для вимірювання слабких струмів на високому потенціалі необхідно застосовувати лазерно підігнані резистивні матриці з точністю $\le 0.1\%$.
2. **Практична цінність конвертора негативного імпедансу:** NIC дозволяє повністю компенсувати омічні опори довгих провідників і датчиків, проте вимагає суворого дотримання умови $R_г < |R_{\text{вх}}|$ для запобігання самозбудженню.
