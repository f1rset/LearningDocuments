## 🎯 Мета та інженерні орієнтири
Цей збірник містить **10 практичних інженерних завдань**, які охоплюють повний спектр розрахунку та проєктування аналогових схем на ОП без реактивних елементів (нульового порядку):
* Розрахунок коефіцієнтів передачі та вхідних/вихідних опорів інвертуючого, неінвертуючого та буферного каскадів.
* Проєктування диференціальних віднімачів та оцінка придушення синфазної завади (CMRR).
* Аналіз багатоканальних інвертуючих та неінвертуючих суматорів, усунення перехресних завад.
* Синтез активного від'ємного опору за допомогою конвертора негативного імпедансу (NIC) та перевірка критерію стійкості.

---

## 🧭 Методичні вказівки до розв'язання
1. **Інвертуючий масштабуючий каскад:**
   $$K_U = -\frac{R_2}{R_1}, \quad R_{\text{вх}} = R_1, \quad R_{\text{вих}} \approx 0, \quad R_{\text{комп}} = R_1 \parallel R_2$$
2. **Неінвертуючий масштабуючий каскад:**
   $$K_U = 1 + \frac{R_2}{R_1}, \quad R_{\text{вх}} \to \infty, \quad R_{\text{вих}} \approx 0$$
3. **Диференціальний віднімач:**
   $$U_{\text{вих}} = -\frac{R_2}{R_1} U_{\text{вх1}} + \frac{R_4}{R_3 + R_4}\left(1 + \frac{R_2}{R_1}\right) U_{\text{вх2}}$$
   За умови балансу $\frac{R_2}{R_1} = \frac{R_4}{R_3} = K_d \implies U_{\text{вих}} = K_d (U_{\text{вх2}} - U_{\text{вх1}})$.
4. **Синфазний коефіцієнт та CMRR:**
   $$K_{CM} = -\frac{R_2}{R_1} + \frac{R_4}{R_3 + R_4}\left(1 + \frac{R_2}{R_1}\right), \quad \text{CMRR} = \left|\frac{K_d}{K_{CM}}\right| \approx \frac{1 + K_d}{4\epsilon_{\text{tol}}}$$
5. **Інвертуючий суматор:**
   $$U_{\text{вих}} = -R_{\text{зз}} \sum_{i=1}^n \frac{U_{\text{вх}i}}{R_i}$$
6. **Інвертор негативного імпедансу (NIC):**
   $$R_{\text{вх}} = -\frac{R_1 R_3}{R_2} < 0, \quad \text{Умова стійкості: } R_г < |R_{\text{вх}}|$$

## 📋 Набір практичних завдань

### 🔹 Рівень 1: Масштабні підсилювачі та буфери

---

#### Завдання 1: Класичний інвертуючий підсилювач та балансування струмів
Спроєктовано інвертуючий підсилювач із номіналами резисторів $R_1 = 4.7\ \text{к}\Omega$ та $R_2 = 47.0\ \text{к}\Omega$. На вхід подається постійна напруга $U_{\text{вх}} = +0.50\ \text{В}$.

```text
               R1 (4.7 кОм)             R2 (47 кОм)
   U_вх ─────────[───]────────┬────────────[───]─────────────┐
                              │                              │
                             ┌┴┐                             │
                             │-│                             │
                             │ ├─────────────────────────────┴──► U_вих
                             │+│
                             └┬┘
                              │
                             ┌┴┐ R_комп
                             └┬┘
                              │
                             ─┴─ GND
```

* **Вихідні дані:**
  * $R_1 = 4.7\ \text{к}\Omega$, $R_2 = 47.0\ \text{к}\Omega$, $U_{\text{вх}} = +0.50\ \text{В}$.
* **Завдання:**
  1. Розрахувати коефіцієнт підсилення за напругою $K_U$ та вихідну напругу $U_{\text{вих}}$.
  2. Знайти вхідний опір каскаду $R_{\text{вх}}$ та струм $i_{\text{вх}}$, що споживається від джерела сигналу.
  3. Визначити номінал компенсаційного резистора $R_{\text{комп}}$, який необхідно підключити до неінвертуючого входу для усунення похибки від вхідного струму зміщення $I_{IB}$.
* 💡 **Підказка:** $R_{\text{вх}} = R_1$, $R_{\text{комп}} = R_1 \parallel R_2$.

---

#### Завдання 2: Неінвертуючий підсилювач для високоомного сенсора
П'єзоелектричний датчик тиску має високий внутрішній опір $R_{\text{дж}} = 500\ \text{к}\Omega$ і генерує сигнал $U_{\text{дат}} = 150\ \text{мВ}$. Необхідно підсилити цей сигнал до рівня $U_{\text{вих}} = 1.50\ \text{В}$. Резистор нижнього плеча дільника обрано $R_1 = 3.3\ \text{к}\Omega$.

* **Вихідні дані:**
  * $U_{\text{дат}} = 150\ \text{мВ}$, $R_{\text{дж}} = 500\ \text{к}\Omega$, бажаний $U_{\text{вих}} = 1.50\ \text{В}$, $R_1 = 3.3\ \text{к}\Omega$.
* **Завдання:**
  1. Розрахувати необхідний коефіцієнт підсилення $K_U$.
  2. Знайти опір резистора зворотного зв'язку $R_2$.
  3. Пояснити, чому використання інвертуючого підсилювача з $R_1 = 10\ \text{к}\Omega$ замість неінвертуючого призвело б до падіння вихідного сигналу практично до нуля (ефект навантаження).
* 💡 **Підказка:** $K_U = 1 + \frac{R_2}{R_1} \implies R_2 = (K_U - 1) R_1$.

---

#### Завдання 3: Буферний повторювач напруги під навантаженням
Буфер на ОП працює при вхідній напрузі $U_{\text{вх}} = 3.30\ \text{В}$ і навантажений на опір $R_н = 200\ \Omega$. Власний коефіцієнт підсилення ОП без зворотного зв'язку $A_0 = 50\,000$ ($94\ \text{дБ}$), а вихідний опір розімкненого ОП становить $R_{\text{out(open)}} = 75\ \Omega$.

* **Вихідні дані:**
  * $U_{\text{вх}} = 3.30\ \text{В}$, $R_н = 200\ \Omega$, $A_0 = 50\,000$, $R_{\text{out(open)}} = 75\ \Omega$.
* **Завдання:**
  1. Розрахувати вихідний опір повторювача із замкненим зворотним зв'язком $R_{\text{вих}} = \frac{R_{\text{out(open)}}}{1 + A_0}$.
  2. Знайти просідання вихідної напруги $\Delta U_{\text{вих}}$ під дією навантаження $R_н$.
  3. Розрахувати відносну похибку передачі напруги під навантаженням $\delta = \frac{U_{\text{вх}} - U_{\text{вих}}}{U_{\text{вх}}} \times 100\%$.
* 💡 **Підказка:** $\Delta U_{\text{вих}} \approx U_{\text{вх}} \frac{R_{\text{вих}}}{R_н}$.

### 🔹 Рівень 2: Диференціальні віднімачі та аналогові суматори

---

#### Завдання 4: Прецизійний диференціальний віднімач
Спроєктовано диференціальний підсилювач із номіналами $R_1 = R_3 = 10.0\ \text{к}\Omega$ та $R_2 = R_4 = 68.0\ \text{к}\Omega$. На входи подаються напруги: $U_{\text{вх1}} = 2.45\ \text{В}$, $U_{\text{вх2}} = 2.65\ \text{В}$.

```text
                 R1 (10 кОм)
   U_вх1 ─────────[───]────────┬───────────────────┐
                               │                   │
                              ┌┴┐                  │
                              │-│                  │
                              │ ├───[ R2: 68 кОм ]─┴────► U_вих
                              │+│
                              └┬┘
   U_вх2 ─────────[───]────────┤
                 R3 (10 кОм)   │
                              ┌┴┐
                              │ │ R4 (68 кОм)
                              └┬┘
                               │
                              ─┴─ GND
```

* **Вихідні дані:**
  * $R_1 = R_3 = 10.0\ \text{к}\Omega$, $R_2 = R_4 = 68.0\ \text{к}\Omega$, $U_{\text{вх1}} = 2.45\ \text{В}$, $U_{\text{вх2}} = 2.65\ \text{В}$.
* **Завдання:**
  1. Розрахувати диференційний коефіцієнт підсилення $K_d$.
  2. Знайти вихідну напругу $U_{\text{вих}}$.
  3. Визначити диференційний вхідний опір між клемами входу 1 та входу 2: $R_{\text{diff}} = R_1 + R_3$.
* 💡 **Підказка:** $U_{\text{вих}} = \frac{R_2}{R_1}(U_{\text{вх2}} - U_{\text{вх1}})$.

---

#### Завдання 5: Погіршення CMRR через технологічний розкид резисторів
У диференціальному підсилювачі із номінальним коефіцієнтом $K_d = 20.0$ ($R_1 = R_3 = 10\ \text{к}\Omega, R_2 = R_4 = 200\ \text{к}\Omega$) внаслідок похибки резистор $R_4$ має значення $R_4 = 202.0\ \text{к}\Omega$ (відхилення $+1\%$), а інші резистори ідеальні. На вхід діє синфазна завада $U_{\text{вх\_CM}} = 5.0\ \text{В}$.

* **Вихідні дані:**
  * $R_1 = R_3 = 10.0\ \text{к}\Omega$, $R_2 = 200.0\ \text{к}\Omega$, $R_4 = 202.0\ \text{к}\Omega$, $U_{\text{вх\_CM}} = 5.0\ \text{В}$.
* **Завдання:**
  1. Розрахувати фактичний коефіцієнт передачі синфазного сигналу $K_{CM} = -\frac{R_2}{R_1} + \frac{R_4}{R_3 + R_4}\left(1 + \frac{R_2}{R_1}\right)$.
  2. Знайти значення $\text{CMRR}$ та перевести його в децибели.
  3. Обчислити амплітуду паразитної напруги на виході $V_{\text{вих(CM)}}$.
* 💡 **Підказка:** $\text{CMRR} = \frac{K_d}{|K_{CM}|}$.

---

#### Завдання 6: Трьохвходовий інвертуючий суматор
Схема суматора на ОП має резистор зворотного зв'язку $R_{\text{зз}} = 100.0\ \text{к}\Omega$ та три вхідні резистори: $R_1 = 10.0\ \text{к}\Omega$, $R_2 = 20.0\ \text{к}\Omega$, $R_3 = 50.0\ \text{к}\Omega$. На входи подано напруги: $U_1 = +0.50\ \text{В}$, $U_2 = -1.00\ \text{В}$, $U_3 = +2.00\ \text{В}$.

* **Вихідні дані:**
  * $R_{\text{зз}} = 100.0\ \text{к}\Omega$, $R_1 = 10.0\ \text{к}\Omega$, $R_2 = 20.0\ \text{к}\Omega$, $R_3 = 50.0\ \text{к}\Omega$.
  * $U_1 = +0.50\ \text{В}$, $U_2 = -1.00\ \text{В}$, $U_3 = +2.00\ \text{В}$.
* **Завдання:**
  1. Знайти вагові коефіцієнти кожного входу: $k_1 = \frac{R_{\text{зз}}}{R_1}$, $k_2 = \frac{R_{\text{зз}}}{R_2}$, $k_3 = \frac{R_{\text{зз}}}{R_3}$.
  2. Розрахувати вихідну напругу $U_{\text{вих}} = -(k_1 U_1 + k_2 U_2 + k_3 U_3)$.
  3. Знайти сумарний струм $i_{\text{зз}}$, що втікає у вузол віртуальної землі інвертуючого входу.
* 💡 **Підказка:** $i_{\text{зз}} = \frac{U_1}{R_1} + \frac{U_2}{R_2} + \frac{U_3}{R_3}$.

---

#### Завдання 7: Неінвертуючий суматор-усереднювач (Average Circuit)
Чотири аналогові датчики формують напруги: $U_1 = 1.0\ \text{В}$, $U_2 = 2.0\ \text{В}$, $U_3 = 3.0\ \text{В}$, $U_4 = 4.0\ \text{В}$. Для обчислення середнього арифметичного сигналу використовується неінвертуючий суматор із чотирма однаковими резисторами $R_{31} = R_{32} = R_{33} = R_{34} = 20.0\ \text{к}\Omega$ ($R_4 = \infty$).

* **Вихідні дані:**
  * $n = 4$, $R_{3i} = 20.0\ \text{к}\Omega$, $R_4 = \infty$.
  * Вхідні напруги: $1.0\ \text{В}, 2.0\ \text{В}, 3.0\ \text{В}, 4.0\ \text{В}$.
* **Завдання:**
  1. Знайти потенціал на неінвертуючому вході ОП $U_+$.
  2. Визначити співвідношення резисторів зворотного зв'язку $R_2 / R_1$, щоб підсилювач видавав точне середнє арифметичне значення ($U_{\text{вих}} = \overline{U}$).
  3. Яким має бути співвідношення $R_2 / R_1$, щоб схема видавала точну алгебраїчну суму всіх сигналів ($U_{\text{вих}} = \sum_{i=1}^4 U_i = 10.0\ \text{В}$)?
* 💡 **Підказка:** $U_+ = \frac{\sum U_i}{n}$. Для середнього потрібно $K_U = 1$ ($R_2 = 0$). Для суми потрібно $K_U = n \implies 1 + \frac{R_2}{R_1} = n$.

#### Завдання 8: Диференціальний сумуючий підсилювач (Суматор-віднімач)
Необхідно реалізувати аналогове обчислення виразу:
$$U_{\text{вих}} = 2.0 \cdot (U_1^+ + U_2^+) - 2.0 \cdot (U_1^- + U_2^-)$$
Схема містить по два входи на кожному полюсі ($n = m = 2$). Номінал резистора зворотного зв'язку $R_2 = 20.0\ \text{к}\Omega$, а резистор на землю $R_4 = 20.0\ \text{к}\Omega$.

* **Вихідні дані:**
  * $R_2 = R_4 = 20.0\ \text{к}\Omega$. Бажаний коефіцієнт для кожного сигналу: $K = 2.0$.
  * Сигнали: $U_1^+ = 1.5\ \text{В}$, $U_2^+ = 2.5\ \text{В}$, $U_1^- = 0.8\ \text{В}$, $U_2^- = 1.2\ \text{В}$.
* **Завдання:**
  1. Розрахувати необхідні номінали вхідних резисторів $R_{11}, R_{12}, R_{31}, R_{32}$.
  2. Перевірити виконання умови балансу вагових коефіцієнтів.
  3. Розрахувати чисельне значення вихідної напруги $U_{\text{вих}}$.
* 💡 **Підказка:** $K_i = \frac{R_2}{R_{1i}} = 2.0 \implies R_{1i} = R_2 / 2.0$.

---

#### Завдання 9: Розрахунок конвертора негативного імпедансу (NIC)
Схема конвертора негативного імпедансу містить резистори дільника $R_1 = 20.0\ \text{к}\Omega$, $R_2 = 10.0\ \text{к}\Omega$ та вихідний резистор $R_3 = 470.0\ \Omega$.

```text
                  R3 (470 Ом)
        ┌────────[───]────────┬────────────────┐
        │                     │                │
        │  i_вх               │             ┌──┴──┐
   Вхід ┼────────►───────────┼─────────────┤+ │  │
   U_вх │                     │             │  ├──┴──► U_вих_ОП
  (1 В) │                     │             │- │
        │                     │          ┌──┴──┘
        │                     │          │
        │                     ├───[ R2 ]─┘ (10 кОм)
        │                     │
       ─┴─ GND               ┌┴┐
                             │ │ R1 (20 кОм)
                             └┬┘
                              │
                             ─┴─ GND
```

* **Вихідні дані:**
  * $R_1 = 20.0\ \text{к}\Omega$, $R_2 = 10.0\ \text{к}\Omega$, $R_3 = 470.0\ \Omega$.
  * Прикладена вхідна напруга: $U_{\text{вх}} = +1.00\ \text{В}$.
* **Завдання:**
  1. Розрахувати еквівалентний вхідний динамічний опір схеми $R_{\text{вх}} = -\frac{R_1 R_3}{R_2}$.
  2. Знайти вихідну напругу операційного підсилювача $U_{\text{вих\_ОП}}$.
  3. Знайти струм $i_{\text{вх}}$ та вказати його реальний напрямок руху.
* 💡 **Підказка:** $U_{\text{вих\_ОП}} = \left(1 + \frac{R_2}{R_1}\right) U_{\text{вх}}$. Вхідний струм: $i_{\text{вх}} = \frac{U_{\text{вх}}}{R_{\text{вх}}}$.

---

#### Завдання 10: Дослідження стійкості інвертора імпедансу при зміні опору джерела $R_г$
Конвертор негативного імпедансу має синтезований опір $R_{\text{вх}} = -500\ \Omega$ ($R_1 = 10\ \text{к}\Omega, R_2 = 10\ \text{к}\Omega, R_3 = 500\ \Omega$). До його входу підключається джерело сигналу з регульованим внутрішнім опором $R_г$.

* **Вихідні дані:**
  * $R_1 = 10.0\ \text{к}\Omega$, $R_2 = 10.0\ \text{к}\Omega$, $R_3 = 500.0\ \Omega$ ($|R_{\text{вх}}| = 500\ \Omega$).
* **Завдання:**
  1. Розрахувати коефіцієнт зворотного зв'язку за інвертуючим входом $\chi_{\text{НЗЗ}}^- = \frac{R_1}{R_1 + R_2}$.
  2. Розрахувати коефіцієнт $\chi_{\text{ПЗЗ}}^+ = \frac{R_г}{R_г + R_3}$ для трьох випадків опору джерела:
     * Варіант A: $R_г = 250\ \Omega$;
     * Варіант B: $R_г = 500\ \Omega$;
     * Варіант C: $R_г = 1000\ \Omega$.
  3. Для кожного випадку визначити стан системи (стійка лінійна робота, межа стійкості чи нестійкість із переходом у насичення).
* 💡 **Підказка:** Умова стійкості: $\chi_{\text{НЗЗ}}^- > \chi_{\text{ПЗЗ}}^+ \iff R_г < |R_{\text{вх}}|$.
