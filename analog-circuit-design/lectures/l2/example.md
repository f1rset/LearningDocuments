## 🎯 Мета та інженерні задачі практикуму
1. Опанувати методику інженерного розрахунку схеми зміщення за постійним струмом (DC Biasing) біполярного транзистора (BJT) з **дільником напруги в базі та емітерною термостабілізацією**.
2. Побудувати **лінію навантаження за постійним струмом (DC Load Line)** та вибрати положення точки спокою $Q$ для забезпечення максимального симетричного розмаху вихідної напруги.
3. Розрахувати номінали пасивних компонентів схеми ($R_1, R_2, R_c, R_e$) зі стандартного ряду номіналів E24.
4. Дослідити температурну стабільність струму колектора та чутливість схеми до технологічного розкиду коефіцієнта підсилення за струмом $\beta$.
5. Розрахувати ємність блокувального конденсатора емітера $C_e$ для заданої нижньої граничної частоти $f_н$.

## 1. Постановка задачі та технічні вимоги

Необхідно спроєктувати та розрахувати вхідний підсилювальний каскад попереднього підсилювача класу A на кремнієвому NPN транзисторі BC547B.

```text
               +V_CC (+12 В)
                 │
                 ├───[ R1 ]────────────┬───[ R_c ]───┬─────────┤├───► U_вих
                 │                     │             │        C_out
                 │                     │          ┌──┴──┐
                 │                     │          │ VT1 │ BJT (NPN)
                 │                     ├──────────┤     │
                 │                     │          └──┬──┘
                 │                     │             ├───[ R_e ]───┬──────┐
                 │                     │             │             │      │
                 └───[ R2 ]────────────┘            ─┴─ C_e        │     ─┴─ GND
                 │                                  GND            │
                ─┴─ GND                                           ─┴─ GND
```

### Вихідні вимоги:
* Напруга джерела живлення: $V_{CC} = 12.0\ \text{В}$.
* Постійний струм колектора в точці спокою: $I_{C0} = 2.0\ \text{мА}$.
* Бажаний максимальний неспотворений розмах напруги на колекторі: симетричний відносно точки спокою ($V_{p-p\text{ max}}$).
* Падіння напруги на емітерному резисторі: $U_{E0} \approx 10\dots 15\%$ від $V_{CC}$ (приймаємо $U_{E0} = 1.5\ \text{В}$).
* Параметри транзистора BC547B при $T = 25^\circ\text{C}$:
  * Напруга база-емітер: $U_{BE0} = 0.65\ \text{В}$.
  * Коефіцієнт передачі струму бази: $\beta_{\text{typ}} = 200$ (технологічний розкид $\beta_{\text{min}} = 110$, $\beta_{\text{max}} = 450$).
  * Гранична напруга насичення: $U_{CE(\text{sat})} \approx 0.2\ \text{В}$.
* Нижня робоча частота підсилювача: $f_н = 20\ \text{Гц}$.

## 2. Покроковий інженерний розрахунок

### 2.1. Вибір напруги точки спокою $U_{CE0}$ та розрахунок навантажувальних резисторів
Для забезпечення максимального розмаху змінної напруги без обмеження (clipping) напруга точки спокою $U_{CE0}$ повинна знаходитися приблизно посередині між напругою насичення $U_{CE(\text{sat})}$ та доступною напругою живлення за вирахуванням падіння на емітері:
$$U_{C0} = U_{E0} + U_{CE0} \approx \frac{V_{CC} + U_{E0}}{2} = \frac{12.0\ \text{В} + 1.5\ \text{В}}{2} = 6.75\ \text{В}$$
Приймаємо зручне інженерне значення напруги спокою на колекторі:
$$U_{C0} = 7.0\ \text{В} \implies U_{CE0} = U_{C0} - U_{E0} = 7.0\ \text{В} - 1.5\ \text{В} = \mathbf{5.5\ \text{В}}$$

#### Розрахунок резистора емітера $R_e$:
Струм емітера:
$$I_{E0} = I_{C0} \cdot \frac{\beta + 1}{\beta} = 2.0\ \text{мА} \cdot \frac{201}{200} \approx 2.01\ \text{мА} \approx I_{C0}$$
Опір емітера:
$$R_e = \frac{U_{E0}}{I_{E0}} = \frac{1.5\ \text{В}}{2.01 \cdot 10^{-3}\ \text{А}} = 746.3\ \Omega$$
Вибираємо найближчий стандартний номінал з ряду **E24**: **$R_e = 750\ \Omega$** (1%).  
Уточнена напруга емітера: $U_{E0} = 2.01\ \text{мА} \times 750\ \Omega = \mathbf{1.508\ \text{В}}$.

#### Розрахунок резистора колектора $R_c$:
Падіння напруги на резисторі $R_c$:
$$U_{Rc} = V_{CC} - U_{C0} = 12.0\ \text{В} - 7.0\ \text{В} = 5.0\ \text{В}$$
Опір колектора:
$$R_c = \frac{U_{Rc}}{I_{C0}} = \frac{5.0\ \text{В}}{2.0 \cdot 10^{-3}\ \text{А}} = 2500\ \Omega = 2.5\ \text{к}\Omega$$
Вибираємо номінал з ряду **E24**: **$R_c = 2.4\ \text{к}\Omega$** або **$R_c = 2.7\ \text{к}\Omega$**. Приймемо **$R_c = 2.4\ \text{к}\Omega$**.  
Тоді напруга на колекторі:
$$U_{C0} = V_{CC} - I_{C0} R_c = 12.0\ \text{В} - (2.0\ \text{мА} \times 2.4\ \text{к}\Omega) = 12.0 - 4.8 = \mathbf{7.2\ \text{В}}$$
$$U_{CE0} = U_{C0} - U_{E0} = 7.2\ \text{В} - 1.51\ \text{В} = \mathbf{5.69\ \text{В}}$$

---

### 2.2. Побудова лінії навантаження за постійним струмом (DC Load Line)
Рівняння вихідного кола за другим законом Кірхгофа:
$$V_{CC} = I_C R_c + U_{CE} + I_E R_e \approx U_{CE} + I_C (R_c + R_e)$$
Звідси рівняння прямої лінії:
$$I_C = \frac{V_{CC} - U_{CE}}{R_c + R_e}$$

```text
       I_C (mA)
         ▲
         │
  3.81 ──┼─── Струм насичення I_C(sat) = V_CC / (R_c + R_e)
         │   \
         │     \
  2.00 ──┼───────*── Робоча точка Q (U_CE0 = 5.69 В, I_C0 = 2.0 мА)
         │        │ \
         │        │   \
         │        │     \
         └────────┴───────┴────────► U_CE (В)
                 5.69    12.0 (Напруга відсічки U_CE(cut) = V_CC)
```

1. **Точка відсічки (Cut-off):** $I_C = 0 \implies U_{CE(\text{cut})} = V_{CC} = \mathbf{12.0\ \text{В}}$.
2. **Точка насичення (Saturation):** $U_{CE} = 0 \implies I_{C(\text{sat})} = \frac{V_{CC}}{R_c + R_e} = \frac{12.0\ \text{В}}{2400\ \Omega + 750\ \Omega} = \frac{12.0}{3150} \approx \mathbf{3.81\ \text{мА}}$.
3. **Робоча точка $Q$:** $U_{CE0} = 5.69\ \text{В},\ I_{C0} = 2.0\ \text{мА}$. Вона лежить практично посередині лінії навантаження ($5.69\ \text{В} \approx 12\ \text{В} / 2$).

---

### 2.3. Розрахунок дільника базового зміщення ($R_1, R_2$)
Напруга на базі відносно землі:
$$U_{B0} = U_{E0} + U_{BE0} = 1.508\ \text{В} + 0.650\ \text{В} = \mathbf{2.158\ \text{В}}$$

Струм бази транзистора в точці спокою (для типового $\beta = 200$):
$$I_{B0} = \frac{I_{C0}}{\beta} = \frac{2.0\ \text{мА}}{200} = 10\ \mu\text{A}$$

#### Правило "жорсткого дільника" (Stiff Voltage Divider):
Щоб коливання струму бази не зсували потенціал бази, струм дільника $I_{\text{діл}}$ (струм через резистор $R_2$) вибирають у $10$ разів більшим за струм бази:
$$I_{\text{діл}} \ge 10 \cdot I_{B0} = 10 \times 10\ \mu\text{A} = 100\ \mu\text{A} = 0.1\ \text{мА}$$

Розрахунок номіналу нижнього плеча $R_2$:
$$R_2 = \frac{U_{B0}}{I_{\text{діл}}} = \frac{2.158\ \text{В}}{0.1 \cdot 10^{-3}\ \text{А}} = 21.58\ \text{к}\Omega$$
Вибираємо стандартний номінал **E24**: **$R_2 = 22\ \text{к}\Omega$**.  
Фактичний струм через $R_2$:
$$I_{R2} = \frac{2.158\ \text{В}}{22\ \text{к}\Omega} \approx 98.1\ \mu\text{A}$$

Розрахунок номіналу верхнього плеча $R_1$:
Струм через резистор $R_1$ є сумою струму дільника та струму бази:
$$I_{R1} = I_{R2} + I_{B0} = 98.1\ \mu\text{A} + 10.0\ \mu\text{A} = 108.1\ \mu\text{A}$$
$$R_1 = \frac{V_{CC} - U_{B0}}{I_{R1}} = \frac{12.0\ \text{В} - 2.158\ \text{В}}{108.1 \cdot 10^{-6}\ \text{А}} = \frac{9.842\ \text{В}}{108.1\ \mu\text{A}} \approx 91.04\ \text{к}\Omega$$
Вибираємо стандартний номінал **E24**: **$R_1 = 91\ \text{к}\Omega$**.

---

### 2.4. Перевірка методом еквівалентного генератора Тевеніна
Перетворимо базове коло дільника на еквівалентне джерело Тевеніна ($E_b, R_b$):
$$E_b = V_{CC} \cdot \frac{R_2}{R_1 + R_2} = 12.0\ \text{В} \cdot \frac{22\ \text{к}\Omega}{91\ \text{к}\Omega + 22\ \text{к}\Omega} = 12.0 \cdot \frac{22}{113} \approx \mathbf{2.336\ \text{В}}$$
$$R_b = R_1 \parallel R_2 = \frac{91 \cdot 22}{91 + 22} = \frac{2002}{113} \approx \mathbf{17.72\ \text{к}\Omega}$$

Застосуємо рівняння Кірхгофа для вхідного контуру:
$$E_b = I_B R_b + U_{BE0} + I_E R_e = I_B R_b + U_{BE0} + (\beta + 1) I_B R_e$$
$$I_B = \frac{E_b - U_{BE0}}{R_b + (\beta + 1) R_e}$$
$$I_{C0} = \beta I_B = \frac{E_b - U_{BE0}}{\frac{R_b}{\beta} + \frac{\beta + 1}{\beta} R_e} \approx \frac{E_b - U_{BE0}}{R_e + \frac{R_b}{\beta}}$$

Підставимо значення для трьох випадків коефіцієнта підсилення $\beta$:
1. **При $\beta = 200$ (номінальне значення):**
   $$I_{C0} = \frac{2.336\ \text{В} - 0.65\ \text{В}}{750\ \Omega + \frac{17720\ \Omega}{200}} = \frac{1.686\ \text{В}}{750 + 88.6\ \Omega} = \frac{1.686}{838.6} \approx \mathbf{2.01\ \text{мА}} \quad (\text{відхилення } +0.5\%)$$
2. **При $\beta = 110$ ($\beta_{\text{min}}$):**
   $$I_{C0} = \frac{1.686\ \text{В}}{750\ \Omega + \frac{17720\ \Omega}{110}} = \frac{1.686\ \text{В}}{750 + 161.1\ \Omega} = \frac{1.686}{911.1} \approx \mathbf{1.85\ \text{мА}} \quad (\text{зміна } -8.0\%)$$
3. **При $\beta = 450$ ($\beta_{\text{max}}$):**
   $$I_{C0} = \frac{1.686\ \text{В}}{750\ \Omega + \frac{17720\ \Omega}{450}} = \frac{1.686\ \text{В}}{750 + 39.4\ \Omega} = \frac{1.686}{789.4} \approx \mathbf{2.14\ \text{мА}} \quad (\text{зміна } +6.5\%)$$

> 💡 **Висновок щодо стабільності:** Навіть при чотирикратному розкиді $\beta$ (від $110$ до $450$) струм колектора змінюється лише в межах $\pm 8\%$. Схема зміщення є високоефективною та стійкою.

### 2.5. Фактор стабільності та температурний дрейф
Фактор термостабільності струму витоку $S_I = \frac{\partial I_C}{\partial I_{CB0}}$:
$$S_I = \frac{1 + \frac{R_b}{R_e}}{1 + \frac{R_b}{(\beta + 1) R_e}} \approx \frac{1 + \frac{17.72}{0.75}}{1 + \frac{17.72}{201 \cdot 0.75}} = \frac{1 + 23.63}{1 + 0.117} = \frac{24.63}{1.117} \approx \mathbf{22.0}$$
*(Для порівняння: у нетермостабілізованій схемі з фіксованим струмом бази $S_I = \beta + 1 = 201$, тобто стабільність даної схеми майже в 10 разів краща).*

Зміна напруги $U_{BE}$ з температурою: $\frac{d U_{BE}}{d T} \approx -2.0\ \text{мВ}/^\circ\text{C}$.  
При нагріванні кристала на $\Delta T = +50^\circ\text{C}$:
$$\Delta U_{BE} = -2.0\ \text{мВ}/^\circ\text{C} \times 50^\circ\text{C} = -100\ \text{мВ} = -0.1\ \text{В}$$
Температурний приріст струму колектора:
$$\Delta I_C \approx \frac{-\Delta U_{BE}}{R_e + \frac{R_b}{\beta}} = \frac{0.1\ \text{В}}{838.6\ \Omega} \approx \mathbf{0.119\ \text{мА}} \quad (+5.9\%)$$

---

### 2.6. Розрахунок ємності блокувального конденсатора емітера $C_e$
Щоб резистор $R_e$ не зменшував коефіцієнт підсилення змінного сигналу за рахунок негативного зворотного зв'язку, його шунтують конденсатором $C_e$.  
Малосигнальний опір емітера транзистора:
$$r_e = \frac{V_T}{I_{E0}} = \frac{26\ \text{мВ}}{2.01\ \text{мА}} \approx \mathbf{12.9\ \Omega}$$
Еквівалентний імпеданс, який бачить конденсатор $C_e$:
$$R_{te} = R_e \parallel \left( r_e + \frac{R_b \parallel R_{\text{дж}}}{\beta + 1} \right)$$
Якщо внутрішній опір джерела $R_{\text{дж}} \approx 0$:
$$R_{te} \approx R_e \parallel r_e \approx 750\ \Omega \parallel 12.9\ \Omega \approx 12.7\ \Omega$$

Інженерне емпіричне правило для запобігання втратам підсилення на нижній граничній частоті $f_н = 20\ \text{Гц}$ ($X_{Ce} \le 0.1 \cdot R_e$ або строго $X_{Ce}(f_н) \le r_e$):
$$C_e \ge \frac{1}{2\pi \cdot f_н \cdot r_e} = \frac{1}{2\pi \cdot 20\ \text{Гц} \cdot 12.9\ \Omega} = \frac{1}{1621} \approx 6.17 \cdot 10^{-4}\ \text{Ф} \approx 620\ \mu\text{F}$$
Якщо закласти допустимий спад $-3\text{ дБ}$ на частоті $f_н = 20\ \text{Гц}$ виключно за рахунок $C_e$:
$$C_e = \frac{1}{2\pi \cdot f_н \cdot R_{te}} = \frac{1}{2\pi \cdot 20 \cdot 12.7} \approx \mathbf{626\ \mu\text{F}}$$
Вибираємо стандартний електролітичний конденсатор: **$C_e = 470\dots 1000\ \mu\text{F}$ (напруга $\ge 6.3\ \text{В}$)**, приймемо **$C_e = 470\ \mu\text{F}$** або **$1000\ \mu\text{F}$**.

### 2.7. Енергетичні характеристики: Потужність, розмах сигналу та ККД
1. **Потужність, споживана від джерела живлення:**
   $$P_{\text{спож}} = V_{CC} \cdot (I_{C0} + I_{R1}) = 12.0\ \text{В} \cdot (2.0\ \text{мА} + 0.11\ \text{мА}) \approx \mathbf{25.3\ \text{мВт}}$$
2. **Розсіювана потужність на колекторі транзистора в режимі спокою:**
   $$P_C = U_{CE0} \cdot I_{C0} = 5.69\ \text{В} \cdot 2.0\ \text{мА} = \mathbf{11.38\ \text{мВт}}$$
   *(Максимально допустима для BC547B: $P_{C(\text{max})} = 500\ \text{мВт}$, запас надійності понад 40 разів).*
3. **Максимальний розмах вихідної змінної напруги без обмеження ($V_{p-p\text{ max}}$):**
   * Вгору: $U_{C(\text{max})} = V_{CC} = 12.0\ \text{В} \implies \Delta U_+ = 12.0 - 7.2 = 4.8\ \text{В}$.
   * Вниз: $U_{C(\text{min})} = U_{E0} + U_{CE(\text{sat})} = 1.51 + 0.2 = 1.71\ \text{В} \implies \Delta U_- = 7.2 - 1.71 = 5.49\ \text{В}$.
   * Симетричний максимальний розмах:
     $$V_{p-p\text{ max}} = 2 \cdot \min(\Delta U_+, \Delta U_-) = 2 \times 4.8\ \text{В} = \mathbf{9.6\ \text{В}}$$
4. **Максимальний ККД підсилювача класу A:**
   $$P_{\sim(\text{max})} = \frac{(V_{p-p\text{ max}} / 2)^2}{2 R_c} = \frac{(4.8\ \text{В})^2}{2 \times 2400\ \Omega} = \frac{23.04}{4800} = 4.8\ \text{мВт}$$
   $$\eta = \frac{P_{\sim(\text{max})}}{P_{\text{спож}}} = \frac{4.8\ \text{мВт}}{25.3\ \text{мВт}} \approx \mathbf{18.97\%}$$
   *(Повністю відповідає теоретичній межі для резистивного навантаження $\eta \le 25\%$).*

## 4. Інженерні висновки
1. **Ефективність емітерної термостабілізації:** Наявність падіння напруги $U_E \approx 1.5\ \text{В}$ на резисторі $R_e$ забезпечує автоматичну компенсацію температурного дрейфу $U_{BE}$ (зі зростанням температури струм $I_C$ намагається зрости, що підвищує $U_E$ і тим самим автоматично знижує напругу $U_{BE} = U_B - U_E$, стабілізуючи струм).
2. **Вибір струму дільника:** Вибір $I_{\text{діл}} \approx 10 I_B$ гарантує стабільність робочої точки при заміні транзисторів без підбору за коефіцієнтом $\beta$.
3. **Роль $C_e$:** Конденсатор $C_e$ усуває резистивний зворотний зв'язок на змінному струмі, відновлюючи крутизну каскаду до значення $g_m \approx 77\ \text{мА/В}$.
