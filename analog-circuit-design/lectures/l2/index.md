## 🎯 Мета та ключові питання лекції
1. **Підсилювачі електричних сигналів:** Визначення, призначення (підсилення потужності, узгодження навантаження), класифікація за діапазоном частот і формою сигналу.
2. **Макромодель підсилювача та схемні функції:** Підсилювач як чотириполюсник, коефіцієнти передачі напруги ($K_U$), струму ($K_I$), передавальний імпеданс ($Z_{\text{пер}}$) і адміттанс ($Y_{\text{пер}}$), вхідний та вихідний опори під навантаженням.
3. **Основні характеристики підсилювачів:** Амплітудна характеристика та динамічний діапазон ($D$), АЧХ і смуга пропускання (рівень -3 дБ), ФЧХ, перехідна ($h(t)$) та імпульсна ($g(t)$) характеристики.
4. **Класи підсилення (Classes of Operation):** Режими A, AB, B, C, D — кути відсічки ($\theta$), енергетична ефективність (ККД / $\eta$), лінійність та спотворення.
5. **Схеми забезпечення статичного режиму (DC Biasing) BJT:** Лінія навантаження за постійним струмом (DC Load Line), схема з фіксованим струмом бази, схема з дільником напруги та емітерною термостабілізацією, схема з колекторним автозміщенням.
6. **Схеми забезпечення статичного режиму (DC Biasing) JFET:** Схема автоматичного зміщення за рахунок струму витоку (Source Self-Bias).

## 1. Підсилювачі електричних сигналів (Electronic Amplifiers)

### 1.1. Визначення та фундаментальний принцип роботи
**Підсилювач (Amplifier)** — це радіоелектронний пристрій, призначений для збільшення потужності вхідного електричного сигналу за рахунок енергії зовнішнього джерела живлення постійного струму (Power Supply / $V_{CC}, V_{DD}$).

> 💡 **Інтуїція:**
> Підсилювач не генерує енергію «з нічого». Активний елемент (транзистор) діє як швидкодіючий «керований кран» (реостат), який модулює потужний потік енергії від джерела живлення відповідно до слабкого вхідного керівного сигналу.

```text
                  Джерело живлення (+Vcc)
                           │
                           ▼
  Вхідний сигнал       ┌────────────┐       Вихідний сигнал
  (Мала потужність) ──►│ Підсилювач ├──► (Велика потужність)
  P_in = U_in * I_in   │ (BJT/JFET) │    P_out = U_out * I_out
                       └────────────┘    (P_out >> P_in)
                           │
                           ▼
                      Спільна шина (GND)
```

### 1.2. Призначення підсилювачів
1. **Підсилення електричної потужності:** Забезпечення достатньої енергії для керування виконавчими пристроями (гучномовці, антени, двигуни, лінії зв'язку).
2. **Підсилення напруги або струму:** Масштабування слабких сигналів первинних сенсорів (мікрофони, термопари, фотодіоди) до рівнів, придатних для подальшої обробки або АЦП.
3. **Узгодження джерела сигналу з навантаженням (Buffering / Impedance Matching):** Запобігання просіданню напруги високоомного джерела (високий $R_{\text{вх}}$) та ефективна передача сигналу в низькоомне навантаження (низький $R_{\text{вих}}$).

### 1.3. Класифікація підсилювачів

                                  ┌─────────────────────────────┐
                                  │ Класифікація підсилювачів   │
                                  └──────────────┬──────────────┘
            ┌────────────────────────┬───────────┴───────────┬────────────────────────┐
            ▼                        ▼                       ▼                        ▼
┌───────────────────────┐ ┌──────────────────────┐ ┌───────────────────┐ ┌────────────────────────┐
│ За родом струму       │ │ За діапазоном частот │ │ За шириною смуги  │ │ За формою сигналу      │
├───────────────────────┤ ├──────────────────────┤ ├───────────────────┤ ├────────────────────────┤
│ • Постійного струму   │ │ • Низькочастотні     │ │ • Вузькосмугові   │ │ • Гармонічні (неперервні)│

## 2. Підсилювач як чотириполюсник. Схемні функції та макромодель

### 2.1. Макромодель підсилювача напруги
Підсилювач розглядається як активний чотириполюсник. Його малосигнальна поведінка на низьких/середніх частотах описується схемою Тевеніна з трьома фундаментальними параметрами:
* $R_{\text{вх}}$ ($R_{\text{in}}$) — вхідний опір підсилювача;
* $R_{\text{вих}}$ ($R_{\text{out}}$) — вихідний опір підсилювача;
* $K_U^{xx}$ ($A_{v0}$) — коефіцієнт підсилення напруги в режимі холостого ходу (без навантаження, $R_н \to \infty$).

```text
      ┌─────────── Підсилювач як лінійний чотириполюсник ───────────┐
      │                                                             │
  1 o─┼───────┐                          R_вих                      ┼─o 2 (+)
      │       │                          ┌───┐                      │
      │       │                          │   │                      │
   U_in      ┌┴┐                        ┌┴───┴┐      +              │    U_out
      │  R_вх│ │                 + - ──►│     │ K_U^xx * U_in       │
      │      └┬┘                ( ~ )   └─────┘      -              │
      │       │                  - +                                │
  1'o─┼───────┴─────────────────────────────────────────────────────┼─o 2' (-)
      │                                                             │
      └─────────────────────────────────────────────────────────────┘
```

### 2.2. Вплив навантаження на коефіцієнт підсилення
При підключенні навантаження $R_н$ до вихідних затискачів вихідна напруга ділиться між вихідним опором $R_{\text{вих}}$ та $R_н$:

$$U_{\text{вих}} = K_U^{xx} \cdot U_{\text{вх}} \cdot \frac{R_н}{R_н + R_{\text{вих}}}$$

Звідси реальний коефіцієнт підсилення напруги під навантаженням:

$$K_U = \frac{U_{\text{вих}}}{U_{\text{вх}}} = K_U^{xx} \cdot \frac{R_н}{R_н + R_{\text{вих}}}$$

> ⚠️ **Важливий висновок:**
> Якщо $R_н \gg R_{\text{вих}}$, то $K_U \approx K_U^{xx}$ (майже вся вихідна напруга потрапляє на навантаження). Якщо $R_н \approx R_{\text{вих}}$, підсилення падає вдвічі (на 6 дБ).

### 2.3. Загальні схемні функції чотириполюсника
Залежно від фізичної природи вхідного і вихідного сигналів визначають 4 типи схемних функцій:

| Тип схемної функції | Позначення | Формула | Одиниці вимірювання | Ідеальний $R_{\text{вх}}$ | Ідеальний $R_{\text{вих}}$ |
| :--- | :---: | :---: | :---: | :---: | :---: |
| **Коефіцієнт передачі напруги** | $K_U$ | $\frac{\dot{U}_{\text{вих}}}{\dot{U}_{\text{вх}}}$ | Безрозмірний (або дБ) | $\infty$ | $0$ |
| **Коефіцієнт передачі струму** | $K_I$ | $\frac{\dot{I}_{\text{вих}}}{\dot{I}_{\text{вх}}}$ | Безрозмірний (або дБ) | $0$ | $\infty$ |
| **Передавальний імпеданс (Transimpedance)** | $Z_{\text{пер}}$ | $\frac{\dot{U}_{\text{вих}}}{\dot{I}_{\text{вх}}}$ | Ом ($\Omega$) | $0$ | $0$ |
| **Передавальний адміттанс (Transconductance)** | $Y_{\text{пер}}$ | $\frac{\dot{I}_{\text{вих}}}{\dot{U}_{\text{вх}}}$ | См (S, $1/\Omega$) | $\infty$ | $\infty$ |

## 3. Основні характеристики підсилювачів

### 3.1. Амплітудна характеристика та динамічний діапазон
**Амплітудна характеристика** — залежність амплітуди вихідної напруги від амплітуди вхідної напруги на фіксованій частоті $U_{\text{вих}}(U_{\text{вх}})$.

```text
    U_вих ^
          │                       /──────── Лінійний розмах (Saturation)
          │                     /
  U_вих.max├───────────────────/
          │                  / │
          │                 /  │   Лінійна ділянка: U_вих = K_U * U_вх
          │                /   │
          │               /    │
  U_вих.min├─────────────/     │
          │  Поріг      /│     │
          │  шумів (U_ш) │     │
          └─────────────┴──────┴─────────────► U_вх
                      U_вх.min U_вх.max
                        ◄─── D ───►
```

* **Нижня межа ($U_{\text{вх.min}}$):** Визначається рівнем власних шумів підсилювача $U_ш$. Сигнал, менший за шум, губиться. Зазвичай приймають $U_{\text{вх.min}} = (2\dots 3) U_ш$.
* **Верхня межа ($U_{\text{вх.max}}$):** Визначається початком нелінійного спотворення (насичення, відсічка транзистора, обмеження напругою живлення).
* **Динамічний діапазон ($D$):** Діапазон вхідних напруг, у якому підсилювач зберігає лінійність:

$$D = \frac{U_{\text{вх.max}}}{U_{\text{вх.min}}} \quad \text{або в децибелах:} \quad D_{\text{дБ}} = 20 \log_{10}\left(\frac{U_{\text{вх.max}}}{U_{\text{вх.min}}}\right)$$

---

### 3.2. Амплітудно-частотна характеристика (АЧХ)
**АЧХ** — залежність модуля коефіцієнта підсилення $|K(j\omega)|$ від частоти гармонічного сигналу.

```text
    |K(f)| ^
           │           Смуга пропускання B = f_в - f_н
       K_0 ├──────────────┬────────────────────────┬──────────────
           │              │  Область СЧ (K ≈ K_0)  │
 0.707*K_0 ├───- - - - - -┌┼────────────────────────┼┐ - - - (-3 дБ)
           │             /││                        ││\
           │            / ││                        ││ \
           │           /  ││                        ││  \
           │   НЧ     /   ││                        ││   \   ВЧ
           └─────────┴────┴┴────────────────────────┴┴────┴───────► f
                     0   f_н                        f_в
```

1. **Область середніх частот (СЧ / Midband):** Коефіцієнт підсилення максимальний і сталий ($K(f) \approx K_0$).
2. **Область низьких частот (НЧ / Low frequencies):** Спад підсилення викликаний реактивним опором розділових ($C_1, C_2$) та блокувальних ($C_e$) конденсаторів ($X_C = \frac{1}{2\pi f C} \to \infty$ при $f \to 0$).
3. **Область високих частот (ВЧ / High frequencies):** Спад викликаний паразитними міжелектродними ємностями транзистора ($C_{be}, C_{bc}, C_{gs}, C_{gd}$) та ємністю монтажу, які шунтують високоомні вузли на землю на високих частотах.
4. **Граничні частоти зрізу ($f_н, f_в$):** Частоти, на яких коефіцієнт підсилення зменшується у $\sqrt{2} \approx 1.414$ разів (на 3 дБ або $29.3\%$) від номінального значення $K_0$:

$$|K(f_н)| = |K(f_в)| = \frac{K_0}{\sqrt{2}} \approx 0.707 K_0$$

5. **Смуга пропускання (Bandwidth):**

$$B = f_в - f_н \approx f_в \quad (\text{якщо } f_в \gg f_н)$$

---

### 3.3. Фазо-частотна характеристика (ФЧХ)
**ФЧХ** — залежність кута зсуву фази $\varphi(f) = \arg K(j\omega)$ між вихідним та вхідним сигналами від частоти.
* Ідеальний каскад зі спільним емітером (СЕ) на середніх частотах інвертує сигнал: $\Delta \varphi = 180^\circ$ ($\pi$ рад).
* На НЧ виникає додатковий додатний зсув фази через розділові ємності.
* На ВЧ виникає додатковий від'ємний фазовий зсув (затримка) через паразитні ємності.

---

### 3.4. Часові характеристики: Перехідна $h(t)$ та Імпульсна $g(t)$
Часові характеристики описують відгук підсилювача на швидкі збурення в часовій області.

```text
   Вхідний сигнал: Сходинка 1(t)             Вихідний відгук: Перехідна характеристика h(t)
         u_in(t) ^                                  h(t) ^             /──\  Викид (δ)
           1.0 ──┌──────────                         1.0 ├───- - - - -/────\- - - - - - -
                 │                                   0.9 ├───- - - - /┼────- - - - - - - -
                 │                                       │          / │     \ Спад (Δ)
                 │                                   0.1 ├───- - - ┌┼─┴──────- - - - - - -
                 └──────────► t                          └─────────┴┴────────────────► t
                                                                   ◄t_r►
```

* **Перехідна характеристика $h(t)$:** Відгук на одиничну сходинку $u_{\text{вх}}(t) = 1(t)$.
  * **Час наростання ($t_r$, Rise Time):** Час зміни відгуку від $0.1$ до $0.9$ усталеного значення. Пов'язаний з верхньою граничною частотою формулою:
    $$t_r \approx \frac{0.35}{f_в}$$
  * **Викид ($\delta$, Overshoot):** Відносне перевищення максимуму відгуку над усталеним значенням: $\delta = \frac{h_{\text{max}} - h(\infty)}{h(\infty)} \cdot 100\%$.
  * **Спад вершини ($\Delta$, Tilt / Sag):** Відносне зменшення амплітуди за час тривалості плоского імпульсу. Пов'язаний з нижньою частотою $f_н$: $\Delta \approx 2\pi f_н \cdot t_{\text{імп}}$.
* **Імпульсна характеристика $g(t)$:** Відгук на одиничний дельта-імпульс $\delta(t)$. Математично є похідною від перехідної функції:
  $$g(t) = \frac{dh(t)}{dt}$$

## 4. Класи підсилення (Classes of Operation)

Класи підсилення визначаються положенням початкової робочої точки (Q-point) на ВАХ транзистора, кутом відсічки $\theta$ (частина періоду гармонічного сигналу, протягом якої через транзистор протікає струм) та енергетичною ефективністю (ККД $\eta$).

```text
    Клас A                Клас AB                 Клас B                 Клас C
  (θ = 180° = π)      (90° < θ < 180°)        (θ = 90° = π/2)        (θ < 90° < π/2)
    i_c ^                 i_c ^                  i_c ^                  i_c ^
        │   /\                │   /\                 │   /\                 │   / \
   I_c0 ├──/──\──        I_c0 ├──/──\──              │  /  \                │  /   \
        │ /    \              │ /    \               │ /    \               │ /     \
      0 ┴────────► t        0 ┴──\──/──► t         0 ┴────────► t         0 ┴────────► t
        Повний період        Майже повний           Рівно 180°             Короткі імпульси
        струм тече           струм з паузою         півперіоду             (< 180°)
```

### 4.1. Зведена таблиця характеристик класів підсилення

| Клас | Кут відсічки ($\theta$) | Час протікання струму за період ($T$) | Теоретичний макс. ККД ($\eta_{\text{max}}$) | Рівень нелінійних спотворень | Типове застосування |
| :---: | :---: | :---: | :---: | :---: | :---: |
| **A** | $180^\circ$ ($\pi$) | $100\%$ ($T$) | $50\%$ (з індуктивним/трансф. зв'язком), $\le 25\%$ (з резистором) | **Мінімальний** (висока лінійність) | Малосигнальні попередні каскади, аудіо Hi-End |
| **AB** | $90^\circ < \theta < 180^\circ$ | $> 50\%$, $< 100\%$ | $50\% \dots 78.5\%$ | Низький (усунуто спотворення "сходинка") | Двотактні підсилювачі потужності НЧ |
| **B** | $90^\circ$ ($\pi/2$) | $50\%$ ($T/2$) | $78.5\%$ ($\frac{\pi}{4}$) | Середній (спотворення типу «сходинка» / crossover) | Двотактні вихідні каскади |
| **C** | $\theta < 90^\circ$ | $< 50\%$ ($< T/2$) | До $85\dots 90\%$ | Дуже високий (синусоїда відновлюється LC-контуром) | Високочастотні резонансні підсилювачі, радіопередавачі |
| **D** | — (імпульсний) | Ключовий режим (ВКЛ/ВИКЛ) | $\approx 90\dots 98\%$ | Залежить від фільтрації ШІМ (PWM) | Енергоефективні аудіопідсилювачі, інвертори, керування ДВЗ |

## 5. Схеми забезпечення статичного режиму (DC Biasing) біполярного транзистора (BJT)

### 5.1. Робоча точка (Q-point) та лінія навантаження (DC Load Line)
Щоб біполярний транзистор працював у лінійному активному режимі підсилення (Class A), на його електроди необхідно подати постійні напруги зміщення так, щоб:
1. Емітерний перехід був зміщений у прямому напрямку: $U_{BE0} \approx 0.6 \dots 0.7\text{ V}$ (для кремнієвих Si).
2. Колекторний перехід був зміщений у зворотному напрямку: $U_{CE0} > U_{BE0}$ (типово $U_{CE0} \approx \frac{1}{2} V_{CC}$).

За другим законом Кірхгофа для вихідного кола каскаду зі спільним емітером:

$$V_{CC} = I_C R_C + U_{CE} \implies I_C = \frac{V_{CC} - U_{CE}}{R_C}$$

```text
   I_C ^
 V_CC/R_C ├────────\
          │         \  Лінія навантаження за постійним струмом (DC Load Line)
          │          \
      I_C0├───────────\──────● Q (Робоча точка / Quiescent Point)
          │            \     │   (U_CE0, I_C0)
          │             \    │
          │              \   │
          └───────────────┴──┴───────────────► U_CE
                          U_CE0            V_CC
```

* Точка насичення (Saturation limit): $U_{CE} = 0 \implies I_{C(\text{sat})} = \frac{V_{CC}}{R_C}$
* Точка відсічки (Cutoff limit): $I_C = 0 \implies U_{CE(\text{cutoff})} = V_{CC}$

---

### 5.2. Схема 1: Фіксований струм бази (Fixed Base Current Bias)

```text
                  +V_CC
                    │
         ┌──────────┴──────────┐
         │                     │
        ┌┴┐                   ┌┴┐
     R_b│ │                R_c│ │
        └┬┘                   └┬┘
         │          i_c        │
         ├─────────────────────┼───► U_ce
         │       i_b           │
         │       ┌──┐       ┌──┴──┐
         └───────┤  ├───────┤ BJT │
                 └──┘       └──┬──┘
                               │
                              ─┴─ GND
```

#### Розрахункові рівняння:
1. Вхідне коло:
   $$V_{CC} = I_{B0} R_b + U_{BE0} \implies I_{B0} = \frac{V_{CC} - U_{BE0}}{R_b} \approx \frac{V_{CC}}{R_b}$$
2. Струм колектора:
   $$I_{C0} = \beta I_{B0}$$
3. Вихідне коло:
   $$U_{CE0} = V_{CC} - I_{C0} R_c = V_{CC} - \beta I_{B0} R_c$$

#### ⚠️ Недоліки:
* Схема є **термонестабільною**: коефіцієнт $\beta$ та зворотний струм $I_{CB0}$ сильно зростають з температурою ($+0.5\dots 1\% / ^\circ\text{C}$). Струм $I_{C0}$ пливе вгору, зміщуючи точку Q в область насичення.

---

### 5.3. Схема 2: Дільник напруги в базі з емітерною термостабілізацією (Voltage Divider Bias)
Це класична, найнадійніша схема для підсилювальних каскадів.

```text
                         +V_CC
                           │
                 ┌─────────┴─────────┐
                 │                   │
                ┌┴┐                 ┌┴┐
             R_1│ │                 │ │R_3 (R_c)
                └┬┘                 └┬┘
                 │     i_b           │       i_c
                 ├──────────┬────────┼────────────► U_ce
                 │          │     ┌──┴──┐
                ┌┴┐         └─────┤ BJT │
             R_2│ │               └──┬──┘
                └┬┘                  │ i_e
                 │                  ┌┴┐
                 │                  │ │R_4 (R_e)
                 │                  └┬┘
                 └─────────┬─────────┘
                           │
                          ─┴─ GND
```

#### Розрахунок методом еквівалентного генератора (Тевеніна):
Розриваємо базу транзистора та знаходимо еквівалентні параметри кола дільника $R_1 - R_2$:
* ЕРС Тевеніна:
  $$E_b = V_{CC} \cdot \frac{R_2}{R_1 + R_2}$$
* Внутрішній опір Тевеніна:
  $$R_b = R_1 \parallel R_2 = \frac{R_1 \cdot R_2}{R_1 + R_2}$$

#### Рівняння Кірхгофа для вхідного контуру:
$$E_b = I_{B0} R_b + U_{BE0} + I_{E0} R_e$$

Оскільки $I_{E0} = (\beta + 1) I_{B0}$:

$$E_b - U_{BE0} = I_{B0} \left[ R_b + (\beta + 1) R_e \right]$$

$$I_{B0} = \frac{E_b - U_{BE0}}{R_b + (\beta + 1) R_e}$$

$$I_{C0} = \beta I_{B0} = \frac{E_b - U_{BE0}}{\frac{R_b}{\beta} + \frac{\beta + 1}{\beta} R_e} \approx \frac{E_b - U_{BE0}}{\frac{R_b}{\beta} + R_e}$$

Напруга колектор-емітер:

$$U_{CE0} = V_{CC} - I_{C0} R_c - I_{E0} R_e = V_{CC} - I_{C0} \left( R_c + \frac{\beta+1}{\beta} R_e \right) \approx V_{CC} - I_{C0} (R_c + R_e)$$

#### 💡 Принцип термостабілізації (Негативний зворотний зв'язок по постійному струму):
$$T \uparrow \implies I_{C0} \uparrow \implies I_{E0} \uparrow \implies U_E = I_{E0} R_e \uparrow \implies U_{BE} = (E_b - U_E) \downarrow \implies I_{B0} \downarrow \implies I_{C0} \downarrow$$
Система автоматично стабілізує початковий струм колектора!

> [!TIP] Інженерне правило проектування (Rule of Thumb):
> Щоб забезпечити незалежність струму $I_{C0}$ від розкиду $\beta$:
> 1. Вибирати струм дільника $I_{\text{діл}} = \frac{V_{CC}}{R_1 + R_2} \ge (5 \dots 10) I_{B0}$, що еквівалентно умові $R_b \le 0.1 \cdot \beta R_e$.
> 2. Падіння напруги на емітерному резисторі: $U_{E0} = I_{E0} R_e \approx (0.1 \dots 0.2) V_{CC}$ (зазвичай $1 \dots 2\text{ V}$).

---

### 5.4. Схема 3: Колекторна стабілізація / Автозміщення (Collector-Feedback Bias)
У цій схемі базовий резистор $R_1$ підключений не до шини живлення $V_{CC}$, а безпосередньо до колектора транзистора.

```text
                     +V_CC
                       │
                      ┌┴┐
                   R_2│ │ (R_c)
                      └┬┘
                       │   i_c + i_b
                       ├─────────────────────► U_ce
                       │          i_c
                      ┌┴┐      ┌──┴──┐
                   R_1│ │◄─────┤ BJT │
                      └┬┘ i_b  └──┬──┘
                       │          │
                       └──────────┘
                                  │
                                 ─┴─ GND
```

#### Розрахункові рівняння:
1. Струм через колекторний резистор $R_2$ дорівнює $I_{C0} + I_{B0} = (\beta + 1) I_{B0}$.
2. Вихідна напруга колектора:
   $$U_{CE0} = V_{CC} - R_2 (I_{C0} + I_{B0}) = V_{CC} - R_2 \left( 1 + \frac{1}{\beta} \right) I_{C0}$$
3. Вхідне коло:
   $$U_{CE0} = I_{B0} R_1 + U_{BE0} \implies V_{CC} - R_2 (\beta + 1) I_{B0} = I_{B0} R_1 + U_{BE0}$$
   $$I_{B0} = \frac{V_{CC} - U_{BE0}}{R_1 + (\beta + 1) R_2}$$
   $$U_{BE0} = V_{CC} - \left[ R_2 (\beta + 1) + R_1 \right] I_{B0}$$

#### Механізм від'ємного зворотного зв'язку:
$$T \uparrow \implies I_{C0} \uparrow \implies U_{CE0} = (V_{CC} - I_{C0} R_2) \downarrow \implies I_{B0} = \frac{U_{CE0} - U_{BE0}}{R_1} \downarrow \implies I_{C0} \downarrow$$

---

### 5.5. Повна принципова схема підсилювального каскаду зі спільним емітером (AC & DC)

```text
                     +V_CC
                       │
           ┌───────────┴───────────┐
           │                       │
          ┌┴┐                     ┌┴┐
       R_1│ │                  R_c│ │
          └┬┘                     └┬┘
           │      C_1              │            C_2
  U_in ────┤├───┬───────┐          ├───┤├───► U_out
                │       │       ┌──┴──┐
               ┌┴┐      └───────┤ BJT │
            R_2│ │              └──┬──┘
               └┬┘                 │
                │                 ┌┴┐      C_e
                │              R_e│ │   ┌──┤├──┐
                │                 └┬┘   │      │
                └──────────┬───────┴────┴──────┘
                           │
                          ─┴─ GND
```

* $C_1, C_2$ — **розділові конденсатори (Coupling Capacitors):** Блокують постійну складову (DC) на вході й виході каскаду, пропускаючи тільки корисний змінний сигнал (AC).
* $C_e$ — **блокувальний / шунтуючий конденсатор емітера (Bypass Capacitor):**
  * По постійному струму (DC): $X_{Ce} = \infty$, резистор $R_e$ забезпечує термостабілізацію.
  * По змінному струму (AC): $X_{Ce} \ll R_e$ на робочих частотах, емітер за змінним струмом «закорочений» на землю ($U_{e(\text{ac})} \approx 0$). Це відновлює максимальний коефіцієнт підсилення каскаду:
    $$K_U \approx - \frac{R_c \parallel R_н}{r_e}$$
    де $r_e = \frac{\varphi_T}{I_{E0}} \approx \frac{25\text{ mV}}{I_{E0}}$ — внутрішній диференційний опір емітерного переходу.

## 6. Схеми забезпечення статичного режиму (DC Biasing) польового транзистора (JFET)

### 6.1. ВАХ JFET та вибір робочої точки
Для $n$-канального JFET робоча точка повинна знаходитися в **пологій області (область насичення / pinch-off / активний режим)**, де:
$$U_{DS} \ge U_{GS} - V_p \quad \text{та} \quad V_p \le U_{GS} \le 0$$

Струм стоку підпорядковується квадратичній формулі Шоклі:

$$I_D = I_{DSS} \left( 1 - \frac{U_{GS}}{V_p} \right)^2$$

де $I_{DSS}$ — початковий струм стоку при $U_{GS} = 0$, $V_p$ — напруга відсічки (від'ємна для $n$-каналу).

```text
    I_D ^
  I_DSS ├──────────────\
        │   Квадратична \
        │   передавальна \
        │   характеристика\
    I_D0├──────────────────● Q (U_GS0, I_D0)
        │                   \
        └────────────────────┴───────────► U_GS
       V_p                 U_GS0   0
   (Відсічка)
```

---

### 6.2. Схема автоматичного зміщення за рахунок струму витоку (Source Self-Bias)

```text
                     +V_CC (V_DD)
                          │
                 ┌────────┴────────┐
                 │                 │
                 │                ┌┴┐
                 │             R_2│ │ (R_d - опір стоку)
                 │                └┬┘
                 │                 │ i_d
                 │              ┌──┴──┐
                 │              │JFET ├───► U_ds
                 │       i_g=0  └──┬──┘
                 ├─────────────────┤
                 │                 │ i_s
                ┌┴┐               ┌┴┐
             R_1│ │            R_3│ │ (R_s - опір витоку)
                └┬┘               └┬┘
                 │                 │
                 └────────┬────────┘
                          │
                         ─┴─ GND
```

#### Розрахункові рівняння:
1. Оскільки струм затвора JFET мізерно малий ($I_G \approx 0$), падіння напруги на резисторі $R_1$ дорівнює нулю:
   $$U_G = 0\text{ V}$$
2. Струм витоку $I_S$ дорівнює струму стоку $I_D$ ($I_S = I_D$). Потенціал витоку відносно землі:
   $$U_S = I_{S0} R_s = I_{D0} R_3$$
3. Напруга затвор-витік стає автоматично від'ємною:
   $$U_{GS0} = U_G - U_S = 0 - I_{D0} R_s = - I_{D0} R_3$$
4. Вихідне коло (напруга стік-витік):
   $$U_{DS0} = V_{CC} - I_{D0} R_d - I_{S0} R_s = V_{CC} - I_{D0} (R_2 + R_3)$$

#### 💡 Принцип самостабілізації робочої точки JFET:
Якщо через нагрівання або заміну транзистора струм стоку зростає:
$$I_{D0} \uparrow \implies U_S = I_{D0} R_s \uparrow \implies U_{GS0} = -U_S \text{ (стає більш від'ємною)} \implies \text{канал перекривається} \implies I_{D0} \downarrow$$

## 🔬 Порівняльний аналіз схем зміщення

| Схема зміщення | Кількість пасивних компонентів | Стабільність Q-point до зміни температури | Залежність від розкиду $\beta$ / $V_p$ | Головна сфера застосування |
| :--- | :---: | :---: | :---: | :--- |
| **BJT: Фіксований струм бази** | 2 ($R_b, R_c$) | 🔴 Дуже погана | 🔴 Пряма ($I_C = \beta I_B$) | Прості ключові схеми, демонстраційні лабораторні |
| **BJT: Дільник напруги + $R_e$** | 4 ($R_1, R_2, R_c, R_e$) | 🟢 Відмінна | 🟢 Майже незалежна при $R_b \ll \beta R_e$ | Стандарт для лінійних підсилювачів СЕ, СБ, СК |
| **BJT: Колекторне автозміщення** | 2 ($R_1, R_2$) | 🟡 Середня | 🟡 Помірна | Прості дискретні каскади з мінімумом деталей |
| **JFET: Автозміщення у витоку ($R_s$)**| 3 ($R_g, R_d, R_s$) | 🟢 Відмінна | 🟢 Автоматична саморегуляція | Вхідні високоомні каскади (СВ, СС) |
