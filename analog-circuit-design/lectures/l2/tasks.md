## 🎯 Мета та інженерні орієнтири
Цей збірник містить **10 розрахункових інженерних завдань**, які охоплюють ключові теми проектування аналогових підсилювальних каскадів на постійному струмі (DC Biasing):
* Побудова ліній навантаження DC та вибір оптимальної точки спокою $Q$.
* Розрахунок різноманітних топологій зміщення (фіксований струм, колекторний зворотний зв'язок, чотирирезисторний термостабілізований дільник, схема самозміщення JFET).
* Оцінка енергетичних показників (ККД $\eta$, розсіювана потужність $P_C$, динамічний діапазон $D$).
* Аналіз режимів та класів підсилення (A, B, AB, C).

## 🧭 Методичні вказівки до розв'язання
1. **Активний режим кремнієвого BJT:** $U_{BE0} \approx 0.65\dots 0.7\ \text{В}$.
2. **Лінія навантаження DC для схеми з емітерним резистором:**
   $$I_C = \frac{V_{CC} - U_{CE}}{R_c + R_e}$$
3. **Еквівалент Тевеніна для дільника бази:**
   $$E_b = V_{CC} \frac{R_2}{R_1 + R_2}, \quad R_b = R_1 \parallel R_2 = \frac{R_1 R_2}{R_1 + R_2}$$
   $$I_{C0} \approx \frac{E_b - U_{BE0}}{R_e + \frac{R_b}{\beta}}$$
4. **Схема самозміщення JFET (Source Bias):**
   $$U_{GS0} = -I_{D0} R_s, \quad I_{D0} = I_{DSS}\left(1 - \frac{U_{GS0}}{V_p}\right)^2$$
5. **Фактор стабільності струму колектора:**
   $$S_I = \frac{\partial I_C}{\partial I_{CB0}} = \frac{1 + \frac{R_b}{R_e}}{1 + \frac{R_b}{(\beta + 1) R_e}}$$

#### Завдання 1: Лінія навантаження за постійним струмом (DC Load Line)
Підсилювальний каскад живиться від однополярного джерела $V_{CC} = 15.0\ \text{В}$. У колі колектора встановлено резистор $R_c = 3.3\ \text{к}\Omega$, а в колі емітера — $R_e = 1.0\ \text{к}\Omega$.

```text
       I_C (mA)
         ▲
         │
  I_sat ─┼───\
         │     \
   I_C0 ─┼───────*── Точка Q
         │        │ \
         │        │   \
         └────────┴─────┴────────► U_CE (В)
                U_CE0  V_CC
```

* **Вихідні дані:**
  * $V_{CC} = 15.0\ \text{В}$, $R_c = 3.3\ \text{к}\Omega$, $R_e = 1.0\ \text{к}\Omega$.
  * Бажаний струм спокою: $I_{C0} = 1.8\ \text{мА}$.
* **Завдання:**
  1. Визначити струм короткого замикання (насичення) лінії навантаження $I_{C(\text{sat})}$.
  2. Визначити напругу холостого ходу (відсічки) $U_{CE(\text{cut})}$.
  3. Обчислити напругу спокою колектор-емітер $U_{CE0}$ при заданому струмі $I_{C0}$.
* 💡 **Підказка:** $I_{C(\text{sat})} = \frac{V_{CC}}{R_c + R_e}$.

---

#### Завдання 2: Чому не можна використовувати схему з фіксованим струмом бази?
Каскад попереднього підсилювача реалізовано за найпростішою схемою з фіксованим струмом бази (один базовий резистор $R_b$, увімкнений між лінією живлення $+V_{CC}$ та базою).

```text
               +V_CC (+9 В)
                 │
                 ├───[ R_b: 430 кОм ]──────┐
                 │                         │
                 ├───[ R_c: 2.2 кОм ]───┬──┼──► U_вих
                 │                      │  │
                                     ┌──┴──┴┐
                                     │ VT1  │ NPN
                                     └──┬───┘
                                        │
                                       ─┴─ GND
```

* **Вихідні дані:**
  * $V_{CC} = 9.0\ \text{В}$, $R_c = 2.2\ \text{к}\Omega$, $R_b = 430\ \text{к}\Omega$, $U_{BE0} = 0.7\ \text{В}$.
* **Завдання:**
  1. Розрахувати струм бази $I_{B0}$.
  2. Знайти струм колектора $I_{C0}$ та напругу $U_{CE0}$ для екземпляра транзистора з $\beta_1 = 100$.
  3. Знайти струм колектора $I_{C0}$ та напругу $U_{CE0}$ для транзистора того ж типу з $\beta_2 = 250$. Зробити висновок щодо працездатності схеми.
* 💡 **Підказка:** Якщо розрахункове $U_{CE0} < 0.2\ \text{В}$, транзистор зайшов у глибоке насичення.

---

#### Завдання 3: Схема колекторного автозміщення (Negative Feedback Bias)
Для стабілізації робочої точки резистор зміщення бази $R_f = 180\ \text{к}\Omega$ підключено безпосередньо до колектора транзистора, створюючи негативний зворотний зв'язок за напругою.

```text
               +V_CC (+12 В)
                 │
                 ├───[ R_c: 2.0 кОм ]───┬───────► U_вих
                 │                      │
                 │     [ R_f: 180 кОм ] │
                 └─────────[───]────────┤
                                        │
                                     ┌──┴──┐
                                     │ VT1 │ NPN (β = 120)
                                     └──┬──┘
                                        │
                                       ─┴─ GND
```

* **Вихідні дані:**
  * $V_{CC} = 12.0\ \text{В}$, $R_c = 2.0\ \text{к}\Omega$, $R_f = 180\ \text{к}\Omega$, $\beta = 120$, $U_{BE0} = 0.65\ \text{В}$.
* **Завдання:**
  1. Записати вираз для струму бази $I_{B0}$ через параметри схеми.
  2. Розрахувати струм спокою колектора $I_{C0}$.
  3. Знайти постійну напругу на колекторі $U_{C0} = U_{CE0}$.
* 💡 **Підказка:** $V_{CC} - (I_C + I_B)R_c - I_B R_f - U_{BE0} = 0 \implies I_{B0} = \frac{V_{CC} - U_{BE0}}{R_f + (\beta + 1)R_c}$.

#### Завдання 4: Повний розрахунок класичного дільника напруги з емітерною стабілізацією
Необхідно спроєктувати чотирирезисторну схему зміщення каскаду класу A для забезпечення максимальної неспотвореної амплітуди сигналу.

* **Вихідні дані:**
  * $V_{CC} = 15.0\ \text{В}$, бажаний струм спокою $I_{C0} = 3.0\ \text{мА}$.
  * Падіння напруги на емітері: $U_{E0} = 2.0\ \text{В}$.
  * Бажана напруга колектор-емітер: $U_{CE0} = 6.5\ \text{В}$.
  * Параметри транзистора: $\beta = 150$, $U_{BE0} = 0.65\ \text{В}$.
  * Умова жорсткого дільника: $I_{\text{діл}} = 10 \cdot I_{B0}$.
* **Завдання:**
  1. Розрахувати опір емітерного резистора $R_e$.
  2. Розрахувати опір колекторного резистора $R_c$.
  3. Розрахувати номінали базового дільника $R_1$ та $R_2$.
* 💡 **Підказка:** $U_C = U_E + U_{CE} \implies R_c = \frac{V_{CC} - U_C}{I_C}$. Напруга бази $U_B = U_E + U_{BE}$.

#### Завдання 5: Розрахунок схеми самозміщення (Source Self-Bias) польового транзистора JFET
Вхідний каскад на $n$-канальному JFET повинен працювати в точці спокою зі струмом стоку $I_{D0} = 2.0\ \text{мА}$.

```text
               +V_DD (+18 В)
                 │
                 ├───[ R_d: 4.7 кОм ]───┬─────► U_вих
                 │                      │
                                     ┌──┴──┐
                                     │ VT1 │ 2N5457 (JFET)
                                     └──┬──┘
   U_вх ───┤├───┬───────────────────────┤
                │                       ├───[ R_s ]───┬────┐
               [R_g: 1 МОм]             │             │    │
                │                      ─┴─ C_s       ─┴─  ─┴─ GND
               ─┴─ GND                 GND           GND
```

* **Вихідні дані:**
  * $V_{DD} = 18.0\ \text{В}$, $R_d = 4.7\ \text{к}\Omega$, $R_g = 1.0\ \text{М}\Omega$.
  * Параметри JFET: струм насичення $I_{DSS} = 6.0\ \text{мА}$, напруга відсічки $V_p = -2.5\ \text{В}$.
  * Бажаний робочий струм: $I_{D0} = 2.0\ \text{мА}$.
* **Завдання:**
  1. За формулою Шоклі обчислити необхідну напругу затвор-витік $V_{GS0}$.
  2. Визначити опір витокового резистора $R_s$, який забезпечує цю напругу зміщення ($I_G \approx 0$).
  3. Знайти напругу сток-витік $V_{DS0}$ у вибраному режимі.
* 💡 **Підказка:** $V_{GS0} = V_p \left(1 - \sqrt{\frac{I_{D0}}{I_{DSS}}}\right)$. Оскільки затвор через $R_g$ заземлений ($U_G = 0$), $U_S = -V_{GS0} = I_D R_s$.

#### Завдання 6: Максимальний неспотворений розмах напруги та динамічний діапазон
Каскад на транзисторі має напругу живлення $V_{CC} = 12.0\ \text{В}$, потенціал емітера в точці спокою $U_{E0} = 1.2\ \text{В}$, напругу спокою на колекторі $U_{C0} = 6.6\ \text{В}$. Гранична напруга насичення колектора $U_{CE(\text{sat})} = 0.3\ \text{В}$. Коефіцієнт підсилення каскаду за напругою $K_U = 60$. Власна середньоквадратична напруга шумів на вході $U_ш = 4.0\ \mu\text{В}$.

* **Вихідні дані:**
  * $V_{CC} = 12.0\ \text{В}$, $U_{E0} = 1.2\ \text{В}$, $U_{C0} = 6.6\ \text{В}$, $U_{CE(\text{sat})} = 0.3\ \text{В}$, $K_U = 60$, $U_ш = 4.0\ \mu\text{В}$.
* **Завдання:**
  1. Визначити максимальний можливий симетричний розмах вихідної напруги від піку до піку $V_{p-p\text{ max}}$.
  2. Знайти максимальну допустиму амплітуду вхідного синусоїдального сигналу $U_{\text{вх.max}}$ без кліпінгу.
  3. Приймаючи мінімальний помітний сигнал на вході як поріг чутливості $U_{\text{вх.min}} = 3 \cdot U_ш$, розрахувати динамічний діапазон каскаду $D$ у децибелах.
* 💡 **Підказка:** $V_{p-p\text{ max}} = 2 \cdot \min(V_{CC} - U_{C0},\ U_{C0} - U_{E0} - U_{CE(\text{sat})})$. $D_{\text{дБ}} = 20 \lg\frac{U_{\text{вх.max}}}{U_{\text{вх.min}}}$.

#### Завдання 7: Розрахунок каскаду зміщення на PNP транзисторі
Розробити схему зміщення для каскаду на PNP-транзисторі BC557B з підключенням до від'ємної шини живлення $V_{EE} = -12.0\ \text{В}$ (або до позитивної $+12\ \text{В}$ із заземленим колекторним колом).

```text
               +V_CC (+12 В)
                 │
                 ├───[ R_e: 820 Ом ]─────────┐
                 │                           │
                 ├───[ R1: 18 кОм ]───┬───┌──┴──┐
                 │                    │   │ VT1 │ PNP (BC557)
                 │                    │   └──┬──┘
                 │                    │      ├───[ R_c: 2.7 кОм ]───► U_вих
                 │                    │      │
                 └───[ R2: 47 кОм ]───┴──────┼───────────────────────┐
                 │                           │                       │
                ─┴─ GND                     ─┴─ GND                 ─┴─ GND
```

* **Вихідні дані:**
  * Полярність живлення: шина живлення $+12.0\ \text{В}$, загальний провід $0\ \text{В}$ (GND).
  * Резистори: $R_e = 820\ \Omega$, $R_c = 2.7\ \text{к}\Omega$, $R_1 = 18\ \text{к}\Omega$ (між $+V_{CC}$ та базою), $R_2 = 47\ \text{к}\Omega$ (між базою та GND).
  * Транзистор PNP: $U_{EB0} = 0.65\ \text{В}$, $\beta = 180$.
* **Завдання:**
  1. Застосувати метод Тевеніна для знаходження еквівалентної напруги бази $E_b$ та опору $R_b$.
  2. Знайти напругу на базі $U_B$ відносно землі.
  3. Розрахувати струм спокою $I_{C0}$ та напругу $U_{EC0} = U_E - U_C$.
* 💡 **Підказка:** Для PNP транзистора емітер має вищий потенціал, ніж база: $U_E = U_B + U_{EB0}$.

#### Завдання 8: Порівняння енергетичної ефективності (ККД) каскадів класу A та класу B
Вихідний каскад підсилювача потужності повинен видавати синусоїдальну потужність $P_{\text{нав}} = 10\ \text{Вт}$ на акустичну систему з опором $R_н = 8\ \Omega$.

* **Вихідні дані:**
  * $P_{\text{нав}} = 10.0\ \text{Вт}$, $R_н = 8.0\ \Omega$.
* **Завдання:**
  1. Знайти необхідну амплітуду вихідної напруги $U_m$ та амплітуду струму в навантаженні $I_m$.
  2. Для однотактного каскаду класу A з резистивним навантаженням знайти мінімальну споживану потужність від джерела DC та максимальний теоретичний ККД ($\eta \le 25\%$).
  3. Для двотактного безтрансформаторного каскаду класу B (напруга живлення двохполярна $\pm V_{CC} = \pm U_m$) знайти споживану потужність $P_{\text{спож}} = \frac{2}{\pi} V_{CC} I_m$, розсіювану потужність на транзисторах $P_T$ та ККД $\eta$.
* 💡 **Підказка:** $P_{\text{нав}} = \frac{U_m^2}{2 R_н} = \frac{I_m^2 R_н}{2}$. ККД: $\eta = \frac{P_{\text{нав}}}{P_{\text{спож}}} \times 100\%$.

#### Завдання 9: Кут відсічки та ККД резонансного підсилювача класу C
У резонансному генераторі радіочастотного тракту біполярний транзистор працює в режимі класу C з кутом відсічки імпульсу колекторного струму $\theta = 60^\circ$ ($\pi/3\ \text{рад}$).

```text
         I_C(t)
           ▲
           │          /│\
    I_max ─┼─────────/ │ \
           │        /  │  \
           │       /   │   \
           │      /    │    \
         ──┴─────*─────┼─────*────────► ωt
               -θ      0     +θ
               <── 2θ = 120° ──>
```

* **Вихідні дані:**
  * Піковий струм імпульсу: $I_{\text{max}} = 600\ \text{мА}$.
  * Кут відсічки: $\theta = 60^\circ$.
  * Напруга живлення: $V_{CC} = 24.0\ \text{В}$.
  * Амплітуда першої гармоніки напруги на коливальному контурі: $U_{m1} = 21.0\ \text{В}$.
* **Завдання:**
  1. За коефіцієнтами Берга розрахувати постійну складову струму:
     $$\alpha_0(60^\circ) = \frac{\sin\theta - \theta\cos\theta}{\pi(1 - \cos\theta)} \approx 0.218 \implies I_0 = \alpha_0 \cdot I_{\text{max}}$$
  2. Розрахувати амплітуду першої гармоніки струму:
     $$\alpha_1(60^\circ) = \frac{\theta - \sin\theta\cos\theta}{\pi(1 - \cos\theta)} \approx 0.391 \implies I_{m1} = \alpha_1 \cdot I_{\text{max}}$$
  3. Обчислити корисну потужність коливань $P_1 = \frac{1}{2} U_{m1} I_{m1}$, споживану потужність $P_0 = V_{CC} I_0$ та ККД каскаду $\eta$.
* 💡 **Підказка:** $\eta = \frac{P_1}{P_0} = \frac{1}{2} \cdot \frac{U_{m1}}{V_{CC}} \cdot \frac{\alpha_1}{\alpha_0}$.

#### Завдання 10: Проєктування базового дільника під заданий фактор стабільності $S_I \le 3.0$
Технічне завдання вимагає забезпечити високу термостабільність каскаду: коефіцієнт нестабільності за струмом витоку не повинен перевищувати $S_I = 3.0$.

* **Вихідні дані:**
  * $V_{CC} = 10.0\ \text{В}$, робочий струм спокою $I_{C0} = 1.5\ \text{мА}$.
  * Резистор емітера: $R_e = 1.0\ \text{к}\Omega$.
  * Мінімальний коефіцієнт підсилення транзистора: $\beta = 100$, $U_{BE0} = 0.65\ \text{В}$.
  * Максимально допустимий фактор стабільності: $S_{I(\text{max})} = 3.0$.
* **Завдання:**
  1. Вивести формулу та знайти гранично допустимий опір Тевеніна базового кола $R_{b(\text{max})}$, що задовольняє умові $S_I \le 3.0$.
  2. Знайти необхідну напругу джерела Тевеніна $E_b$.
  3. Розрахувати точні значення резисторів дільника $R_1$ та $R_2$.
* 💡 **Підказка:** $S_I \approx 1 + \frac{R_b}{R_e} \implies R_b \le (S_I - 1) R_e$. Далі скористайтеся формулами зв'язку $R_1 = R_b \frac{V_{CC}}{E_b}$ та $R_2 = \frac{R_b V_{CC}}{V_{CC} - E_b}$.
