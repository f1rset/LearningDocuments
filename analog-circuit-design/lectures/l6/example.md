# 🧮 Приклад розв'язання задачі: Повний розрахунок диференційного підсилювача на ОП з аналізом похибок DC та динамічних меж AC

> **Курс:** Аналогова схемотехніка  
> **Тема:** Лекція 6. Операційні підсилювачі (Макромоделі, Параметри, Схемотехніка LM324)

## 🎯 Мета та інженерні задачі практикуму
1. Опанувати методику інженерного проєктування **диференційного підсилювача (віднімача)** на базі операційного підсилювача (ОП).
2. Скласти та розрахувати **бюджет статичних похибок за постійним струмом (DC Error Budget)**: врахувати вплив вхідної напруги зміщення $V_{IO}$, вхідних струмів зміщення $I_{IB}$ та зсуву $I_{IO}$.
3. Оцінити коефіцієнт придушення синфазного сигналу (**CMRR**) з урахуванням розкиду допусків резисторів ($\pm 1\%$ та $\pm 0.1\%$).
4. Визначити динамічні межі за змінним струмом (AC): розрахувати робочу смугу частот за малим сигналом через добуток підсилення на смугу ($GBW$) та смугу повної потужності за великим сигналом через швидкість наростання ($SR$).
5. Розробити заходи схемотехнічного усунення спотворень типу «сходинка» (crossover distortion) мікросхеми LM324 при роботі від однополярного живлення $+5\ \text{В}$.

## 1. Постановка задачі та вихідні вимоги

Необхідно спроєктувати прецизійний вимірювальний тракт для підсилення диференційного сигналу тензорезистивного моста на базі доступного ОП загального призначення LM324 (або LM358).

```text
                 R1 (10 кОм)
   U_вх1 ─────────[───]────────┬───────────────────┐
   (Інверт.)                   │                   │
                              ┌┴┐                  │
                              │-│                  │
                              │ ├───[ R2: 200 кОм ]┼────► U_вих
                              │+│                  │
                              └┬┘                  │
   U_вх2 ─────────[───]────────┤                   │
   (Неінверт.)   R3 (10 кОм)   │                   │
                              ┌┴┐                  │
                              │ │ R4 (200 кОм)     │
                              └┬┘                  │
                               │                   │
                              ─┴─ GND             ─┴─ GND
```

### Вихідні вимоги:
* Диференційний коефіцієнт підсилення: $K_d = \frac{U_{\text{вих}}}{U_{\text{вх2}} - U_{\text{вх1}}} = \mathbf{20.0}$ ($26.02\ \text{дБ}$).
* Діапазон вхідного диференційного сигналу: $U_d = U_{\text{вх2}} - U_{\text{вх1}} = 0\dots 150\ \text{мВ}$.
* Синфазна постійна складова сигналу (потенціал середини моста): $U_{cm} = 2.5\ \text{В}$.
* Однополярне живлення: $V_{CC} = +5.0\ \text{В}$, $V_{EE} = 0\ \text{В}$ (GND).
* Паспортні параметри операційного підсилювача LM324 (найгірший випадок при $25^\circ\text{C}$):
  * Напруга зсуву: $V_{IO} = 2.0\ \text{мВ}$ (макс. $3.0\ \text{мВ}$).
  * Температурний дрейф $V_{IO}$: $\frac{\Delta V_{IO}}{\Delta T} = 7.0\ \mu\text{В}/^\circ\text{C}$.
  * Вхідний струм зміщення: $I_{IB} = 45\ \text{нА}$ (макс. $100\ \text{нА}$).
  * Вхідний струм зсуву: $I_{IO} = 5\ \text{нА}$ (макс. $20\ \text{нА}$).
  * Власний коефіцієнт CMRR підсилювача: $\text{CMRR}_{\text{ОП}} = 80\ \text{дБ}$.
  * Добуток підсилення на смугу: $GBW = 1.0\ \text{МГц}$.
  * Швидкість наростання вихідної напруги: $SR = 0.5\ \text{В}/\mu\text{с}$.

## 2. Розрахунок резистивної матриці та балансування імпедансів

Класичне рівняння диференційного підсилювача за принципом суперпозиції:
$$U_{\text{вих}} = U_{\text{вх2}} \cdot \left(\frac{R_4}{R_3 + R_4}\right) \cdot \left(1 + \frac{R_2}{R_1}\right) - U_{\text{вх1}} \cdot \left(\frac{R_2}{R_1}\right)$$

### 2.1. Умова ідеального віднімання та рівності коефіцієнтів:
Щоб напруга залежала виключно від різниці $(U_{\text{вх2}} - U_{\text{вх1}})$, має виконуватися пропорція:
$$\frac{R_2}{R_1} = \frac{R_4}{R_3} = K_d = 20.0$$
Тоді рівняння спрощується до:
$$U_{\text{вих}} = K_d \cdot (U_{\text{вх2}} - U_{\text{вх1}}) = 20 \cdot U_d$$

### 2.2. Умова балансування опорів для компенсації струмів $I_{IB}$:
Для повної взаємної компенсації падінь напруги від вхідних струмів зміщення $I_{IB}$ еквівалентні опори Тевеніна, що підключені до обох входів ОП, повинні бути абсолютно однаковими:
$$R_{\text{екв-}} = R_1 \parallel R_2 = \frac{R_1 R_2}{R_1 + R_2}$$
$$R_{\text{екв+}} = R_3 \parallel R_4 = \frac{R_3 R_4}{R_3 + R_4}$$
Оскільки $\frac{R_2}{R_1} = \frac{R_4}{R_3} = 20$, автоматично отримуємо $R_3 = R_1$ та $R_4 = R_2$.

### 2.3. Вибір номіналів резисторів:
* Вибираємо $R_1 = R_3 = 10.0\ \text{к}\Omega$ (забезпечує помірне вхідне навантаження для моста).
* Тоді $R_2 = R_4 = 20 \times 10.0\ \text{к}\Omega = \mathbf{200.0\ \text{к}\Omega}$.
* Еквівалентний опір входів:
  $$R_{\text{екв}} = 10\ \text{к}\Omega \parallel 200\ \text{к}\Omega = \frac{10 \times 200}{210} \approx \mathbf{9.524\ \text{к}\Omega}$$

## 3. Бюджет статичних похибок за постійним струмом (DC Error Budget)

Розрахуємо внесені похибки вихідної напруги для найгіршого випадку (Worst-Case Analysis).

### 3.1. Похибка від напруги зсуву нульового рівня ($V_{IO}$):
Напруга $V_{IO}$ діє як джерело ЕРС, включене послідовно з неінвертуючим входом. Її коефіцієнт підсилення до виходу дорівнює «підсиленню шуму» (Noise Gain, $K_N$):
$$K_N = 1 + \frac{R_2}{R_1} = 1 + 20 = 21.0$$
Вихідна напруга зміщення:
$$V_{\text{out}(V_{IO})} = \pm V_{IO} \cdot K_N = \pm 2.0\ \text{мВ} \times 21 = \mathbf{\pm 42.0\ \text{мВ}}$$

### 3.2. Похибка від температурного дрейфу ($T = 25^\circ\text{C} \dots 65^\circ\text{C}$, $\Delta T = 40^\circ\text{C}$):
$$\Delta V_{IO(\text{drift})} = 7.0\ \mu\text{В}/^\circ\text{C} \times 40^\circ\text{C} = 280\ \mu\text{В} = 0.28\ \text{мВ}$$
$$V_{\text{out(drift)}} = \pm 0.28\ \text{мВ} \times 21 = \mathbf{\pm 5.88\ \text{мВ}}$$

### 3.3. Похибка від струму зміщення ($I_{IB}$) та струму зсуву ($I_{IO}$):
Завдяки рівності опорів Тевеніна ($R_{\text{екв+}} = R_{\text{екв-}}$), синфазна складова вхідного струму $I_{IB}$ створює однакові падіння напруги на обох входах і повністю віднімається диференційним каскадом ОП!  
Залишається лише вплив різницевого струму зсуву $I_{IO} = |I_{B+} - I_{B-}| = 5\ \text{нА}$:
$$V_{\text{out}(I_{IO})} = \pm I_{IO} \cdot R_2 = \pm 5.0 \cdot 10^{-9}\ \text{А} \times 200 \cdot 10^3\ \Omega = \mathbf{\pm 1.0\ \text{мВ}}$$
*(Якби опори не були збалансовані, струм $I_{IB} = 45\ \text{нА}$ вніс би похибку $45\ \text{нА} \times 200\ \text{к}\Omega = 9.0\ \text{мВ}$, тобто в 9 разів більше!)*.

### 3.4. Сумарна абсолютна статична похибка виходу (Worst-case):
$$V_{\text{err(tot)}} = |V_{\text{out}(V_{IO})}| + |V_{\text{out(drift)}}| + |V_{\text{out}(I_{IO})}| = 42.0\ \text{мВ} + 5.88\ \text{мВ} + 1.0\ \text{мВ} = \mathbf{48.88\ \text{мВ}}$$
Приведена до входу похибка:
$$V_{\text{err(in)}} = \frac{V_{\text{err(tot)}}}{K_d} = \frac{48.88\ \text{мВ}}{20} \approx \mathbf{2.44\ \text{мВ}}$$
При повному сигналі $U_d = 100\ \text{мВ}$ відносна систематична похибка складає $\approx \mathbf{2.44\%}$.

## 4. Аналіз синфазного придушення (CMRR) та вплив допусків резисторів

Напруга на входах містить велику синфазну складову $U_{cm} = 2.5\ \text{В}$.

### 4.1. Погіршення CMRR через розкид номіналів резисторів:
Навіть якщо сам ОП є ідеалом ($\text{CMRR}_{\text{ОП}} = \infty$), найменша асиметрія моста резисторів перетворює синфазну напругу $U_{cm}$ у паразитний диференційний сигнал.  
Найгірше значення CMRR резистивної схеми з допуском компонентів $\epsilon_{\text{tol}}$:
$$\text{CMRR}_{\text{res}} \approx \frac{1 + K_d}{4 \cdot \epsilon_{\text{tol}}}$$

1. **При використанні звичайних резисторів з допуском $1\%$ ($\epsilon_{\text{tol}} = 0.01$):**
   $$\text{CMRR}_{\text{res(1\%)}} = \frac{1 + 20}{4 \times 0.01} = \frac{21}{0.04} = 525 \implies 20\lg(525) \approx \mathbf{54.4\ \text{дБ}}$$
   Паразитна напруга на виході від $U_{cm} = 2.5\ \text{В}$:
   $$V_{\text{out}(cm)} = U_{cm} \cdot \frac{K_d}{\text{CMRR}_{\text{res}}} = 2.5\ \text{В} \times \frac{20}{525} \approx \mathbf{95.2\ \text{мВ}} \quad (\text{катастрофічно багато!})$$
2. **При використанні прецизійних резисторів з допуском $0.1\%$ ($\epsilon_{\text{tol}} = 0.001$):**
   $$\text{CMRR}_{\text{res(0.1\%)}} = \frac{21}{0.004} = 5250 \implies 20\lg(5250) \approx \mathbf{74.4\ \text{дБ}}$$
   $$V_{\text{out}(cm)} = 2.5\ \text{В} \times \frac{20}{5250} \approx \mathbf{9.52\ \text{мВ}}$$

### 4.2. Результуючий CMRR системи (ОП + Резистори 0.1%):
$$\frac{1}{\text{CMRR}_{\text{tot}}} = \frac{1}{\text{CMRR}_{\text{res}}} + \frac{1}{\text{CMRR}_{\text{ОП}}}$$
$$\text{CMRR}_{\text{ОП}} = 80\ \text{дБ} \implies 10000; \quad \text{CMRR}_{\text{res}} = 74.4\ \text{дБ} \implies 5250$$
$$\frac{1}{\text{CMRR}_{\text{tot}}} = \frac{1}{5250} + \frac{1}{10000} = 0.0001905 + 0.0001 = 0.0002905 \implies \text{CMRR}_{\text{tot}} \approx 3442 \approx \mathbf{70.74\ \text{дБ}}$$

> 💡 **Головне правило аналогового інженера:** CMRR диференційного підсилювача практично завжди лімітується **не операційним підсилювачем, а точністю узгодження резисторів**! Використання резисторів $1\%$ руйнує точність схеми.

## 5. Динамічний аналіз за змінним струмом (AC: GBW та Slew Rate)

### 5.1. Робоча смуга частот за малим сигналом (Closed-Loop Bandwidth):
Смуга пропускання замкненого контуру визначається відношенням $GBW$ до підсилення шуму $K_N$:
$$f_{-3\text{дБ}} = \frac{GBW}{K_N} = \frac{GBW}{1 + \frac{R_2}{R_1}} = \frac{1.0\ \text{МГц}}{1 + 20} = \frac{1000\ \text{кГц}}{21} \approx \mathbf{47.62\ \text{кГц}}$$

### 5.2. Обмеження швидкості наростання (Slew Rate) та смуга повної потужності:
Паспортний $SR = 0.5\ \text{В}/\mu\text{с} = 5.0 \cdot 10^5\ \text{В/с}$.  
Припустимо, що вихідний синусоїдальний сигнал має максимальну амплітуду $V_p = 2.0\ \text{В}$ (розмах від піку до піку $V_{p-p} = 4.0\ \text{В}$).  
Максимальна частота без спотворення форми синусоїди (Power Bandwidth):
$$f_{\text{max}} = \frac{SR}{2\pi \cdot V_p} = \frac{5.0 \cdot 10^5\ \text{В/с}}{2\pi \times 2.0\ \text{В}} = \frac{500000}{12.566} \approx \mathbf{39.79\ \text{кГц}}$$

> ⚠️ **Порівняння:**
> * Малосигнальна смуга: $f_{-3\text{дБ}} = 47.6\ \text{кГц}$.
> * Смуга великого сигналу ($V_p = 2\ \text{В}$): $f_{\text{max}} = 39.8\ \text{кГц}$.
> При роботі на частотах понад $40\ \text{кГц}$ із високою амплітудою вихідний синусоїдальний сигнал почне перетворюватися на трикутний через обмеження струму перезаряджання міллерівської ємності корекції ($SR$).

## 6. Специфіка LM324: Усунення спотворень типу «сходинка» (Crossover Distortion)

У вихідному каскаді LM324 використовується двотактна схема класу B/AB. При перетині струму навантаження через нуль утворюється зона мертвої нечутливості, що викликає виражену «сходинку» на змінному струмі.

```text
               Усунення сходинки за допомогою підтяжки Pull-Down
               
                              +5 В
                               │
                            ┌──┴──┐
                            │ LM  │
                            │ 324 ├──────┬─────────► U_вих (без сходинки!)
                            └──┬──┘      │
                               │        ┌┴┐
                              ─┴─ GND   │ │ R_pull (1.5..3.3 кОм)
                                        └┬┘
                                         │
                                        ─┴─ GND
```

### Схемотехнічне вирішення:
Підключення резистора підтяжки $R_{\text{pull}} = 2.2\ \text{к}\Omega$ з виходу ОП на землю (GND) створює постійний струм витікання:
$$I_{\text{pull}} \approx \frac{U_{\text{вих}}}{R_{\text{pull}}} \approx \frac{2.5\ \text{В}}{2.2\ \text{к}\Omega} \approx 1.14\ \text{мА}$$
Цей струм примусово зміщує верхній транзистор вихідного каскаду (Q6 в LM324) у режим **чистого класу A**, повністю вимикаючи нижній транзистор Q13 і ліквідуючи спотворення типу «сходинка».
