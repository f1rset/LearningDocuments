## 🎯 Мета та інженерні орієнтири
Цей збірник містить **10 розрахункових інженерних завдань**, які охоплюють ключові аспекти проєктування та аналізу схем на операційних підсилювачах:
* Базові топології ОП: інвертуючий, неінвертуючий, буфер (повторювач), суматор, інтегратор.
* Статичний розрахунок похибок зміщення ($V_{IO}, I_{IB}, I_{IO}$) та вибір балансувальних опорів.
* Динамічний аналіз: збереження $GBW$, швидкість наростання $SR$ та смуга повної потужності $f_{\text{max}}$.
* Спеціалізовані схеми: трансімпедансний підсилювач (TIA) для фотодіода, диференційний підсилювач з оцінкою CMRR за допусками резисторів.

---

## 🧭 Методичні вказівки до розв'язання
1. **Золоті правила для лінійного режиму ОП з НЗЗ:**
   $$U_+ = U_-, \quad i_+ = i_- = 0$$
2. **Інвертуючий підсилювач:** $K_U = -\frac{R_f}{R_{in}}$, $R_{\text{вх}} = R_{in}$, $R_{\text{комп}} = R_{in} \parallel R_f$.
3. **Неінвертуючий підсилювач:** $K_U = 1 + \frac{R_f}{R_1}$, $R_{\text{вх}} \to \infty$.
4. **Закон збереження GBW:** $f_{-3\text{дБ}} = \frac{GBW}{K_N}$, де підсилення шуму $K_N = 1 + \frac{R_f}{R_{in}}$.
5. **Смуга повної потужності (Slew Rate):** $f_{\text{max}} = \frac{SR}{2\pi V_p}$.
6. **Вплив розкиду резисторів на CMRR:** $\text{CMRR}_{\text{res}} \approx \frac{1 + K_d}{4 \epsilon_{\text{tol}}}$.

#### Завдання 1: Класичний інвертуючий підсилювач з балансуванням по DC
Необхідно спроєктувати інвертуючий підсилювач з коефіцієнтом підсилення за напругою $K_U = -10.0$ на біполярному ОП LM324.

```text
               R_in (10 кОм)
   U_вх ─────────[───]────────┬───────────────────┐
                              │                   │
                             ┌┴┐                  │
                             │-│                  │
                             │ ├───[ R_f: 100 кОм ]┼────► U_вих
                             │+│                  │
                             └┬┘                  │
                              │                   │
                             ┌┴┐ R_комп           │
                             │ │ (9.1 кОм)        │
                             └┬┘                  │
                              │                   │
                             ─┴─ GND             ─┴─ GND
```

* **Вихідні дані:**
  * Коефіцієнт підсилення: $K_U = -10.0$.
  * Вхідний опір каскаду: $R_{\text{вх}} = 10.0\ \text{к}\Omega$.
* **Завдання:**
  1. Розрахувати опір резистора зворотного зв'язку $R_f$.
  2. Знайти точний номінал компенсаційного резистора $R_{\text{комп}}$, що підключається між неінвертуючим входом $(+)$ та землею для нейтралізації струму $I_{IB}$.
  3. Вибрати найближчий стандартний номінал $R_{\text{комп}}$ з ряду E24.
* 💡 **Підказка:** $R_{\text{вх}} = R_{in}$, $R_{\text{комп}} = R_{in} \parallel R_f$.

---

#### Завдання 2: Неінвертуючий підсилювач та розмах вихідної напруги
Датчик температури видає сигнал $U_{\text{дат}} = 0\dots 50\ \text{мВ}$. Необхідно підсилити цей сигнал до діапазону $0\dots 2.5\ \text{В}$ для оцифрування АЦП.

* **Вихідні дані:**
  * $U_{\text{вх.max}} = 50.0\ \text{мВ}$, бажаний $U_{\text{вих.max}} = 2.50\ \text{В}$.
  * Живлення ОП: однополярне $V_{CC} = +5.0\ \text{В}$, $V_{EE} = 0\ \text{В}$ (GND).
  * Резистор нижнього плеча: $R_1 = 2.0\ \text{к}\Omega$.
* **Завдання:**
  1. Розрахувати необхідний коефіцієнт підсилення $K_U$.
  2. Знайти опір резистора зворотного зв'язку $R_2$ ($R_f$).
  3. Перевірити, чи не заходить вихід LM324 в обмеження ($V_{OH} \approx V_{CC} - 1.5\ \text{В} = 3.5\ \text{В}$, $V_{OL} \approx 20\ \text{мВ}$).
* 💡 **Підказка:** $K_U = 1 + \frac{R_2}{R_1} \implies R_2 = (K_U - 1) R_1$.

---

#### Завдання 3: Буферний повторювач напруги та похибка від скінченного підсилення ОП $A_0$
Досліджується повторювач напруги ($100\%$ НЗЗ) на реальному ОП зі скінченним власним коефіцієнтом підсилення $A_0$.

```text
   U_вх ─────────┐
                ┌┴┐
                │+│
                │ ├──────┬──────► U_вих
                │-│      │
                └┬┘      │
                 └───────┘ (100% зворотний зв'язок)
```

* **Вихідні дані:**
  * Вхідна напруга: $U_{\text{вх}} = 2.0\ \text{В}$.
* **Завдання:**
  1. За формулою Блека вивести точний коефіцієнт передачі повторювача $K_U = \frac{U_{\text{вих}}}{U_{\text{вх}}} = \frac{A_0}{1 + A_0}$.
  2. Розрахувати відносну похибку передачі $\delta = \frac{U_{\text{вх}} - U_{\text{вих}}}{U_{\text{вх}}} \times 100\%$ для високоякісного ОП з $A_0 = 10^5$ ($100\ \text{дБ}$).
  3. Розрахувати похибку $\delta$ для ОП на високій частоті, де $A_0$ впало до $10^3$ ($60\ \text{дБ}$) та до $100$ ($40\ \text{дБ}$).
* 💡 **Підказка:** $\delta \approx \frac{1}{A_0} \times 100\%$.

### 🔹 Рівень 2: Аналогові обчислювальні схеми та похибки DC

---

#### Завдання 4: Трьохвходовий інвертуючий аудіомікшер (Суматор)
Для змішування сигналів трьох мікрофонів використовується аналоговий суматор на ОП.

```text
   U_1 ───[ R1: 20 кОм ]───┬───────────────┐
                           │               │
   U_2 ───[ R2: 10 кОм ]───┼──┐           ┌┴┐
                           │ ┌┴┐          │-│
   U_3 ───[ R3: 50 кОм ]───┤ │-│          │ ├───[ R_f: 100 кОм ]──► U_вих
                           │ └┬┘          │+│
                           │  │           └┬┘
                           └──┼────────────┤
                              │           ┌┴┐ R_комп
                             ─┴─ GND      └┬┘
                                           │
                                          ─┴─ GND
```

* **Вихідні дані:**
  * Резистори входів: $R_1 = 20\ \text{к}\Omega$, $R_2 = 10\ \text{к}\Omega$, $R_3 = 50\ \text{к}\Omega$.
  * Резистор зворотного зв'язку: $R_f = 100\ \text{к}\Omega$.
  * Миттєві вхідні напруги: $U_1 = +0.2\ \text{В}$, $U_2 = -0.15\ \text{В}$, $U_3 = +0.5\ \text{В}$.
* **Завдання:**
  1. Записати вагові коефіцієнти кожного каналу $k_1, k_2, k_3$.
  2. Розрахувати вихідну напругу $U_{\text{вих}} = -(k_1 U_1 + k_2 U_2 + k_3 U_3)$.
  3. Знайти оптимальний опір компенсаційного резистора $R_{\text{комп}} = R_1 \parallel R_2 \parallel R_3 \parallel R_f$.
* 💡 **Підказка:** Коефіцієнт кожного входу $k_i = \frac{R_f}{R_i}$.

---

#### Завдання 5: Практичний аналоговий інтегратор з резистором DC-скидання
Для інтегрування прямокутних імпульсів спроєктовано інтегратор Міллера. Щоб постійний струм зсуву ОП не заганяв вихід у насичення, паралельно конденсатору $C$ встановлено паразитний опір витоку $R_f$.

```text
                 R (100 кОм)       C (100 нФ)
   U_вх ───────────[───]───────┬──────┤├───┬──────► U_вих
                               │           │
                              ┌┴┐         ┌┴┐
                              │-│         │ │ R_f (1.0 МОм)
                              │ ├───[     │ │
                              │+│         └┬┘
                              └┬┘          │
                               │           │
                              ─┴─ GND     ─┴─ GND
```

* **Вихідні дані:**
  * $R = 100\ \text{к}\Omega$, $C = 100\ \text{нФ}$, $R_f = 1.0\ \text{М}\Omega$.
* **Завдання:**
  1. Розрахувати постійну часу інтегрування $\tau = R \cdot C$.
  2. Визначити граничну частоту зрізу $f_c = \frac{1}{2\pi R_f C}$, нижче якої схема перестає інтегрувати і працює як звичайний інвертуючий підсилювач.
  3. Розрахувати максимальне підсилення схеми за постійним струмом ($f = 0$).
* 💡 **Підказка:** На постійному струмі конденсатор є розривом кола, тому $K_{U(DC)} = -R_f / R$.

---

#### Завдання 6: Бюджет похибок постійного струму (DC Offset Error)
Інвертуючий підсилювач має $R_{in} = 10\ \text{к}\Omega$ та $R_f = 220\ \text{к}\Omega$ ($K_U = -22$). Використовується ОП з параметрами: $V_{IO} = 3.0\ \text{мВ}$, $I_{IB} = 80\ \text{нА}$, $I_{IO} = 10\ \text{нА}$.

* **Вихідні дані:**
  * $R_{in} = 10\ \text{к}\Omega$, $R_f = 220\ \text{к}\Omega$, $V_{IO} = 3.0\ \text{мВ}$, $I_{IB} = 80\ \text{нА}$, $I_{IO} = 10\ \text{нА}$.
* **Завдання:**
  1. Розрахувати вихідну похибку від напруги зсуву: $V_{\text{out}(V_{IO})} = V_{IO} \left(1 + \frac{R_f}{R_{in}}\right)$.
  2. Знайти вихідну похибку від струму $I_{IB}$, якщо неінвертуючий вхід заземлено напряму ($R_{\text{комп}} = 0$): $V_{\text{out}(I_{IB})} = I_{IB} \cdot R_f$.
  3. Знайти вихідну похибку, якщо встановлено правильний резистор $R_{\text{комп}} = R_{in} \parallel R_f$: $V_{\text{out}(I_{IO})} = I_{IO} \cdot R_f$.
  4. Порівняти сумарну вихідну похибку зміщення нуля у випадках 2 та 3.
* 💡 **Підказка:** У випадку збалансованих входів струм $I_{IB}$ повністю взаємокомпенсується.

#### Завдання 7: Розрахунок робочої смуги за законом збереження $GBW$
Операційний підсилювач LM324 має паспортний добуток підсилення на смугу $GBW = 1.0\ \text{МГц}$.

* **Вихідні дані:**
  * $GBW = 1.0\ \text{МГц} = 1000\ \text{кГц}$.
* **Завдання:**
  1. Розрахувати верхню частоту зрізу $f_{-3\text{дБ}}$ для неінвертуючого підсилювача з коефіцієнтами підсилення $K_U = 1$ (буфер), $K_U = 10$ та $K_U = 100$.
  2. Розрахувати $f_{-3\text{дБ}}$ для інвертуючого підсилювача з підсиленням за сигналом $K_U = -10$. Чому його смуга вужча, ніж у неінвертуючого з $K_U = +10$?
* 💡 **Підказка:** Смуга визначається коефіцієнтом підсилення шуму: $f_{-3\text{дБ}} = \frac{GBW}{K_N}$, де для інвертуючого каскаду $K_N = 1 + \left|\frac{R_f}{R_{in}}\right| = 1 + 10 = 11$.

---

#### Завдання 8: Швидкість наростання (Slew Rate) та спотворення синусоїди
На неінвертуючий підсилювач подається високочастотний синусоїдальний сигнал. Паспортна швидкість наростання ОП становить $SR = 0.5\ \text{В}/\mu\text{с}$.

* **Вихідні дані:**
  * $SR = 0.5\ \text{В}/\mu\text{с} = 5.0 \cdot 10^5\ \text{В/с}$.
  * Амплітуда вихідного синусоїдального сигналу: $V_p = 4.0\ \text{В}$ ($V_{p-p} = 8.0\ \text{В}$).
* **Завдання:**
  1. Розрахувати граничну частоту повної потужності $f_{\text{max}}$ (частоту, вище якої синусоїда перетворюється на трикутник).
  2. Якщо робоча частота сигналу становить $f = 50.0\ \text{кГц}$, якою є максимальна допустима амплітуда $V_{p(\text{max})}$ без появи швидкостійних спотворень?
* 💡 **Підказка:** $\left. \frac{dU}{dt} \right|_{\text{max}} = 2\pi f V_p \le SR \implies f_{\text{max}} = \frac{SR}{2\pi V_p}$.

---

#### Завдання 9: Трансімпедансний підсилювач (TIA) для фотодіода
Для вимірювання світлового потоку лазера застосовується PIN-фотодіод, увімкнений у фотогальванічному режимі (на входи ОП).

```text
               ┌──────────[ R_f: 500 кОм ]──────────┐
               │                                    │
               ├───────────────┤├───────────────────┤  C_f (корекція)
               │                                    │
               ├───┐                                │
               │  ┌┴┐                               │
     PIN       │▲ │-│                               │
   фотодіод    ││ │ ├───────────────────────────────┴────► U_вих
  (C_d: 50 пФ) └┬─┤+│
                │ └┬┘
               ─┴──┴─ GND
```

* **Вихідні дані:**
  * Фотострум діода: $I_{ph} = 0\dots 8.0\ \mu\text{A}$.
  * Бар'єрна ємність фотодіода: $C_d = 50.0\ \text{пФ}$.
  * Резистор зворотного зв'язку: $R_f = 500.0\ \text{к}\Omega$.
  * ОП: $GBW = 4.0\ \text{МГц}$, польовий вхід ($I_{IB} \approx 0$).
* **Завдання:**
  1. Розрахувати діапазон вихідної напруги $U_{\text{вих}} = I_{ph} \cdot R_f$.
  2. Пояснити, чому без конденсатора $C_f$ виникає самозбудження (генерація) схеми.
  3. За формулою оптимуму Баттерворта $45^\circ$ знайти ємність коригуючого конденсатора $C_f = \sqrt{\frac{C_d}{2\pi R_f GBW}}$.
  4. Знайти результуючу смугу пропускання фотоприймача $f_{-3\text{дБ}} \approx \frac{1}{2\pi R_f C_f}$.
* 💡 **Підказка:** Ємність $C_d$ створює полюс у петлі зворотного зв'язку, що зсуває фазу на $90^\circ$, викликаючи нестабільність. $C_f$ додає нуль компенсації.

#### Завдання 10: Розрахунок CMRR диференційного підсилювача при допусках резисторів $1\%$ та $0.1\%$
Диференційний підсилювач має номінальне підсилення $K_d = 10.0$ ($R_1 = R_3 = 10\ \text{к}\Omega$, $R_2 = R_4 = 100\ \text{к}\Omega$). На вхід діє синфазна завада мережі $U_{cm} = 10.0\ \text{В}$ (50 Гц).

* **Вихідні дані:**
  * $K_d = 10.0$, $U_{cm} = 10.0\ \text{В}$.
  * Власний $\text{CMRR}_{\text{ОП}} = 90\ \text{дБ}$.
* **Завдання:**
  1. Розрахувати $\text{CMRR}_{\text{res}}$ для звичайних металоплівкових резисторів з допуском $\pm 1\%$ ($\epsilon = 0.01$). Знайти амплітуду завади на виході $V_{\text{out}(cm)}$.
  2. Розрахувати $\text{CMRR}_{\text{res}}$ для прецизійних резисторів з допуском $\pm 0.1\%$ ($\epsilon = 0.001$). Знайти $V_{\text{out}(cm)}$.
  3. Порівняти отримані рівні завад із ціною молодшого розряду (1 LSB) 12-бітного АЦП з опорною напругою $V_{\text{ref}} = 5.0\ \text{В}$ ($\text{LSB} = \frac{5.0\ \text{В}}{4096} \approx 1.22\ \text{мВ}$). Зробити інженерний висновок.
* 💡 **Підказка:** $\text{CMRR}_{\text{res}} \approx \frac{1 + K_d}{4 \epsilon}$. Напруга завади на виході: $V_{\text{out}(cm)} = U_{cm} \cdot \frac{K_d}{\text{CMRR}_{\text{res}}}$.
