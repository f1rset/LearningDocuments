## 🎯 Ключові концепції (Core Concepts)
1. **Кососиметричні (Anti-Symmetric / Skew-Symmetric) та Косоермітові матриці:** Власні значення є суто уявними ($\lambda = j\omega$).
2. **Ермітові матриці (Hermitian Matrices $A^* = A$):** Комплексний аналог симетричних матриць.
3. **Унітарні матриці (Unitary Matrices $U^* U = I$):** Власні значення лежать на одиничному колі ($|\lambda| = 1$).
4. **Нормальні матриці (Normal Matrices $A^* A = A A^*$):** Найширший клас матриць, що допускають унітарну діагоналізацію (теорема Шура).
5. **Пряма сума та ортогональні проектори (Direct Sums & Projections):** Спектральний розклад одиниці $I = \sum P_i$.

---

## 1. Класифікація спеціальних класів матриць

Нехай $A \in \mathbb{C}^{n \times n}$ — комплексна квадратна матриця, а $A^* = \overline{A}^T$ — її ермітове спряження (транспонування + комплексне спряження).

```text
                                Нормальні матриці (Normal Matrices: A* A = A A*)
                                                       |
         +---------------------------------------------+---------------------------------------------+
         |                                             |                                             |
   Ермітові (Hermitian)                     Косоермітові (Skew-Hermitian)                 Унітарні (Unitary)
        A* = A                                      A* = -A                                    U* U = I
   (Дійсний аналог: Симетричні)               (Дійсний аналог: Кососиметричні)           (Дійсний аналог: Ортогональні)
   Власні значення: Дійсні (λ ∈ R)            Власні значення: Суто уявні (λ = j*b)       Власні значення: |λ| = 1
```

---

## 2. Симетричні та Кососиметричні матриці (Symmetric & Skew-Symmetric)

### 2.1. Розклад довільної квадратної матриці
Будь-яку квадратну дійсну матрицю $A \in \mathbb{R}^{n \times n}$ можна **єдиним чином** розкласти на суму симетричної та кососиметричної матриць:
$$\mathbf{A = A_{\text{sym}} + A_{\text{skew}} = \frac{A + A^T}{2} + \frac{A - A^T}{2}}$$

* **Симетрична частина:** $A_{\text{sym}}^T = A_{\text{sym}}$.
* **Кососиметрична частина:** $A_{\text{skew}}^T = -A_{\text{skew}}$.
  * Головна діагональ кососиметричної матриці **завжди складається з нулів** ($a_{ii} = -a_{ii} \implies a_{ii} = 0$).

### 2.2. Властивості кососиметричних матриць ($A^T = -A$):
1. **Квадратична форма завжди тотожно дорівнює нулю:**
   $$\mathbf{x}^T A_{\text{skew}} \mathbf{x} = 0 \quad \forall \mathbf{x} \in \mathbb{R}^n$$
   *(Оскільки $(\mathbf{x}^T A \mathbf{x})^T = \mathbf{x}^T A^T \mathbf{x} = -\mathbf{x}^T A \mathbf{x} \implies 2\mathbf{x}^T A \mathbf{x} = 0$).*
2. **Власні значення є суто уявними:**
   $$\lambda_i = j \omega_i \quad (\text{де } \omega_i \in \mathbb{R}, \text{Re}(\lambda_i) = 0)$$
3. **Експонента від кососиметричної матриці є ортогональною:**
   Якщо $A^T = -A$, то $Q = e^A$ є ортогональною матрицею ($Q^T Q = I$).
   *(Фундаментальний факт для фізики та робототехніки: алгебра Лі $\mathfrak{so}(3)$ нескінченно малих поворотів генерує групу Лі $SO(3)$ 3D обертань!).*

## 3. Ермітові та Унітарні матриці (Hermitian & Unitary)

### 3.1. Ермітові матриці (Hermitian: $A^* = A$)
* Комплексний скалярний добуток: $\langle \mathbf{u}, \mathbf{v} \rangle = \mathbf{u}^* \mathbf{v} = \sum \overline{u}_i v_i$.
* **Властивість:** Для будь-якого $\mathbf{x} \in \mathbb{C}^n$ величина $\mathbf{x}^* A \mathbf{x}$ є **строго дійсною** ($\mathbf{x}^* A \mathbf{x} \in \mathbb{R}$).
* **Спектральна теорема:** Будь-яка ермітова матриця унітарно діагоналізовна:
  $$\mathbf{A = U \Lambda U^* = \sum_{i=1}^n \lambda_i \mathbf{u}_i \mathbf{u}_i^*}, \quad \lambda_i \in \mathbb{R}, \quad U^* U = I$$

### 3.2. Унітарні матриці (Unitary: $U^* U = U U^* = I$)
* Комплексний аналог ортогональних матриць.
* **Зберігають ермітову норму:** $\|U\mathbf{x}\| = \|\mathbf{x}\|$.
* **Власні значення:** Усі власні значення мають одиничний модуль:
  $$\lambda = e^{j\theta} \implies |\lambda| = 1$$
* **Спектральний розклад унітарної матриці:**
  $$\mathbf{U = V \Lambda V^*}, \quad \Lambda = \text{diag}(e^{j\theta_1}, e^{j\theta_2}, \dots, e^{j\theta_n})$$

---

## 4. Нормальні матриці та Теорема Шура (Normal Matrices & Schur Triangulation)

### 4.1. Нормальні матриці (Normal Matrices: $A^* A = A A^*$)
Матриця комутує зі своїм ермітовим спряженням.
* Клас нормальних матриць включає: симетричні, кососиметричні, ермітові, косоермітові, ортогональні, унітарні та циркулянтні матриці.
* **Головна теорема про нормальні матриці:** Матриця $A$ допускає **унітарну діагоналізацію ($A = U \Lambda U^*$) тоді і тільки тоді, коли вона є нормальною** ($A^* A = A A^*$).

### 4.2. Теорема Шура (Schur's Triangularization Theorem)
Будь-яку квадратну матрицю $A \in \mathbb{C}^{n \times n}$ можна унітарно звести до **верхньої трикутної форми (матриця Шура $T$)**:
$$\mathbf{A = U T U^*}$$
де $U$ — унітарна матриця, а $T$ — верхня трикутна матриця, на головній діагоналі якої стоять власні значення матриці $A$.

---

## 5. Прямі суми та спектральні проектори (Spectral Decomposition of Identity)

### 5.1. Розклад одиничного оператора
Якщо матриця $A$ є нормальною ($A = U \Lambda U^*$), то множина її власних векторів $\{\mathbf{u}_1, \dots, \mathbf{u}_n\}$ утворює ортонормований базис простору $\mathbb{C}^n$.
Введемо **ортогональні проектори (Orthogonal Projectors)** на відповідні 1-вимірні власні підпростори:
$$P_i = \mathbf{u}_i \mathbf{u}_i^*$$

Властивості проекторів:
1. **Ідемпотентність:** $P_i^2 = (\mathbf{u}_i \mathbf{u}_i^*)(\mathbf{u}_i \mathbf{u}_i^*) = \mathbf{u}_i (\mathbf{u}_i^* \mathbf{u}_i) \mathbf{u}_i^* = P_i$.
2. **Взаємна ортогональність:** $P_i P_j = \mathbf{0}$ для $i \neq j$.
3. **Розклад одиниці (Resolution of Identity):**
   $$\mathbf{I = \sum_{i=1}^n P_i = P_1 + P_2 + \dots + P_n}$$
4. **Спектральний розклад оператора через проектори:**
   $$\mathbf{A = \sum_{i=1}^n \lambda_i P_i = \lambda_1 P_1 + \lambda_2 P_2 + \dots + \lambda_n P_n}$$
5. **Обчислення будь-якої матричної функції $f(A)$:**
   $$f(A) = \sum_{i=1}^n f(\lambda_i) P_i = f(\lambda_1) P_1 + \dots + f(\lambda_n) P_n$$
   *(Наприклад, $\sqrt{A} = \sum \sqrt{\lambda_i} P_i$, $\ln(A) = \sum \ln(\lambda_i) P_i$, $e^{At} = \sum e^{\lambda_i t} P_i$).*

|---|---|---|---|
