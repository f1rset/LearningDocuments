# 04. Неперервні випадкові величини та щільності розподілу (Continuous Random Variables & Densities)

## 🎯 Ключові концепції (Core Concepts)
1. **Неперервна випадкова величина (CRV) та щільність (PDF $f(x)$):** Локальна концентрація ймовірності.
2. **Властивості PDF та CDF:** $P(X = c) = 0$, $F(x) = \int_{-\infty}^x f(t)\,dt$, $f(x) = F'(x)$.
3. **Рівномірний та Експоненційний розподіли:** Неперервна властивість безпам'ятності.
4. **Нормальний (Гауссів) розподіл ($\mathcal{N}(\mu, \sigma^2)$):** $Z$-стандартизація, функція Лапласа $\Phi(z)$ та правило $3\sigma$.
5. **Розподіли Гамма, Бета, Логнормальний та Коші:** Моделювання часу життя, пропорцій та важких хвостів.
6. **Перетворення випадкових величин (Change of Variables):** $f_Y(y) = f_X(g^{-1}(y)) \left|\frac{d g^{-1}(y)}{dy}\right|$.

## 1. Означення та фундаментальні властивості (CRV)

### 1.1. Щільність розподілу (Probability Density Function - PDF $f(x)$)
Випадкова величина $X$ називається **неперервною**, якщо існує така невід'ємна функція $f(x)$, що для будь-якого інтервалу $[a, b]$:
$$P(a \le X \le b) = \int_a^b f(x)\,dx$$

* **Властивості PDF:**
  1. $f(x) \ge 0$ для всіх $x \in \mathbb{R}$.
  2. **Умова нормування:** $\int_{-\infty}^{+\infty} f(x)\,dx = 1$ (загальна площа під кривою дорівнює 1).
  3. **Ймовірність окремої точки дорівнює нулю:** $\forall c \in \mathbb{R}: P(X = c) = \int_c^c f(x)\,dx = 0$.
     *(Тому не має значення, строгі нерівності чи ні: $P(a \le X \le b) = P(a < X < b)$)*.

```text
    f(x) ^              Площа під кривою = P(a <= X <= b)
         |                    .-----.
         |                   /       \
         |                  /|||||||||\
         +-----------------|---------|--------> x
         -∞                a         b        +∞
```

### 1.2. Кумулятивна функція розподілу (CDF $F(x)$)
$$F(x) = P(X \le x) = \int_{-\infty}^x f(t)\,dt \iff f(x) = F'(x) = \frac{d F(x)}{dx}$$

## 2. Основні неперервні розподіли (Key Continuous Distributions)

### 2.1. Неперервний рівномірний розподіл ($\text{Uniform}(a, b)$ або $U(a, b)$)
Ймовірність однакова в будь-якій точці відрізка $[a, b]$:
$$f(x) = \begin{cases} \frac{1}{b - a}, & x \in [a, b] \\ 0, & x \notin [a, b] \end{cases}, \qquad F(x) = \begin{cases} 0, & x < a \\ \frac{x - a}{b - a}, & a \le x \le b \\ 1, & x > b \end{cases}$$
* **Характеристики:** $E[X] = \frac{a + b}{2}$, $\operatorname{Var}(X) = \frac{(b - a)^2}{12}$.

### 2.2. Експоненційний (показниковий) розподіл ($\text{Exponential}(\lambda)$)
Моделює час очікування до настання наступної події у пуассонівському процесі зі швидкістю $\lambda > 0$:
$$f(x) = \begin{cases} \lambda e^{-\lambda x}, & x \ge 0 \\ 0, & x < 0 \end{cases}, \qquad F(x) = \begin{cases} 1 - e^{-\lambda x}, & x \ge 0 \\ 0, & x < 0 \end{cases}$$
* **Характеристики:** $E[X] = \frac{1}{\lambda}$, $\operatorname{Var}(X) = \frac{1}{\lambda^2}$.
* **👑 Неперервна властивість відсутності пам'яті (Memoryless Property):**
  $$P(X > s + t \mid X > s) = \frac{P(X > s + t)}{P(X > s)} = \frac{e^{-\lambda(s+t)}}{e^{-\lambda s}} = e^{-\lambda t} = P(X > t)$$
* **Функція інтенсивності відмов (Hazard Rate):** $h(t) = \frac{f(t)}{1 - F(t)} = \frac{\lambda e^{-\lambda t}}{e^{-\lambda t}} = \lambda = \text{const}$.

### 2.3. Нормальний (Гауссів) розподіл ($\text{Normal}(\mu, \sigma^2)$ або $\mathcal{N}(\mu, \sigma^2)$)
Найважливіший розподіл у теорії ймовірностей та статистиці:
$$f(x) = \frac{1}{\sigma \sqrt{2\pi}} \exp\left( -\frac{(x - \mu)^2}{2\sigma^2} \right), \quad x \in (-\infty, +\infty)$$
* **Параметри:** $\mu = E[X]$ — центр симетрії (математичне сподівання), $\sigma^2 = \operatorname{Var}(X)$ — масштаб/розсіювання (дисперсія).

```text
    f(x) ^                    Нормальний дзвін Гаусса
         |                             /\
         |                            /  \
         |                           /    \
         |             .------------'  μ   '------------.
         +-------------|--------------|--------------|--------> x
                      μ-3σ            μ             μ+3σ
```

* **Стандартний нормальний розподіл ($\mathcal{N}(0, 1)$) та $Z$-трансформація:**
  Якщо $X \sim \mathcal{N}(\mu, \sigma^2)$, то стандартизована змінна $Z = \frac{X - \mu}{\sigma} \sim \mathcal{N}(0, 1)$:
  $$\varphi(z) = \frac{1}{\sqrt{2\pi}} e^{-z^2/2}, \qquad \Phi(z) = P(Z \le z) = \frac{1}{\sqrt{2\pi}}\int_{-\infty}^z e^{-t^2/2}\,dt$$
  * *Симетрія:* $\Phi(-z) = 1 - \Phi(z)$.
  * *Обчислення інтервалу:* $P(a \le X \le b) = \Phi\left(\frac{b - \mu}{\sigma}\right) - \Phi\left(\frac{a - \mu}{\sigma}\right)$.
* **Правило трьох сигм ($3\sigma$ Rule):**
  * $P(\mu - \sigma \le X \le \mu + \sigma) = \Phi(1) - \Phi(-1) \approx 68.27\%$
  * $P(\mu - 2\sigma \le X \le \mu + 2\sigma) = \Phi(2) - \Phi(-2) \approx 95.45\%$
  * $P(\mu - 3\sigma \le X \le \mu + 3\sigma) = \Phi(3) - \Phi(-3) \approx 99.73\%$

### 2.4. Інші важливі неперервні розподіли

1. **Логнормальний ($\text{LogNormal}(\mu, \sigma^2)$):**
   $X > 0$, $\ln X \sim \mathcal{N}(\mu, \sigma^2)$. Використовується для моделювання цін акцій, доходів, розмірів файлів.
2. **Гамма-розподіл ($\text{Gamma}(\alpha, \beta)$):**
   Узагальнення експоненційного розподілу. Час очікування $\alpha$ подій у пуассонівському процесі:
   $$f(x) = \frac{\beta^\alpha}{\Gamma(\alpha)} x^{\alpha - 1} e^{-\beta x}, \quad E[X] = \frac{\alpha}{\beta}, \; \operatorname{Var}(X) = \frac{\alpha}{\beta^2}$$
3. **Бета-розподіл ($\text{Beta}(\alpha, \beta)$):**
   Визначений на інтервалі $x \in [0, 1]$. Використовується у Байєсівській статистиці як спряжений апріорний розподіл для ймовірності успіху $p$.
4. **Розподіл Коші ($\text{Cauchy}(x_0, \gamma)$):**
   $f(x) = \frac{1}{\pi \gamma [1 + ((x - x_0)/\gamma)^2]}$. Має важкі хвости (Heavy Tails), для нього **математичне сподівання та дисперсія не існують**!

## 3. Функціональні перетворення випадкових величин (Change of Variables)

Нехай $Y = g(X)$, де $g(x)$ — строго монотонна диференційовна функція з оберненою $x = g^{-1}(y)$:
$$f_Y(y) = f_X(g^{-1}(y)) \cdot \left| \frac{d}{dy} g^{-1}(y) \right| = \frac{f_X(x)}{|g'(x)|}$$

* *Приклад (Генерація випадкових величин / Inverse Transform Sampling):*
  Якщо $U \sim \text{Uniform}(0, 1)$, а $F(x)$ — неперервна строго монотонна CDF, то $X = F^{-1}(U)$ має розподіл із функцією розподілу $F(x)$!

---

## ⚠️ Підводні камені та типові помилки (Pitfalls)

1. **Тлумачення щільності $f(x)$ як ймовірності:**
   Значення щільності $f(x)$ **може бути більшим за 1** (наприклад, для $U(0, 0.1)$ щільність $f(x) = 10$). Ймовірністю є лише площа під кривою $\int_a^b f(x)\,dx \le 1$.
2. **Забутий модуль похідної при заміні змінних:**
   У формулі $f_Y(y) = f_X(g^{-1}(y)) |\frac{dx}{dy}|$ модуль $| \cdot |$ є критично важливим (наприклад, при $y = -x$, $dy/dx = -1$, але щільність не може бути від'ємною!).
3. **Ілюзія існування моментів (Розподіл Коші):**
   Неможливо застосовувати закон великих чисел чи ЦГТ до розподілів із важкими хвостами на кшталт Коші, оскільки інтеграл $\int x f(x)dx$ розбігається.
