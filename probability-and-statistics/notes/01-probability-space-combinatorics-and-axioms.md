## 🎯 Ключові концепції (Core Concepts)
1. **Простір елементарних подій ($\Omega$) та події:** Множина всіх можливих наслідків випадкового експерименту.
2. **Алгебра та $\sigma$-алгебра подій ($\mathcal{F}$):** Замкненість відносно об'єднання, перетину та доповнення.
3. **Аксіоматика Колмогорова (Kolmogorov's Axioms):** Ймовірнісний простір $(\Omega, \mathcal{F}, P)$.
4. **Основи комбінаторики (Combinatorics Basics):** Правила суми та добутку, перестановки ($P_n$), розміщення ($A_n^k$), комбінації ($C_n^k = \binom{n}{k}$).
5. **Класична та геометрична ймовірність (Classical & Geometric Probability):** Формула Лапласа та відношення геометричних мір.
6. **Формула включень-виключень (Inclusion-Exclusion Principle):** Ймовірність об'єднання довільних подій.

## 1. Простір елементарних подій та операції над подіями

### 1.1. Означення
* **Експеримент (Random Experiment):** Будь-який процес, результат якого неможливо однозначно передбачити наперед.
* **Простір елементарних подій (Sample Space $\Omega$):** Множина всіх взаємовиключних неподільних наслідків $\omega \in \Omega$.
  * *Приклад (кидання грального кубика):* $\Omega = \{1, 2, 3, 4, 5, 6\}$.
  * *Приклад (час очікування автобуса):* $\Omega = [0, +\infty)$.
* **Випадкова подія (Event $A \subseteq \Omega$):** Будь-яка підмножина простору $\Omega$.
  * Подія $A$ **відбувається**, якщо наслідок експерименту $\omega \in A$.
  * **Достовірна подія (Certain Event):** $\Omega$ (відбувається завжди).
  * **Неможлива подія (Impossible Event):** $\emptyset$ (не відбувається ніколи).

### 1.2. Теоретико-множинні операції над подіями (Set Operations)

| Операція | Позначення | Подія | Інтерпретація |
| :--- | :--- | :--- | :--- |
| **Доповнення (Complement)** | $A^c = \bar{A} = \Omega \setminus A$ | Протилежна подія | $A$ не відбулася |
| **Об'єднання (Union)** | $A \cup B$ | Сума подій | Відбулася хоча б одна з подій: $A$ або $B$ |
| **Перетин (Intersection)** | $A \cap B = AB$ | Добуток подій | Відбулися обидві події: і $A$, і $B$ |
| **Різниця (Difference)** | $A \setminus B = A \cap \bar{B}$ | Різниця подій | Відбулася $A$, але не відбулася $B$ |
| **Несумісність (Disjoint / Mutually Exclusive)** | $A \cap B = \emptyset$ | Несумісні події | Події не можуть відбутися одночасно |

* **Закони де Моргана (De Morgan's Laws):**
  $$\overline{A \cup B} = \bar{A} \cap \bar{B}, \qquad \overline{A \cap B} = \bar{A} \cup \bar{B}$$

```text
       Множина Ω
      +-----------------------------+
      |      A               B      |
      |   /-----\         /-----\   |
      |  (   A   \       /   B   )  |
      |   \   A ∩ B     /       )   |
      |    \-----/       \-----/    |
      +-----------------------------+
```

## 2. Аксіоматика Колмогорова (Kolmogorov's Probability Axioms)

Імовірнісний простір задається трійкою $(\Omega, \mathcal{F}, P)$, де $\mathcal{F}$ — $\sigma$-алгебра підмножин $\Omega$, а $P: \mathcal{F} \to [0, 1]$ — ймовірнісна міра.

### 2.1. Три аксіоми Колмогорова
1. **Невід'ємність (Non-negativity):**
   $$\forall A \in \mathcal{F}: \quad P(A) \ge 0$$
2. **Нормованість (Normalization):**
   $$P(\Omega) = 1$$
3. **Зліченна адитивність ($\sigma$-Additivity):**
   Для будь-якої зліченної послідовності попарно несумісних подій $A_1, A_2, \dots$ ($A_i \cap A_j = \emptyset$ при $i \neq j$):
   $$P\left(\bigcup_{i=1}^\infty A_i\right) = \sum_{i=1}^\infty P(A_i)$$

### 2.2. Наслідки з аксіом (Fundamental Properties)
* Ймовірність неможливої події: $P(\emptyset) = 0$.
* Ймовірність протилежної події: $P(\bar{A}) = 1 - P(A)$.
* Монотонність: Якщо $A \subseteq B$, то $P(A) \le P(B)$, причому $P(B \setminus A) = P(B) - P(A)$.
* Межі ймовірності: $\forall A \in \mathcal{F}: 0 \le P(A) \le 1$.
* **Ймовірність об'єднання двох подій (Addition Rule):**
  $$P(A \cup B) = P(A) + P(B) - P(A \cap B)$$
* **Формула включень-виключень для $n$ подій (Inclusion-Exclusion Principle):**
  $$P\left(\bigcup_{i=1}^n A_i\right) = \sum_{i=1}^n P(A_i) - \sum_{1 \le i < j \le n} P(A_i \cap A_j) + \sum_{1 \le i < j < k \le n} P(A_i \cap A_j \cap A_k) - \dots + (-1)^{n-1} P\left(\bigcap_{i=1}^n A_i\right)$$
* **Нерівність Буля-Бонферроні (Boole's / Union Bound):**
  $$P\left(\bigcup_{i=1}^n A_i\right) \le \sum_{i=1}^n P(A_i)$$

## 3. Моделі обчислення ймовірностей

### 3.1. Класична ймовірність (Classical Discrete Model)
Якщо простір $\Omega$ скінченний ($|\Omega| = N$) і всі елементарні наслідки є **рівноможливими (equally likely)**:
$$P(A) = \frac{|A|}{|\Omega|} = \frac{m}{N} = \frac{\text{кількість сприятливих наслідків}}{\text{загальна кількість наслідків}}$$

### 3.2. Геометрична ймовірність (Geometric Probability)
Якщо простір $\Omega \subset \mathbb{R}^n$ має скінченну геометричну міру $\mu(\Omega) > 0$ (довжина, площа, об'єм), і точка навмання кидається в $\Omega$:
$$P(A) = \frac{\mu(A)}{\mu(\Omega)}$$
* *Класичний приклад (Задача про зустріч / Meeting Problem):* Двоє людей домовляються зустрітися між 12:00 та 13:00. Кожен чекає 15 хв ($1/4$ год). Ймовірність зустрічі:
  $$\Omega = [0, 1] \times [0, 1], \quad A = \{(x, y) \mid |x - y| \le 1/4\} \implies P(A) = \frac{1 - (3/4)^2}{1^2} = \frac{7}{16} = 0.4375$$

## 4. Комбінаторні методи підрахунку (Combinatorics)

| Тип вибірки | Враховується порядок? | Повторення дозволені? | Формула кількості варіантів |
| :--- | :---: | :---: | :--- |
| **Перестановки без повторень (Permutations)** | Так | Ні | $P_n = n! = n \cdot (n-1) \dots 1$ |
| **Перестановки з повтореннями** | Так | Так | $\bar{P}_n(n_1, \dots, n_k) = \frac{n!}{n_1! n_2! \dots n_k!}$ |
| **Розміщення без повторень (Arrangements)** | Так | Ні | $A_n^k = \frac{n!}{(n - k)!} = n(n-1)\dots(n-k+1)$ |
| **Розміщення з повтореннями** | Так | Так | $\bar{A}_n^k = n^k$ |
| **Комбінації без повторень (Combinations)** | Ні | Ні | $C_n^k = \binom{n}{k} = \frac{n!}{k!(n - k)!}$ |
| **Комбінації з повтореннями** | Ні | Так | $\bar{C}_n^k = \binom{n + k - 1}{k}$ |

* **Біном Ньютона (Binomial Theorem):**
  $$(a + b)^n = \sum_{k=0}^n \binom{n}{k} a^k b^{n-k}$$
* **Властивості біноміальних коефіцієнтів:**
  $$\binom{n}{k} = \binom{n}{n-k}, \quad \binom{n}{k} = \binom{n-1}{k-1} + \binom{n-1}{k}, \quad \sum_{k=0}^n \binom{n}{k} = 2^n$$

## ⚠️ Підводні камені та типові помилки (Pitfalls)

1. **Застосування класичної ймовірності без перевірки рівноможливості:**
   Формула $P(A) = m/N$ працює **тільки** коли кожен елементарний наслідок має абсолютно однакову ймовірність (наприклад, для симетричного кубика, а не деформованого).
2. **Парадокс Монті Голла / Неправильне визначення простору $\Omega$:**
   Неврахування процесу вибору або інтуїтивне ігнорування залежностей спотворює розмір простору наслідків.
3. **Плутанина між несумісністю та незалежністю:**
   * Несумісність ($A \cap B = \emptyset$) — теоретико-множинна властивість ($P(A \cap B) = 0$).
   * Незалежність ($P(A \cap B) = P(A)P(B)$) — ймовірнісна властивість.
   * Дві події з ненульовими ймовірностями **не можуть** бути одночасно несумісними та незалежними!
