# 📐 Стандарт та Правила оформлення матеріалів курсу (Style Guide)

Цей документ є обов'язковою інструкцією для людей та ШІ-асистентів (Antigravity, Cursor, Claude, Gemini тощо) щодо ведення та структурування конспектів лекцій і навчальних матеріалів.

---

## 📌 Обов'язкова структура для кожної лекції

Кожна лекція (наприклад, `analog-circuit-design/lectures/l1/`, `analog-circuit-design/lectures/l2/` тощо) **повинна містити мінімум 2 документи**:
1. **`README.md` (або `lecture.md`)** — Детальний академічний конспект лекції за шаблоном [`.templates/LECTURE_TEMPLATE.md`](LECTURE_TEMPLATE.md).
2. **`cheat-sheet.md`** — Компактна інженерна шпаргалка / концентрована вижимка за шаблоном [`.templates/CHEATSHEET_TEMPLATE.md`](CHEATSHEET_TEMPLATE.md).

---

## 🎯 Принципи викладу матеріалу

1. **Принцип «Від інтуїції до суворої математики»:**
   * Спочатку надати коротке інтуїтивне пояснення / аналогію явища ("на пальцях").
   * Потім подати чіткі математичні викладки та формули у форматі KaTeX (`$ ... $`).
   * Завершити схемотехнічним аналізом (схема, графік або ASCII/Mermaid діаграма).

2. **Принцип самодостатності Cheat Sheet (Формули + Суть):**
   * Шпаргалка (`cheat-sheet.md`) повинна містити **найважливішу квінтесенцію теми**, навіть якщо в темі **немає математичних формул** (або їх мало).
   * Обов'язково виносити: ключові визначення, класифікації, принципи роботи, архітектурні блоки, порівняльні таблиці, емпіричні правила (Rules of Thumb) та критичні підводні камені.

3. **Обов'язкові структурні блоки:**
   * **⚠️ Підводні камені / Типові помилки:** Виділені блоки з помилками початківців або небезпечними режимами роботи компонентів.
   * **💡 Практичне застосування:** Де це зустрічається в реальних схемах (підсилювачі, фільтри, живлення, сенсори).
   * **Табличний підсумок / Порівняння:** Наприкінці кожного модуля або лекції.

4. **Наскрізна навігація:**
   * Кожен документ повинен мати навігаційні кнопки зверху і знизу:
     `[⬅️ Попередня лекція/тема] | [🏠 Зміст] | [Наступна лекція/тема ➡️] | [⚡ Cheat Sheet]`

## 📂 Дерево структури проєкту

```text
.
├── .templates/                     <- Прихована папка шаблонів та інструкцій
│   ├── GUIDELINES.md               <- Загальний стандарт та правила
│   ├── LECTURE_TEMPLATE.md         <- Шаблон детального конспекту лекції
│   └── CHEATSHEET_TEMPLATE.md      <- Шаблон шпаргалки (концепції + формули + правила)
├── .cursorrules                    <- Автоматичні правила для Cursor / ШІ
├── AGENTS.md                       <- Інструкції для ШІ-агентів (Antigravity / Claude / Gemini)
└── analog-circuit-design/          <- Матеріали курсу «Аналогова схемотехніка»
    ├── prerequisites/              <- Базові фізичні та схемотехнічні концепції
    │   ├── README.md
    │   ├── cheat-sheet.md
    │   └── 01-*.md ... 09-*.md
    └── lectures/                   <- Лекції курсу
        ├── l1/
        │   ├── README.md           <- Детальний конспект
        │   ├── cheat-sheet.md      <- Шпаргалка лекції
        │   └── [джерела/PDF]
        └── l2/ ...
```
