## 2. Побудова малосигнальної еквівалентної схеми

### 2.1. Фізичні припущення для робочої смуги частот
1. Реактивні опори всіх розділових та блокувальних конденсаторів вважаються нульовими: $X_C = \frac{1}{\omega C} \approx 0$ (коротке замикання по AC).
2. Джерело постійної напруги живлення $+E_ж$ по змінному струму з'єднане із землею: $U_{AC}(+E_ж) = 0$ (GND).
3. Паразитні міжелектродні ємності транзисторів не враховуються (розрив кола по AC).

## 3. Математична модель: Матриця вузлових провідностей $[Y]$

### 3.1. Запис вузлових рівнянь за I законом Кірхгофа
$$[Y] \cdot [U] = [I]$$

де матриця провідностей формується за правилом:
* $Y_{ii} = \sum G_{\text{підключених до вузла } i}$
* $Y_{ij} = -\sum G_{\text{зв'язку між } i \text{ та } j}$
* Додавання внесків залежних джерел струму $g_m \cdot U_{ctrl}$.

```text
       ┌                   ┐   ┌     ┐   ┌     ┐
       │ Y11   Y12   Y13   │   │ U_1 │   │ I_1 │
       │ Y21   Y22   Y23   │ · │ U_2 │ = │  0  │
       │ Y31   Y32   Y33   │   │ U_3 │   │  0  │
       └                   ┘   └     ┘   └     ┘
```

## 4. Аналітичне виведення цільових характеристик

### 4.1. Розрахунок визначника $\Delta$ та алгебраїчних доповнень $\Delta_{ij}$
* Головний детермінант матриці: $\Delta = \det([Y])$
* Алгебраїчне доповнення $\Delta_{11}$:
  $$\Delta_{11} = (-1)^{1+1} \cdot M_{11}$$
* Алгебраїчне доповнення $\Delta_{12}$:
  $$\Delta_{12} = (-1)^{1+2} \cdot M_{12}$$

### 4.2. Формули характеристик чотириполюсника
* **Коефіцієнт підсилення за напругою:**
  $$K_U = \frac{U_{\text{вих}}}{U_{\text{вх}}} = \frac{\Delta_{12}}{\Delta_{11}}$$
* **Вхідний опір:**
  $$R_{\text{вх}} = \frac{1}{Y_{\text{вх}}} = \frac{\Delta_{11}}{\Delta}$$
* **Вихідний опір:**
  $$R_{\text{вих}} = \frac{1}{Y_{\text{вих}}} = \left. \frac{\Delta_{22}}{\Delta} \right|_{G_н = 0}$$
