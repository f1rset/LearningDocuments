# 10. Диференціальні рівняння та системи (Differential Equations & Systems)

## 🎯 Ключові концепції (Core Concepts)
1. **Звичайні диференціальні рівняння (Ordinary Differential Equations - ODE):** Порядок, загальний та частинний розв'язки, задача Коші (Initial Value Problem).
2. **Рівняння 1-го порядку (First-Order ODEs):** З відокремлюваними змінними, однорідні, лінійні (інтегрувальний множник / метод варіації сталої), рівняння Бернуллі та в повних диференціалах.
3. **Лінійні ДР 2-го порядку зі сталими коефіцієнтами (2nd Order Linear ODEs):** Характеристичне рівняння, розв'язки для дійсних/комплексних коренів, метод підбору частинного розв'язку.
4. **Метод варіації довільних сталих (Variation of Parameters & Wronskian):** Визначник Вронського.
5. **Системи лінійних диференціальних рівнянь (Systems of ODEs):** Матричний вигляд $\dot{\mathbf{x}} = A\mathbf{x}$, матрична експонента $e^{At}$, фазові портрети та класифікація особливих точок (вузол, сідло, фокус, центр).

---

## 1. Загальні поняття та задача Коші (Fundamentals & Cauchy Problem)

**Диференціальне рівняння порядку $n$** зв'язує незалежну змінну $x$, невідому функцію $y(x)$ та її похідні $y', y'', \dots, y^{(n)}$:
$$F(x, y, y', y'', \dots, y^{(n)}) = 0$$

* **Загальний розв'язок (General Solution):** Сім'я функцій $y = \varphi(x, C_1, \dots, C_n)$, що містить $n$ незалежних довільних сталих і перетворює рівняння на тотожність.
* **Частинний розв'язок (Particular Solution):** Розв'язок, отриманий при конкретних фіксованих значеннях сталих $C_i$.
* **Задача Коші (Cauchy / Initial Value Problem - IVP):** Знайти розв'язок рівняння $y^{(n)} = f(x, y, y', \dots, y^{(n-1)})$, що задовольняє початкові умови:
  $$y(x_0) = y_0, \quad y'(x_0) = y_1, \quad \dots, \quad y^{(n-1)}(x_0) = y_{n-1}$$
* **Теорема Пікара-Лінделефа (Існування та єдиність):** Якщо функція $f(x, y)$ та її частинна похідна $\frac{\partial f}{\partial y}$ неперервні в околі точки $(x_0, y_0)$, то задача Коші має єдиний розв'язок.

## 2. Диференціальні рівняння 1-го порядку (First-Order ODEs)

### 2.1. Рівняння з відокремлюваними змінними (Separable Equations)
$$y' = f(x) g(y) \iff \frac{dy}{dx} = f(x) g(y) \iff \frac{dy}{g(y)} = f(x)\,dx$$
Інтегруємо обидві частини:
$$\int \frac{dy}{g(y)} = \int f(x)\,dx + C$$

### 2.2. Однорідні рівняння 1-го порядку (Homogeneous 1st Order)
$$y' = f\left(\frac{y}{x}\right)$$
* **Метод розв'язання:** Заміна $u(x) = \frac{y}{x} \implies y = u x \implies y' = u' x + u$.
  $$u' x + u = f(u) \iff x \frac{du}{dx} = f(u) - u \implies \int \frac{du}{f(u) - u} = \int \frac{dx}{x}$$

### 2.3. Лінійні рівняння 1-го порядку (Linear First-Order ODEs)
$$y' + P(x) y = Q(x)$$

* **Метод інтегрувального множника (Integrating Factor $\mu(x)$):**
  Помножимо все рівняння на $\mu(x) = e^{\int P(x)\,dx}$:
  $$\underbrace{\mu(x) y' + \mu(x) P(x) y}_{\frac{d}{dx}(\mu(x) y)} = \mu(x) Q(x)$$
  $$\mu(x) y = \int \mu(x) Q(x)\,dx + C \implies y(x) = e^{-\int P(x)\,dx} \left( \int Q(x) e^{\int P(x)\,dx}\,dx + C \right)$$

* **Метод варіації сталої (Variation of Constants / Метод Бернуллі $y = u v$):**
  1. Знаходимо розв'язок однорідного рівняння $y' + P(x)y = 0 \implies y_0 = C e^{-\int P dx}$.
  2. Вважаємо $C = C(x)$ функцією і підставляємо у вихідне рівняння для знаходження $C'(x)$.

### 2.4. Рівняння Бернуллі (Bernoulli Equation)
$$y' + P(x) y = Q(x) y^n, \quad n \neq 0, 1$$
* **Метод розв'язання:** Ділимо все рівняння на $y^n$: $y^{-n} y' + P(x) y^{1-n} = Q(x)$.
  Робимо заміну $z(x) = y^{1-n} \implies z' = (1-n) y^{-n} y'$. Рівняння стає лінійним відносно $z$:
  $$\frac{1}{1-n} z' + P(x) z = Q(x)$$

### 2.5. Рівняння в повних диференціалах (Exact Differential Equations)
$$M(x, y)\,dx + N(x, y)\,dy = 0$$
Рівняння є точним (exact), якщо:
$$\frac{\partial M}{\partial y} = \frac{\partial N}{\partial x}$$
Тоді існує функція потенціалу $U(x, y)$, така що $dU = M\,dx + N\,dy = 0$, і загальний розв'язок має вигляд:
$$U(x, y) = C, \quad \text{де } U(x, y) = \int M(x, y)\,dx + \int \left( N(x, y) - \frac{\partial}{\partial y}\int M(x, y)\,dx \right) dy$$

## 3. Лінійні рівняння 2-го порядку зі сталими коефіцієнтами

Загальний вигляд:
$$a y'' + b y' + c y = f(x), \quad a \neq 0$$

* **Принцип суперпозиції:** Загальний розв'язок неоднорідного рівняння є сумою загального розв'язку однорідного $y_{\text{одн}}$ та будь-якого частинного розв'язку неоднорідного $y_{\text{част}}$:
  $$y(x) = y_{\text{одн}}(x) + y_{\text{част}}(x)$$

### 3.1. Однорідне рівняння $a y'' + b y' + c y = 0$
Складаємо **характеристичне рівняння (Characteristic Equation)** підстановкою $y = e^{\lambda x}$:
$$a \lambda^2 + b \lambda + c = 0, \quad D = b^2 - 4ac$$

| Випадок коренів | Корені $\lambda_1, \lambda_2$ | Загальний розв'язок однорідного ДР $y_{\text{одн}}(x)$ |
| :--- | :--- | :--- |
| **1. Дійсні різні ($D > 0$)** | $\lambda_1 \neq \lambda_2 \in \mathbb{R}$ | $y_{\text{одн}} = C_1 e^{\lambda_1 x} + C_2 e^{\lambda_2 x}$ |
| **2. Дійсні кратні ($D = 0$)** | $\lambda_1 = \lambda_2 = \lambda$ | $y_{\text{одн}} = (C_1 + C_2 x) e^{\lambda x}$ |
| **3. Комплексно-спряжені ($D < 0$)** | $\lambda_{1,2} = \alpha \pm i \beta$ | $y_{\text{одн}} = e^{\alpha x} (C_1 \cos(\beta x) + C_2 \sin(\beta x))$ |

```text
  Затухаючі коливання (D < 0, α < 0):
      y ^
        |   .---.
        |  /     \     .---.
        | /       \   /     \
        +----------\-/-------\------> x
        |           '         '
```

### 3.2. Метод невизначених коефіцієнтів для $y_{\text{част}}$ (Method of Undetermined Coefficients)

Працює для спеціальних правих частин $f(x)$:

1. **$f(x) = P_m(x) e^{\gamma x}$:**
   $$y_{\text{част}} = x^k Q_m(x) e^{\gamma x}$$
   де $Q_m(x)$ — многочлен того ж степеня $m$, а $k$ — кратність числа $\gamma$ серед коренів характеристичного рівняння ($k = 0, 1, 2$).
2. **$f(x) = e^{\alpha x} [P_m(x)\cos(\beta x) + Q_l(x)\sin(\beta x)]:$**
   $$y_{\text{част}} = x^k e^{\alpha x} [S_N(x)\cos(\beta x) + T_N(x)\sin(\beta x)]$$
   де $N = \max(m, l)$, а $k$ — кратність числа $\alpha + i\beta$ серед коренів характеристичного рівняння.

### 3.3. Загальний метод варіації довільних сталих (Вронскіан / Wronskian)
Якщо відомі два лінійно незалежні розв'язки однорідного рівняння $y_1(x), y_2(x)$:
$$W(x) = \begin{vmatrix} y_1(x) & y_2(x) \\ y_1'(x) & y_2'(x) \end{vmatrix} = y_1 y_2' - y_2 y_1' \neq 0$$

Шукаємо частинний розв'язок у вигляді $y_{\text{част}} = C_1(x) y_1(x) + C_2(x) y_2(x)$, де:
$$C_1'(x) = -\frac{y_2(x) f(x)}{a W(x)}, \quad C_2'(x) = \frac{y_1(x) f(x)}{a W(x)}$$

## 4. Системи лінійних диференціальних рівнянь (Systems of ODEs)

### 4.1. Матрична форма
Однорідна лінійна система зі сталими коефіцієнтами:
$$\frac{d\mathbf{x}}{dt} = A \mathbf{x}, \quad \mathbf{x}(t) \in \mathbb{R}^n, \; A \in \mathbb{R}^{n \times n}$$

* **Загальний розв'язок через власні вектори:**
  Якщо матриця $A$ має $n$ лінійно незалежних власних векторів $\mathbf{v}_1, \dots, \mathbf{v}_n$ з власними значеннями $\lambda_1, \dots, \lambda_n$:
  $$\mathbf{x}(t) = \sum_{k=1}^n C_k e^{\lambda_k t} \mathbf{v}_k$$
* **Матрична експонента (Matrix Exponential $e^{At}$):**
  $$\mathbf{x}(t) = e^{At} \mathbf{x}(0), \quad e^{At} = \sum_{k=0}^\infty \frac{(At)^k}{k!} = I + At + \frac{A^2 t^2}{2} + \dots$$

### 4.2. Фазовий портрет та класифікація точок спокою (2D Phase Portrait)
Для 2D системи $\dot{\mathbf{x}} = A\mathbf{x}$ поведінка біля точки $\mathbf{x} = \mathbf{0}$ повністю визначається слідом $\operatorname{Tr}(A)$ та визначником $\det(A)$:

```text
              Δ = det(A) ^
                         |       Вузол (Node)
                         |       .--------.
                  Центр  |      /  D > 0   \
                  (Center)    /              \
             - - - - - - + - / - - - - - - - - \ - - - - 
                         |  /   Фокус (Spiral)   \
                         | /       D < 0          \
       ------------------+---------------------------> τ = Tr(A)
                         |
                         |     Сідлова точка (Saddle)
                         |            Δ < 0
```

1. **Сідло (Saddle Point):** $\det A < 0$ (власні значення різного знаку $\lambda_1 < 0 < \lambda_2$). Завжди нестійке.
2. **Вузол (Node):** $\det A > 0, D = \operatorname{Tr}^2 - 4\det \ge 0$ (однаковий знак $\lambda$). Стійкий при $\operatorname{Tr} A < 0$, нестійкий при $\operatorname{Tr} A > 0$.
3. **Фокус / Спіраль (Spiral Point):** $\det A > 0, D < 0, \operatorname{Tr} A \neq 0$. Траєкторії закручуються всередину ($\operatorname{Tr} < 0$, стійкий) або назовні ($\operatorname{Tr} > 0$, нестійкий).
4. **Центр (Center):** $\det A > 0, \operatorname{Tr} A = 0$ (чисто уявні $\lambda = \pm i\omega$). Замкнені еліптичні орбіти, нейтральна стійкість.

## ⚠️ Підводні камені та типові помилки (Pitfalls)

1. **Втрата особливих розв'язків при діленні на $g(y)$:**
   При відокремленні змінних $\frac{dy}{g(y)} = f(x)dx$ перевіряйте корені рівняння $g(y) = 0$. Вони можуть бути розв'язками, які втрачаються при діленні!
2. **Забутий резонансний множник $x^k$ у методі підбору:**
   Якщо права частина $f(x) = e^{2x}$, а серед коренів характеристики вже є $\lambda = 2$ кратності 1, шукати $y_{\text{част}}$ треба як $A x e^{2x}$, а не $A e^{2x}$.
3. **Плутанина між лінійною незалежністю функцій та векторів:** Функції $y_1, y_2$ лінійно незалежні на інтервалі тоді й лише тоді, коли їх вронскіан $W(x) \neq 0$.
